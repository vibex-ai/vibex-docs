代码工作台把文件树、搜索、编辑器、Git 差异和内容预览放在同一个窗口。所有文件操作都以当前工作区为边界。

## 文件树和搜索

从右侧栏的 **Files** 图标打开文件树：

1. 展开工作区目录，或用文件名直接输入定位（type-ahead）。
2. 使用 **Search workspace files** 按内容搜索，可以切换 **Match case**、**Match whole word** 和正则模式。
3. 点击文件在预览标签中打开；多个标签可以并列或分栏显示。

文件树的右键菜单提供 **New File**、**New Folder**、**Cut**、**Copy**、**Paste**、**Copy Relative Path**、**Copy Absolute Path**、**Copy File Name**、**Rename**、**Delete**，以及 **Open In** 子菜单（**Editor** / **Default App** / **Terminal** / **Native Terminal** / **File Manager**）。文件也支持拖放移动。

搜索不会自动修改文件。大型文件、不可解码内容和工作区外路径会被文件服务拒绝。

## 编辑和保存

- 在编辑器中直接修改文本。
- 用 **Save file** 保存当前文件（`cmd-s`）。
- 工具栏可以切换 **soft wrap** 和 **whitespace** 显示。
- 状态栏显示 `Ln N, Col N`、总行数、语言、编码（`UTF-8` / `UTF-8 BOM` / `Binary`）、行尾（`LF` / `CRLF` / `Mixed EOL`）和文件大小。
- 标题栏状态显示 **Modified**（有未保存改动）、**Saving** 或 **Saved**。

<Note>
  编辑器**没有** Save As：保存始终写回原路径。也没有文件内查找栏——`cmd-f` 打开的是会话搜索。
</Note>

### 大文件与只读

以下情况文件会以只读方式打开，并在标题栏标记 **Large file - read only** 或 **Binary - read only**：

- 大于 8 MiB
- 超过 5 万行
- 内容被截断
- 被识别为二进制

## 编辑器保护与恢复

每个编辑缓冲区同时记录已保存内容、外部 revision 和本地 revision。保存请求使用乐观并发控制：如果磁盘上的内容已经变化，保存会失败并返回 `file_external_revision_changed`，而不是静默覆盖。

有未保存改动的标签在关闭时会提示 **Save or discard the dirty editor before closing it**；切换工作区时同样会拦截。

权威运行时重启后，Vibex 会恢复未保存的缓冲区（标记为 **恢复缓冲区**）。恢复内容仍需你主动保存，不会自动覆盖磁盘文件。

<Warning>
  删除文件会改变工作区内容。删除前查看 Git 状态，必要时先复制内容或创建提交。
</Warning>

## 内容预览

| 类型 | 扩展名 | 能做什么 |
| --- | --- | --- |
| Markdown | `md` `mdx` `markdown` | 渲染视图，支持代码块、表格、任务列表、脚注、公式和图表（Mermaid / PlantUML）。 |
| 图片 | `png` `jpg` `jpeg` `gif` `webp` `svg` | 预览图片。 |
| PDF | `pdf` | 原生 PDF 预览，支持 **Fit width**、50%–200% 缩放和页码跳转。 |
| Office | `docx` `xlsx` `ods` `pptx` | 只读内容预览。 |
| 音视频 | `mp4` `mp3` `wav` 等 | **不在应用内播放**，交给系统默认应用。 |
| 其他 | 其余文本格式 | 以编辑器打开。 |

Markdown 预览提供 **Contents** 大纲、**Copy document text**、逐块 **Copy code** / **Copy diff**、图表源码查看和全屏。工作区相对链接在预览内打开，外部链接交给系统浏览器。

Office 预览是**只读的提取视图**，不是版面还原：

- `docx` —— 标题与段落。
- `xlsx` / `ods` —— **仅第一个工作表**，最多 80 行 × 20 列。
- `pptx` —— 幻灯片文字，最多 200 页。

PDF 预览同样只读，不支持搜索、批注和表单。

### 无法预览的格式

| 格式 | 现象 |
| --- | --- |
| `.bmp` | 显示 **Unsupported file**。 |
| `doc` `xls` `ppt` | 报 `office_legacy_format_unsupported`，请先转换为新格式。 |
| `odt` `odp` | 没有处理程序。 |
| `.html` | 以带高亮的源文本打开，**不会渲染页面**。 |
| `.json` `.yaml` `.csv` | 以源文本打开，不做格式化或表格化。 |
| `.ipynb` | 当作 JSON 文本打开，不是 Notebook。 |

<Info>
  语法高亮覆盖 Rust、TypeScript/TSX、JavaScript、JSON、Markdown、TOML、YAML、Python、Go、Java、CSS、HTML 和 Shell。其它语言以纯文本显示。
</Info>

## 图片编辑

图片编辑器用于**在发送前标注附件图片**，不是工作区图片文件的通用编辑器。在 Composer 的附件区点击 **Edit image** 进入。

可用工具：**Crop**、**Brush**、**Text**、**Rectangle**、**Circle**、**Arrow**、**Mosaic**，以及 **Undo edit** / **Redo edit**。支持 25%–400% 缩放和拖拽平移。

- macOS：`cmd-z` 撤销，`cmd-shift-z` 重做。
- Windows/Linux：`ctrl-z` 撤销，`ctrl-shift-z` 重做。

保存时会重新编码为 **PNG**，不支持选择其它格式，也没有旋转、缩放、翻转或图层。

## 预览标签和分栏

拖动标签或使用标签菜单中的 **Split right** / **Split down** 把视图分栏，分栏边界可以拖动调整。代码、差异、终端和文档都可以放在同一窗口里。

关闭标签不会删除文件或终端，只关闭当前视图。

## 标签操作

- 悬停在文件或差异标签上可查看完整路径。
- 标签右键菜单：**Close tab**、**Close other tabs**、**Close tabs to the left**、**Close tabs to the right**、**Close all tabs**、**Split right**、**Split down**、**Pin tab** / **Unpin tab**、**Reveal in Files**、**Open In**。
- 固定标签必须先取消固定才能关闭。关闭其它标签时，固定标签和未保存的标签会保留。
- `cmd-w` 关闭当前预览标签；`cmd-tab` / `cmd-shift-tab` 和 `cmd-pageup` / `cmd-pagedown` 循环切换标签。终端标签不使用这些快捷键。

完整快捷键列表见[快捷键参考](/reference/shortcuts)。
