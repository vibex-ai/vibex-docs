---
title: "代码工作台"
description: "浏览、搜索、编辑和预览工作区文件。"
---

代码工作台把文件树、搜索、编辑器、Git 差异和内容预览放在同一个窗口。所有文件操作都以当前工作区为边界。

## 文件树和搜索

1. 打开侧栏中的文件树，展开工作区目录。
2. 使用文件名搜索快速定位路径。
3. 使用内容搜索查找文本；结果会显示文件路径和匹配位置。
4. 点击文件在预览标签中打开。多个标签可以并列或分栏显示。

搜索不会自动修改文件。大型文件、不可解码内容和工作区外路径可能被文件服务拒绝。

## 编辑和保存

- 在编辑器中直接修改文本。
- 用 **Save** 保存当前文件；快捷键为 `cmd-s`（Windows/Linux 通常为 `ctrl-s`）。
- 新建、重命名或删除文件前确认目标路径。
- 编辑器默认保留软换行和空白字符显示偏好，可在工具栏切换。
- 编辑器顶部显示文件名、相对目录和状态；底部显示光标行列、总行数、语言、编码、行尾格式和文件大小。
- 保存时 Vibex 会携带已读取的内容 revision。若文件已被外部进程修改，保存会暂停并要求重新加载或比较差异，不会静默覆盖。
- 文件被外部删除时，编辑器会标记为缺失；未保存内容会保留在恢复缓冲区中，供你决定保存到新路径或放弃。

<Warning>
  删除文件会改变工作区内容。删除前查看 Git 状态，必要时先复制内容或创建提交，以便恢复。
</Warning>

## 编辑器保护与恢复

每个编辑缓冲区同时记录保存内容、外部 revision 和本地 revision。保存请求只在这三者仍然匹配时提交；并发修改会返回冲突状态，要求你重新读取后再决定如何合并。切换工作区或关闭标签前，桌面端会检查 dirty、保存中、外部冲突和文件缺失状态，并在必要时阻止操作。

重启或工作区重新载入时，桌面端会恢复受限的未保存缓冲区。恢复内容仍需要你主动保存，不会自动覆盖磁盘文件。

## 内容预览

| 类型 | 能做什么 |
| --- | --- |
| Markdown | 在编辑和渲染视图之间切换，查看代码块、表格、公式和图表。 |
| 图片 | 查看图片并进入图片编辑器；支持撤销和重做。 |
| PDF | 使用原生 PDF 预览，按页查看文档。 |
| Office 文档 | 预览受支持的 Office 文件内容。 |
| 其他文本 | 以编辑器打开，并保留编码和换行信息。 |

二进制文件和超过编辑器限制的大文件保持只读。Markdown 资源会遵守工作区路径、大小和资源数量限制；无法解码的内容不会被强制当作文本打开。

## 图片编辑

打开图片后进入编辑模式，完成裁剪或其他支持的编辑，再保存结果。图片编辑器提供：

- macOS：`cmd-z` 撤销，`cmd-shift-z` 重做。
- Windows/Linux：`ctrl-z` 撤销，`ctrl-shift-z` 重做。

保存前确认输出路径和文件格式。原图是否保留取决于你选择的保存目标。

## 预览标签和分栏

拖动标签或使用分栏入口，将代码、差异、终端和文档放在同一工作区中。关闭标签不会删除文件或终端；它只关闭当前视图。

## 标签操作

- 将鼠标悬停在文件或差异标签上可查看完整路径。
- 使用标签的上下文菜单可以关闭当前、其他或全部标签，也可以固定标签；标签栏的 **标签操作** 菜单提供关闭其他或全部标签。
- 固定标签必须先取消固定才能关闭。关闭其他或全部标签时，固定标签和未保存的编辑器标签会保留；未保存内容仍需先保存或放弃。
- 对非终端预览标签，`cmd-w`（Windows/Linux 为 `ctrl-w`）关闭当前标签；`cmd-tab`/`cmd-shift-tab` 和 `cmd-pageup`/`cmd-pagedown`（Windows/Linux 使用 `ctrl`）循环切换标签。聚焦标签后也可以使用左右方向键。

## 常用快捷键

| 操作 | macOS | Windows/Linux |
| --- | --- | --- |
| 保存文件 | `cmd-s` | `ctrl-s` |
| 打开预览 | `cmd-shift-p` | `ctrl-shift-p` |
| 侧栏 | `cmd-b` | `ctrl-b` |
| 关闭当前预览标签 | `cmd-w` | `ctrl-w` |
| 切换预览标签 | `cmd-tab` / `cmd-shift-tab` | `ctrl-tab` / `ctrl-shift-tab` |
| 切换上一个/下一个标签 | `cmd-pageup` / `cmd-pagedown` | `ctrl-pageup` / `ctrl-pagedown` |
| 前进/后退 | `alt-left` / `alt-right` | `alt-left` / `alt-right` |

快捷键可以在 **Settings > Shortcuts** 中查看或调整。
