打开 **设置**（`cmd-,`）可以修改桌面端的本地偏好。设置不会替代配置中心中的 Agent、供应商、MCP 或 Skill 配置。

页面顶部有 **搜索设置** 输入框，可以按名称或关键字直接跳到某一项。改动过的项旁边会出现 **撤销更改**。

## 分区

| 分区 | 可调整内容 |
| --- | --- |
| **常规** | 语言、关闭 Vibex 时的行为、Vibex TUI、网络代理、启动行为、开机启动、系统通知、更新。 |
| **外观** | 主题、工作台背景、窗口缩放、界面字体与代码字体、动效与对比度。 |
| **工作台** | 侧栏视图、新会话默认位置、预览窗口位置、布局记忆、Git 改动计数和编辑器自动保存。 |
| **远程实例** | SSH / WSL 远程运行时、配对链接、已配对设备、兼容性与卸载。 |
| **会话** | 会话内容宽度、时间线显示、消息队列、自动继续和 Agent 通知。 |
| **已归档会话** | 自动归档窗口、恢复和永久删除。 |
| **终端** | 默认 shell、新建终端的初始目录和终端打开方式。 |
| **浏览器** | 起始页、搜索引擎、画面质量、下载和登录状态。 |
| **电脑操作** | 驱动安装、系统权限、审批策略、面板和超时。 |
| **快捷键** | 查看、修改和重置键盘快捷键。 |
| **数据与诊断** | 本地存储用量与清理、诊断与恢复入口。 |
| **开发者** | 帧率监视器。 |
| **关于** | 版本、通道、软件更新、许可证和平台信息。 |

## 常规

| 选项 | 说明 |
| --- | --- |
| **语言** | 系统默认，以及 English、简体中文、繁體中文、日本語、한국어、Deutsch、Français、Español、Português (Brasil)、Русский。 |
| **关闭 Vibex 时** | 二选一：**后台运行**（关闭主窗口后留在系统托盘，默认）或 **直接退出**。旧版本里「关闭到托盘」的开关会自动按原意迁移。 |
| **Vibex TUI** | 允许本机上的 TUI 附着到这个运行时。关闭后，TUI 会提示 home 被锁，并给出其它连接方式。 |
| **网络代理** | 让 Vibex 的网络请求和 Agent 工具走本地或企业代理。支持 `http`、`https`、`socks5`、`socks5h`。启用前会校验地址。 |
| **启动行为** | 启动后恢复工作台，或直接新建会话。 |
| **开机启动** | 登录系统时启动 Vibex。 |
| **系统通知** | 桌面通知总开关。 |
| **更新提示** | 显示标题栏更新按钮和更新浮层。后台安全检查始终保持启用。 |
| **自动更新** | 默认开启。发现已签名的新版本后自动下载；可以在应用内立即安装，或在退出应用时安装。 |

<Note>
  自动更新只接受同通道的版本。RC 安装包只看 `-rc.*`，Stable 只看正式版本；通道不会互相回退。
</Note>

## 外观

控制主题模式（跟随系统 / 浅色 / 深色）、窗口缩放（75%–200%）、**界面字体** 与 **代码字体** 的字号和字重、**减少动效**、**失焦时暂停动画** 和 **高对比度**。代码字体同时影响代码块、集成编辑器和终端。

**主题** 用三张预览卡片选择 **跟随系统** / **浅色** / **深色**，每张卡片都会用该模式解析出的配色画一个微缩工作台。**浅色主题** 与 **深色主题** 是各自独立的下拉框，收起状态和菜单里都显示色块与主题名。内置二十套：浅色为 Vibex Light、Catppuccin Latte、Gruvbox Light、Solarized Light、GitHub Light、Rosé Pine Dawn、Everforest Light、Ayu Light、One Light、Kanagawa Lotus，深色为 Vibex Dark、Catppuccin Mocha、Gruvbox Dark、Tokyo Night、Nord、Rosé Pine、Everforest Dark、Ayu Dark、Dracula、Kanagawa Wave。你也可以把只写想改颜色的 JSON 主题文件放进运行时 home 目录的 `themes` 文件夹来扩充列表；文件里没写的颜色会按它实际所在的背景补齐。

**工作台背景** 可以放一张自己的图：静态图、GIF 或 WebP 动图，支持 **填充**、**适应** 或 **拉伸**，并有一层可调遮罩。浅色外观下背景会当作玻璃处理，启动加载页始终不透明。图片按项目图标同样的方式导入，存放在运行时 home 下。

字体会从系统已安装的字体中列出，缺失时回退。

## 工作台

| 选项 | 说明 |
| --- | --- |
| **侧栏层级** | **会话视图**（按会话分组）或 **工作区视图**（按工作区分组）。 |
| **新会话默认位置** | **当前检出** 或 **新建 Worktree**（中文界面显示「新建 Worktree」）。 |
| **编辑器窗口** | **内嵌**（在工作台列内嵌打开，默认）或 **独立窗口**（弹出为独立窗口）。预览面板标题栏的弹出和停靠按钮写入同一项设置。 |
| **记住工作台布局** | 记住侧栏、预览、右侧栏和分栏布局。 |
| **显示 Git 变更数量** | 在 Git 图标上显示待处理改动数。 |
| **项目覆盖项** | 清除各项目的布局覆盖。 |
| **工作区状态** | 清除记住的工作区选择。 |
| **重置工作台布局** | 把工作台布局恢复默认。 |
| **自动保存** | **手动**（只用保存快捷键）、**延迟保存**（停止输入后写回）或 **失焦保存**（编辑器或窗口失去焦点时写回）。 |
| **自动保存延迟** | 停止输入多久之后写回，250–5000 毫秒，默认 1000 毫秒；只在 **延迟保存** 时出现。 |

## 远程实例

SSH 和 WSL 远程运行时是**测试版**，入口始终可见，不需要开发者开关或环境变量。

可以：

- **添加 SSH 连接**：从 SSH 配置发现主机，探测环境并开始配置。
- **添加 WSL 运行时**：选择本机 WSL2 发行版，并设置 **运行时端口**（默认 `8765`）。
- **用配对链接连接**：粘贴 `vibex://pair#/code/...`，或填入地址与数字配对码。
- **初始化 SSH**：为没有 sshd 的 Linux 主机生成一次性 bootstrap 命令。
- 查看配置进度、诊断卡、日志和运行时兼容性。
- 编辑或移除连接，卸载远端运行时。

完整步骤见[SSH 与 WSL 远程运行时](/ssh-runtime)。

## 会话

控制会话内容宽度（窄屏 / 标准 / 全屏）、时间线条目显示（**会话预览条**、**Agent 生成状态**、**推理显示方式**、**默认展开推理**、**命令卡片渲染**、**文件编辑卡片渲染**、**自动折叠工具调用**），以及消息队列行为：

- **队列发送** —— 自动或手动。
- **消息发送按键** —— Enter 或 Cmd/Ctrl+Enter。
- **自动继续** —— 让满足条件的回合自动推进；无法继续时会停下来等待你处理。默认开启。
- **Agent 通知** —— **Agent 完成** / **Agent 需要输入** / **Agent 失败** 三类通知开关；**系统通知** 总开关关闭时这三项不可用。
- **已记住的运行时** / **自动继续默认项** —— 清除已记住的选择。
- **Agent 配置** —— 打开配置中心的 Agent 分区。

## 已归档会话

已归档会话保留完整时间线，并从侧栏移出。这个页面可以：

- 设置 **自动归档** 的空闲窗口（关闭，或 1–14 天）。自动归档按项目/文件夹生效，只归档空闲、已结束且没有运行中回合的会话；置顶会话和委派子会话不归档。
- 查看已归档会话列表，**恢复** 到侧栏，或 **永久删除**。
- **全部删除** 已归档会话。

归档是可逆的；删除不是。误归档可以在这里撤销。

## 终端

设置默认 shell 和新建终端的初始目录（**Worktree** / **项目** / **当前文件**）。

- 默认 shell 可以从系统检测到的 shell 中选择，也可以指定自定义路径。
- 已打开的终端不会因为修改偏好而迁移。
- 滚动缓冲区固定为 10000 行，不可配置。

## 浏览器

控制内嵌浏览器面板自己的标签页：

| 选项 | 说明 |
| --- | --- |
| **起始页** | Google、Bing、百度或自定义地址。只影响你新建的标签页。 |
| **搜索引擎** | 地址栏输入关键词时使用；支持 Google、Bing、百度、DuckDuckGo 或自定义模板。 |
| **无损画面** | 文字更清晰，但画面更大、更慢；面板上的 HD 按钮切换同一个设置。 |
| **允许下载** | 默认关闭。打开后页面可以保存文件到运行时下载目录。 |
| **导入本机 Chrome 登录状态** | 从 Chrome、Edge 或 Brave 复制 Cookie 与 localStorage 到隔离配置。只读源配置，不写回。 |
| **清除浏览器数据** | 删除隔离配置里的 Cookie、localStorage、缓存和已导入登录状态；已打开标签会关闭。 |

详见[内嵌浏览器](/browser)。

## 电脑操作

电脑操作默认关闭。这个页面负责：

- 安装和检测桌面驱动。
- 查看操作系统权限（辅助功能、屏幕录制）。
- 设置审批策略（**允许** / **询问** / **拒绝**）和是否允许 Agent 操作 Vibex 自身窗口。
- 打开电脑操作面板，选择 **窗口** 或 **浮动** 模式。
- 设置单次桌面调用的超时。
- 查看当前平台支持的能力和 Wayland 实验路径。

完整说明见[电脑操作](/computer-use)。

## 快捷键

所有可重绑定的快捷键、默认键位和分组见[快捷键参考](/reference/shortcuts)。在这里可以逐项修改，也可以 **重置** 单项或 **全部重置** 全部恢复默认。冲突的键位会被拒绝并提示 **快捷键无效或已被占用**。

## 数据与诊断

显示本地存储用量明细（数据库、会话、终端、附件、诊断、Agent 安装），并提供逐类清理入口：

| 操作 | 影响 |
| --- | --- |
| **清理会话与附件** | 删除会话和附件记录。 |
| **清理终端数据** | 删除终端元数据。 |
| **清理诊断数据** | 删除诊断数据。 |
| **数据目录** | 在文件管理器中打开数据目录。 |
| **打开用量统计** | 跳转到用量统计。 |
| **诊断与恢复** | 打开管理中心，查看诊断与恢复入口。 |
| **从 RC 版本导入数据** | 把候选版的工作区、会话与供应商配置带进当前版本；导入失败时保留当前数据。见[从候选版本导入数据](/privacy-and-recovery#从候选版本导入数据)。 |

<Warning>
  清理操作是**破坏性**的，且不会回滚。执行前先阅读[隐私与恢复](/privacy-and-recovery)。
</Warning>

## 开发者

- **帧率监视器**：在工作台显示帧率和重绘信息，用于诊断性能。开启时每秒记录一次采样到诊断数据。

## 关于

显示当前**版本**与**通道**（预览 / ReleaseCandidate / Stable）、平台信息、许可证，并提供：

- **软件更新** —— 更新状态与操作按钮（**立即检查** / **下载更新** / **安装更新** / **立即重启** / **打开发行版** / **重试**）。更新清单经过签名校验，校验失败不会安装。卡片还会列出 **最新版本**、**发布时间** 和 **下载大小**，并把该版本的发布说明渲染成 Markdown（**Vibex 更新内容**）；没有更新时显示当前已安装版本的发布说明。
- **环境摘要** —— 可复制的不敏感环境信息，报问题时附上它。
- **源代码** / **更新日志** —— 跳转到仓库和发布说明。

报告问题时请附上版本、通道、平台和结构化错误码，不要附上完整日志。
