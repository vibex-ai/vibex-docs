**Usage Statistics** 用來查看 Vibex 已記錄的 Agent 用量。它是觀測工具，**不是帳單頁面**——實際價格、額度和發票仍由供應商決定。Vibex 不記錄費用，也沒有價格欄位。

入口：側欄的 **Usage Statistics** 按鈕，或 Composer 上的 token 圓環（**Open usage statistics**）。

## 選擇時間範圍

工具列提供四個範圍，並據此自動決定分桶粒度：

| 範圍 | 涵義 | 分桶 |
| --- | --- | --- |
| **Today** | 依系統時區查看今天。 | 小時 |
| **7 days** | 最近七天。 | 天 |
| **30 days** | 最近三十天。 | 天 |
| **All** | 本機保留的全部記錄。 | 月 |

沒有可用記錄時頁面顯示空狀態，不會把未知值當成零。

## 篩選和分組

可以組合五個篩選器：**Agent**、**Model provider**、**Model**、**Project**、**Session**。

結果可以依五個維度分組，也就是表格上方的分頁：**Time**、**Agent**、**Project**、**Model provider**、**Model**。

<Note>
  **Project** 維度對應側欄裡的專案，一個專案下可能包含多個工作區。**Session 只作為篩選器**，不能作為分組維度。
</Note>

## 讀取指標

彙總區顯示六個指標：

| 指標 | 涵義 |
| --- | --- |
| **Total tokens** | 各類 Token 的合計。 |
| **API requests** | 已觀測的 API 請求數；適配器不提供逐請求資料時改為顯示 **Turns**。 |
| **Input** / **Output** | 輸入與輸出 Token。 |
| **Cached read** | 快取讀取 Token。 |
| **Cache hit rate** | 快取讀取相對於可計算分母的比例。 |

分組表的欄位為：維度名稱、**Requests**、**Total**、**Input**、**Output**、**Cache**、**Hit rate**、**Last activity**、**Coverage**。

### Coverage 的涵義

**Coverage** 說明這一行的資料可信到什麼程度：

| 顯示 | 涵義 |
| --- | --- |
| **Reported** | 適配器完整回報。 |
| **Derived from input + output** | 總量由輸入加輸出推導，而非直接回報。 |
| **Partial** | 只回報了一部分。 |
| **Not reported** | 沒有資料。 |

滑鼠懸停還可以看到更細的分佈（complete / partial / baseline only / unreported / unsupported）。

<Warning>
  **不要把 `Not reported` 或 `Partial` 解讀為零**，也不要用它推算供應商帳單。缺少供應商欄位時 Vibex 會保留未知狀態，而不是填入猜測值。
</Warning>

## 趨勢檢視

| 檢視 | 說明 |
| --- | --- |
| **Trend** | 堆疊長條圖，可在 **Total** / **Input** / **Output** / **Cache** 之間切換，圖例可點擊篩選。 |
| **Heatmap** | 365 天日曆熱圖，展示每日活動密度；沒有年度資料時顯示為不可用。 |
| **Models** | 依天展示各模型佔比（100% 堆疊），取前 10 個模型，其餘歸入 **Other** 和 **Unknown**。可在 **Turns** 和 **Total tokens** 之間切換。 |

重新整理期間頁面保留上一份結果並標記為過期；載入失敗時優先使用上一份權威結果，並提示 **Refresh failed; showing previous data**。

## 資料邊界

- 用量來自權威執行環境記錄的 Agent 執行和適配器回報。**權威執行環境是統計的權威來源。**
- Usage Statistics **不讀取**完整提示詞、檔案內容、終端機輸出或供應商金鑰。
- **行動端不顯示用量明細**——行動端的用量頁只顯示會話數量，並提示 "Usage details are available on the desktop host."
- 單次查詢有資料列數上限（100000 列），超出會傳回 `agent_usage_query_too_large`。

匯出診斷資料時請遵守[隱私與恢復](/zh-TW/privacy-and-recovery)中的去識別化要求。
