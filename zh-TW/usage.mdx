---
title: "用量統計"
description: "依時間、Agent、專案、供應商和模型查看本機用量。"
---

**用量統計** 用來查看 Vibex 已記錄的 Agent 用量。它是觀測工具，**不是帳單頁面**——實際價格、額度和發票仍由供應商決定。Vibex 不記錄費用，也沒有價格欄位。

入口：側欄的 **用量統計** 按鈕，或輸入框上的 token 圓環（**開啟用量統計**）。

## 選擇時間範圍

工具列提供四個範圍，並據此自動決定分桶粒度：

| 範圍 | 涵義 | 分桶 |
| --- | --- | --- |
| **今天** | 依系統時區查看今天。 | 小時 |
| **7 天** | 最近七天。 | 天 |
| **30 天** | 最近三十天。 | 天 |
| **全部** | 本機保留的全部記錄。 | 月 |

沒有可用記錄時頁面顯示空狀態，不會把未知值當成零。

## 篩選和分組

可以組合五個篩選器：**Agent**、**模型供應商**、**模型**、**專案**、**會話**。

結果可以依五個維度分組，也就是表格上方的分頁：**時間**、**Agent**、**專案**、**模型供應商**、**模型**。

<Note>
  **專案** 維度對應側欄裡的專案，一個專案下可能包含多個工作區。**會話只作為篩選器**，不能作為分組維度。
</Note>

## 讀取指標

彙總區顯示六個指標：

| 指標 | 涵義 |
| --- | --- |
| **總 Token** | 各類 Token 的合計。 |
| **API 請求數** | 已觀測的 API 請求數；適配器不提供逐請求資料時改為顯示 **對話輪次**。 |
| **輸入** / **輸出** | 輸入與輸出 Token。 |
| **快取讀取** | 快取讀取 Token。 |
| **快取命中率** | 快取讀取相對於可計算分母的比例。 |

分組表的欄位為：維度名稱、**請求**、**總計**、**輸入**、**輸出**、**快取**、**命中率**、**最近活動**、**回報覆蓋**。

### 回報覆蓋的涵義

**回報覆蓋** 說明這一行的資料可信到什麼程度：

| 顯示 | 涵義 |
| --- | --- |
| **已回報** | 適配器完整回報。 |
| **由輸入 + 輸出推導** | 總量由輸入加輸出推導，而非直接回報。 |
| **部分回報** | 只回報了一部分。 |
| **未回報** | 沒有資料。 |

滑鼠懸停還可以看到更細的分佈（complete / partial / baseline only / unreported / unsupported）。

<Warning>
  **不要把 `Not reported` 或 `Partial` 解讀為零**，也不要用它推算供應商帳單。缺少供應商欄位時 Vibex 會保留未知狀態，而不是填入猜測值。
</Warning>

## 趨勢檢視

| 檢視 | 說明 |
| --- | --- |
| **趨勢** | 堆疊長條圖，可在 **總計** / **輸入** / **輸出** / **快取** 之間切換，圖例可點擊篩選。 |
| **熱力** | 365 天日曆熱圖，展示每日活動密度；沒有年度資料時顯示為不可用。 |
| **模型** | 依天展示各模型佔比（100% 堆疊），取前 10 個模型，其餘歸入 **其他** 和 **未知**。可在 **對話輪次** 和 **總 Token** 之間切換。 |

重新整理期間頁面保留上一份結果並標記為過期；載入失敗時優先使用上一份權威結果，並提示 **重新整理失敗，正在顯示上次資料**。

## 資料邊界

- 用量來自權威執行環境記錄的 Agent 執行和適配器回報。**權威執行環境是統計的權威來源。**
- 用量統計 **不讀取**完整提示詞、檔案內容、終端機輸出或供應商金鑰。
- **行動端不顯示用量明細**——行動端的用量頁只顯示會話數量，並提示 "Usage details are available on the desktop host."
- 單次查詢有資料列數上限（100000 列），超出會傳回 `agent_usage_query_too_large`。

匯出診斷資料時請遵守[隱私與恢復](/zh-TW/privacy-and-recovery)中的去識別化要求。
