**Usage Statistics** 用來查看 Vibex 已記錄的 Agent 用量。它是本機觀測工具，不是帳單頁面；實際價格、額度和發票仍由供應商決定。

## 選擇時間範圍

工具列支援以下範圍：

| 範圍 | 意義 |
| --- | --- |
| **Today** | 依系統時區查看今天的記錄。 |
| **7 days** | 查看最近七天。 |
| **30 days** | 查看最近三十天。 |
| **All** | 查看本機保留的全部記錄。 |

統計結果會顯示有效起止時間和分桶方式。範圍為空或沒有可用記錄時，頁面會顯示空狀態，不會把未知值當成零。

## 篩選和分組

你可以組合 **Agent**、**Model provider**、**Model**、**Project** 和 **Session** 篩選器。結果也可依時間、Agent、專案、供應商或模型分組。長工作階段名稱會在篩選選單中截斷顯示，但懸停仍可查看完整名稱。

## 讀取指標

摘要和分組表會盡量顯示以下指標：

- **Requests**：已觀測的請求或工作階段執行次數。適配器不提供逐請求資料時，頁面會按可確認的執行粒度統計。
- **Total tokens**：輸入、輸出和快取等可用 Token 的合計。
- **Input / Output / Cached tokens**：分別顯示輸入、輸出和快取 Token。
- **Cache hit rate**：快取讀取 Token 相對於可計算分母的比例。
- **Coverage**：標記指標是完整回報、推導、部分回報還是未知。

缺少供應商欄位時，Vibex 會保留未知狀態。不要把 `unknown` 或 `partial` 解讀為零，也不要用它推算供應商帳單。

## 查看趨勢

趨勢區域提供三種檢視：

- **Bars**：按時間桶比較總量、輸入、輸出、快取或請求數。
- **Heatmap**：按日期查看全年活動密度；沒有年度資料時會顯示不可用狀態。
- **Models**：按模型比較請求數或總 Token，超出主要模型數量的項目會歸入其他模型。

切換指標不會修改已保存的用量記錄。重新整理期間頁面會保留上一份結果並標記為過期，載入失敗時優先使用上一份權威結果。

## 資料邊界

用量來自桌面端記錄的 Agent 執行和適配器回報。桌面端是統計的權威來源；行動端只接收經過權限過濾的投影。Usage Statistics 不讀取完整 Prompt、檔案內容、終端機輸出或供應商密鑰。匯出診斷時仍應遵守[隱私與恢復](/zh-TW/privacy-and-recovery)中的脫敏要求。
