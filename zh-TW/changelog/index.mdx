## 如何閱讀版本頁面

* **亮點** — 該版本最重要的行為變化。
* **新功能** — 該版本新增的能力，按受影響的產品面分組。
* **修復** — 已修正的問題，按受影響的介面分組。
* **效能** — 響應速度與資源佔用的改進。
* **內部、建構與文件** — 依賴升級、建構與發佈流程、文件和規範改動。

版本頁面按發佈說明整理，頁尾的完整差異連結指向 GitHub 上的提交範圍。較早的候選版本頁面還會在條目末尾標註提交短雜湊（例如 `(ec6e378)`）。
