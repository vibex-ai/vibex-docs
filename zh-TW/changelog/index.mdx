## 如何閱讀版本頁面

* **亮點** — 該版本最重要的行為變化。
* **新功能** — 該版本新增的能力，按受影響的產品面分組。
* **修復** — 已修正的問題，按受影響的介面分組。
* **效能** — 回應速度與資源佔用的改進。
* **內部、建置與文件** — 依賴升級、建置與發佈流程、文件和規範改動。

條目末尾的短雜湊值（例如 `(ec6e378)`）標識 GitHub 上的對應提交。
