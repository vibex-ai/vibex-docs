## 如何閱讀版本頁面

- **亮點** — 該版本最重要的行為變化。
- **新功能** — 按遠端與伺服器、桌面端、行動端分組的新增能力。
- **修復** — 已修正的問題，按受影響的介面分組。
- **內部、構建與文件** — 依賴升級、構建與發布流程、文件和規範改動。

條目末尾的短雜湊值（例如 `(ec6e378)`）標識 GitHub 上的對應提交。
