## 亮點

* **工作台裡內建瀏覽器，而且 Agent 能驅動它** — 瀏覽器面板與終端、預覽並列，用的是你已經裝好的 Chrome。頁面即時可見，Agent 在同一個標籤裡操作，因此它操作的物件和你看到的內容不會脫節。
* **在頁面與程式碼之間來回跳轉** — Alt+點擊頁面元素，開啟渲染它的原始檔並定位到行；Alt+點擊原始碼行，在頁面中高亮該行渲染出的元素。答不出來時，兩個方向都會說明原因。
* **瀏覽器工具幾乎能到達每個 Agent** — 內建瀏覽器服務會投遞給每一個能承載它的 Agent，每個 Agent 的行都會說明它拿到了什麼，或者為什麼什麼都沒拿到。
* **預覽可以開啟任意位置的檔案** — 專案外的檔案以唯讀方式開啟，標籤選單的檔案瀏覽器現在也能選檔案，而不只是資料夾。
* **Prompt 成為一等物件** — Prompt 有了自己的配置中心標籤，左側列表、右側單一編輯器；啟用的 Prompt 會作為快捷短語出現在輸入框中。
* **Skill 市場改讀 ClawHub** — 可以直接瀏覽登入庫自己的排名，Skill 以完整資料夾安裝，其中的引用、腳本一併帶上。
* **更快、更安靜** — 側欄、計時器和懸停效果帶來的閒置重繪被削減，流式回合不再為每個分塊付出一次資料庫往返。
* **GPUI 套件升到 0.7.0** — 對話方塊、面板和通知層改由根層擁有，選中的引用在輸入框中成為一個原子化的整體。

## 新功能

**內嵌瀏覽器**

* 可從右欄、編輯器頭部終端入口旁，或標籤欄的「+」選單開啟瀏覽器；它是工作台裡的一個工具面板，而不是第二個應用視窗（`8b7b7e9`、`e144dad`、`75a01fd`）
* 完整導航：前進、後退和重新整理按鈕在無處可去時停用，滑鼠側鍵可用，右鍵頁面選單提供前進、後退、重新整理、複製、貼上和全選（`f625d8d`、`171c446`）
* 標籤的行為和瀏覽器一致：頁面自己開啟的標籤會新建一個，頁面關閉的標籤隨之消失，Agent 開啟的標籤在它驅動期間帶專屬標記（`b525944`、`66679a6`、`5fd55b6`）
* 每個標籤顯示頁面自己的標題和載入指示器，還有站點圖示，以及寬度上限，長標題不會擠佔整條標籤欄（`66679a6`、`e1e8028`）
* 瀏覽器標籤在重啟後恢復；恢復不了的標籤會在頁面上說明原因，而不是留一個空白標籤（`ade29a4`）
* 輸入、點擊、滾動和快捷鍵都能到達頁面，包括 Ctrl/Cmd+C/X/V、F5 與 Ctrl+R 重新整理、Ctrl+L 聚焦位址列（`5a4684a`、`ac451cf`、`a8da112`）
* 頁面上的下拉框會打開面板自己的選單；頁面請求檔案時會開啟工作台的檔案瀏覽器，並把你確認的選擇交回頁面（`112359b`、`9a52f05`）
* 頁內查詢會高亮每一處命中並滾動到當前項；指標會對映所指元素的游標，因此連結在點擊前就看得出來是連結（`aa33e67`）
* 下載預設拒絕，允許後以永不覆蓋的安全檔名儲存，並顯示進度彈窗、一個開啟目錄的按鈕，每次儲存只通告一次（`aa33e67`、`c9f1915`、`9a52f05`）
* HD 開關可把即時畫面切換為無損影像以便細看，你的選擇會被記住（`e06d4a7`）
* 面板的活動按鈕會即時顯示 Agent 的瀏覽器操作；錄製期間會顯示橫幅，提示原始表單值仍留在記憶體中（`1f0cb32`、`a96f3da`）
* 任何終端標籤打印出的開發伺服器都會被檢測到，並以通知形式提供而不是把你跳轉走；瀏覽器設定可選擇新標籤起始頁和位址列搜尋引擎（`1c7c1cf`、`df03fcf`）
* 暫停始終是你的主動動作：Agent 正在驅動的頁面會顯示播放/暫停按鈕，驅動期間標籤欄變綠、暫停後轉為弱化色，點擊、滾動或輸入都不會替你暫停它（`197fef5`、`2e6e35a`）

**Agent 瀏覽器工具**

* 內建瀏覽器服務通過本地端點或 sidecar 投遞，包括那些 CLI 讀取自己 MCP 檔案的 Agent；`pi` 與 `factory-droid` 什麼都拿不到，會如實標註而不是靜默失敗（`b0f6fb2`、`4dc4a90`）
* 31 個工具保留粗粒度、細粒度和視覺三檔，並且從頁面讀到的一切都按不可信內容圍起來，而不是憑一句提示就採信（`c81194a`）
* 跨源框架內的頁面同樣可以讀取，嵌入的小元件不會成為盲區（`9cd20d0`）
* 上傳檔案或在瀏覽器中開啟本地檔案會先詢問你，卡片上列出檔名且沒有「始終允許」——位於專案內並不等於同意把檔案送出去（`9cd20d0`）
* 導航處處受限：新建標籤與你手動輸入的地址受同一套策略約束，一次性批准不會被記住，正在使用的標籤也不會被清理流程在 Agent 腳下關掉（`6cde975`）

**瀏覽器與程式碼**

* 在頁面裡 Alt+點擊會開啟該元素的原始檔並定位到行，這次點擊不會到達頁面；沒有答案時面板會內聯說明原因（`ae3e82f`）
* 在原始碼行上 Alt+點擊會高亮並滾動到這一行渲染出的元素，用的是與 Agent 操作相同的那個高亮（`6aec9f4`）

**預覽與檔案**

* 專案外的檔案在預覽面板中以唯讀方式開啟：客戶端直接讀取，儲存會被拒絕並給出說明，標籤也始終顯示檔案真正所在的位置（`904c7be`、`3d83253`）
* 標籤選單的檔案瀏覽器現在也能選檔案：點擊行是選中而不是進入目錄，確認的路徑會在預覽中開啟（`d41d783`）

**配置中心**

* Prompt 成為配置中心的一級標籤：可搜尋的列表、每條記錄一張卡片、所選 Prompt 的單一編輯器；列表預覽 Prompt 正文而不是重複它的型別，帶著未儲存修改離開會先詢問（`4d203b5`、`37a2fb7`）
* 已啟用的 Prompt 會作為快捷短語出現在輸入框的 `/` 彈窗中，按原文插入，排序先按使用頻率再按最近編輯（`b1e0d21`）
* 快捷短語彈窗會按行數調整高度，預覽它將插入的文本，並避免過長的名稱把預覽擠沒（`8c3dadb`）
* MCP 市場分頁遍歷整個登入庫，而不只是已抓取的第一個視窗；傳輸篩選在切頁之前收窄結果，篩選後的檢視不會被誤當成完整目錄（`5f575e8`）
* 管理側欄的資源行統一一種選中樣式，結果摘要改為正文尺寸，必須截斷的卡片說明以省略號結尾而不是從詞中間切斷（`f467d7d`）

**Skill**

* Skill 市場改讀 ClawHub，使用登入庫自己的排名和分頁，因此瀏覽不再需要替代查詢，目錄也能真正分頁（`3d95486`）
* Skill 以完整資料夾安裝——說明文件加上它呼叫的引用、腳本和模板——安裝前解包供你檢視，條目被限制在 Skill 自己的資料夾內，被拒絕的檔案會逐個報告（`3d95486`）
* 一次安裝即可到達 Claude、Codex、Cursor、Gemini、OpenCode 和預設來源，走的是原生 Skill 匯出（`3d95486`）

**Agent 管理**

* 託管 Agent 執行環境被固定到穩定入口，重啟 Agent 不再改寫你的持久配置，也不會讓繫結到它的會話失效（`64f3c7b`）
* 對外觀性修改供應商配置不再讓會話繫結失效，而端點、憑證或命令的真正改動仍會照常重建它們（`eeb55ac`）
* OpenCode 新增可按會話選擇的自動接受模式，同時也讓工作區外的讀取不再每次都彈窗（`af8a9fa`）
* Codex 會話在你所選供應商配置的模型上啟動，因此換一個模型會乾淨地重啟，而不是讓程序停留在舊模型上（`b5dc05d`）
* Claude 供應商配置中的模型無需修改你自己的 Claude 配置即可解析（`9d71fcc`）
* 排隊中的訊息能在本地寫入爭用中存活，不再報「訊息未傳送」（`8530dd5`）

**輸入框**

* 從建議選單選中的 `/` 命令、`@` 檔案或 `$` Skill 成為一個整體：游標一步跨過，一次退格整體刪除，點擊檔案 token 即可開啟該檔案——而發給 Agent 的文本仍然與你看到的完全一致（`3f47e3c`）

**工作台與設定**

* 查詢跟隨焦點：Ctrl+F 先交給聚焦的編輯器，再交給聚焦的瀏覽器面板，只有真正持有鍵盤的對話才打開會話搜尋（`d793b4f`、`9a52f05`）
* 拖動會話會移動你已選中的每一行，包括當前會話行，因此高亮的內容和移動的內容始終是同一批行（`b699a38`、`7b0c3e9`）
* 設定行按頁面寬度決定堆疊還是同行，值列保持可收縮且標籤列有下限，長值能幹淨換行而不會被擠成每行一個字元（`68f8be5`）
* 開發者 FPS HUD 每次開啟都居中顯示，拖動是相對中心的偏移，且永遠不會跑出視窗（`87a2268`、`4b52031`）
* 更新入口與「關於」頁面已修復：圖示使用成功色，從更新面板開啟「關於」不再自顧自地出錯，釋出說明滾動時不會帶著後面的面板一起動（`7581dff`）
* 右鍵選單、對話方塊或另一個分屏持有鍵盤時，編輯器仍顯示你的選區（`a6c62ec`）
* 關閉「視窗失活時暫停動畫」後，後台工作台真的繼續動，包括側欄指示器、終端游標和回合計時器（`beacd98`）
* 中文介面把該功能稱為 Skill 而不是「技能」，在輸入框、側欄和市場標題中保持一致（`1f51aa9`、`5f575e8`）

## 修復

* 修復在 Windows 上開啟標籤：殘留的瀏覽器端點不再指向已死的瀏覽器，也不再每次啟動都探測你安裝的 Chrome（`a7a7289`）
* 修復第一次點擊瀏覽器入口就崩潰的問題，畫面流結束時不再凍結在最後一幀（`9c9a00c`、`90ab6f8`）
* 丟棄會導致所有頁面載入失敗的繼承代理設定；頁面載入失敗時保留你請求的地址，標籤不再停在內部的錯誤頁地址上（`5d7d9cb`、`1f66568`）
* 補上面板此前丟掉的事件——頁面對話方塊、檔案選擇器和可用性變化——讓只有明確輸入才會從 Agent 手中接管，並讓已停止會話的批准請求立即被拒絕而不是耗完超時（`2e6e35a`、`3079c7d`）
* 每次下載只通告一次，修復面板的空格、回車、Ctrl+X 和下載反饋，並讓拖動按你預期的方式選擇文本（`c9f1915`、`9a52f05`、`65c8ab2`）
* 移除讓瀏覽器無法使用的阻斷式風險提示，並刪除無法安全附著的檢查器和元素拾取器（`93ab323`、`228ec67`）
* 讓市場分頁器固定顯示而卡片在其下滾動，把不滾動面板的高度還給它，並修復「關於」頁面的釋出資訊（`0c0d534`、`e638395`、`7581dff`）
* 設定行按頁面排版並讓長值換行；關閉失活暫停後自驅動動畫繼續執行；市場的匯入表單仍使用自身滾動（`68f8be5`、`beacd98`）
* 遠端面板現在會如實標記為降級，並說明這些顯示選項不會配置真正執行頁面的那台機器，而不是靜默失敗（`6a7d58f`）

## 效能

* 削減閒置重繪：懸停效果、側欄狀態指示器、回合計時器和區域設定查詢在無變化時不再重繪視窗，FPS HUD 也在快取邊界之後繪製（`80f4b4d`）
* 流式分塊不再各付一次資料庫往返、一次提交和一次輪詢，共享執行環境也按所在主機的規模調整（`e934ec0`）
* 在後台退讓而不是空燒幀：視窗失活時所選會話的輪詢減少，token 用量改在介面執行緒之外讀取（`80f4b4d`）
