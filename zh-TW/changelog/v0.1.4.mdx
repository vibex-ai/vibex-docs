## 亮點

* **Linux 新增 RPM 包** — x86_64 與 aarch64 在 `.deb` 和 AppImage 之外提供 `.rpm`，從已稽核的 `.deb` 載荷重新打包，更新清單把它登記為 `rpm/system_installer` 產物。
* **共享 Provider 的改動送達每個 Agent** — 在 Providers 頁面編輯一個 Provider 會更新所有繫結到它的 Agent，而不再只更新最初派生該記錄的那一個。
* **Codex 讀取你宣告的模型能力** — 帶宣告的思考檔位或上下文視窗的別名模型會投影進一份私有 Codex 目錄，因此檔位可選、宣告的視窗生效。
* **WSL 執行環境配置顯示進度** — 新增 WSL 執行環境會報告每一步，並把連線連同即時狀態保留在 **遠端連線** 下。
* **遠端 Markdown 圖片可以載入** — 會話與渲染文件裡的 `http(s)` 圖片改走應用自己的 HTTP 客戶端，每個響應上限 32 MiB，不再被平臺拒絕請求的客戶端變成空白。
* **串流的觀看成本更低** — 回答流式輸出時，桌面端合併只與串流有關的時間線事件，並把側欄與標籤掃掠限制在 30fps 預算內。
* **移動端會話同步更輕** — 手機只在開啟圖片時拉取附件位元組，推理更新只攜帶新增的增量。

## 新功能

**Linux 打包**

* `.rpm` 由 `scripts/build-rpm.mjs` 從已稽核的 `.deb` 資料載荷驅動 `rpmbuild` 生成，安裝檔案、權限和內嵌的 PDFium 執行環境與 `.deb` 逐位元組一致。
* 打標籤的釋出任務上傳 RPM，釋出頁列出下載，簽名更新清單攜帶 `rpm/system_installer`。

**桌面端**

* 後臺更新檢查不再自行開啟標題欄面板；更新仍通過標題欄入口出現，面板點選才展開，並畫在樹內層，讓對話框顯示在它上方。
* 選擇 **連線 WSL** 會逐步報告發行版檢查、下載、安裝、啟動、轉發、配對和連線，關閉對話框後繼續執行；失敗的嘗試可以在 **遠端連線** 裡重試或檢視。
* 遠端 `http(s)` Markdown 圖片與 HTML `<img>` 源通過應用 HTTP 客戶端載入，帶連線與請求超時、最多十次重定向和 32 MiB 響應上限。
* 渲染 Markdown 的目標在解析為 URL 前先分類：`file:` URL 或 `C:\work\notes.md` 這樣的磁碟機代號路徑按本地檔案解析並開啟，`http(s)` 仍是網頁，其它協議不支援。
* 標題微光、只與串流有關的時間線批次、側欄與分組標籤掃掠都遵守 30fps 動畫預算；減少動效或視窗不活躍時仍渲染靜態內容。

**Provider 與 Agent**

* 在 Providers 頁面新增或編輯模型會同步到每個 Agent 的啟動行與執行環境配置，每個 Agent 仍只顯示自己宣告的協議；刪除模型留在 Providers 頁面，儲存 Agent 頁面不再移除其它 Agent 仍能訪問的模型。
* 閘道器路由組與遠端排程寫入也會重新發布目錄，因此 Provider 編輯、刪除或 Key 變更會重新整理所有受影響的 Agent，包括來自已配對裝置的寫入。
* Codex 的別名模型會寫入 Profile 旁的 `vibex-models.json`，列出每個啟用模型及其宣告的上下文視窗和思考檔位，並把 `model_catalog_json` 指向它；兩者都未宣告的 Profile 保持原輸出。
* 託管 Agent 的安裝或回滾只有在快照與新的啟動指紋匹配時才算當前，避免新會話以 `runtime_switch_configuration_unavailable` 失敗。
* pi-acp 的 `<provider>/<model>` 模型 id 會帶上 provider 名稱空間，讀回時再剝掉，因此含斜槓的產品 id 不再被拒絕為 `Model not found`。

**移動端與遠端**

* 時間線讀取用有界標記替換內聯附件，只在圖片開啟時讀取詳情項；`agent_session` 事件限定在開啟的會話，應用在後臺時只發通知，缺口用有界追頁恢復。
* 推理分塊按增量傳送，內聯附件位元組從時間線頁預算中扣除。
* 遠端時間線頁限制在 512 KiB，為 Relay 的 E2EE 信封留出餘量；Relay 的幀上限通過 `VIBEX_RELAY_MAX_WEBSOCKET_FRAME_BYTES`（預設 2 MiB）暴露。

**技能與市場**

* 安裝按鈕在 Skill 資料夾抓取和預覽期間保持可用，大 Skill 上的按下會被記住，並在預覽到達時立刻開始安裝；寫入的位元組仍嚴格等於預覽披露的內容。
