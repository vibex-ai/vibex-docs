## 亮點

* **用所點名的 chip 調校被委派的 Agent** — 輸入框的執行環境級聯跟隨游標：落在 `@Agent` chip 上時，Provider、模型、思考檔位、對話模式和功能開關編輯的是這位協作者；移開游標就回到會話。調校值編碼進 chip 的 token id，草稿、剪貼簿和遠端客戶端都能還原同一份配置。
* **抓取的 Provider 模型先挑選再匯入** — 模型標籤頁開啟選擇器，被宣傳的每個模型是一行；確認之前不寫入，確認時只加入所選行，不覆蓋你手寫的模型。`autoRefreshModels` 現在只決定廠商的新行是否預設勾選。
* **父 Agent 可以回答自己子任務的核准** — 被委派的子 Agent 繼承了父級的沙箱與工具集，因此批准它的常規命令不會擴大權限。`vibex_read_approvals` 讓父級先在不信任圍欄內讀卡片，`vibex_decide_approval` 只能批准或拒絕，不可逆操作仍由人決定。
* **轉錄有了右鍵選單與摺疊** — 使用者訊息、Agent 回答、選區、過程行、回合標題和時間線都能右鍵；**自動摺疊工具呼叫** 把進行中的工具活動畫成一行摘要，展開後才顯示呼叫。摺疊偏好預設關閉。
* **被停止的委派不會再凍住輸入框** — 取消任務會關閉子任務提出的核准卡片，裁決會讀取取消圍欄，遲到的核准以 `task_cancelled_before_approval` 作答；傳送前佇列的派發圍欄改為按會話區分。

## 新功能

**會話轉錄**

* 右鍵選單可以複製、引用到輸入框、在該行分叉、編輯並重發、停止正在流式輸出的回答；過程行可以複製命令、輸出、輸入、diff 或路徑並開啟檔案；選區可以按文字或 Markdown 複製、引用、查詢並開啟一個外部連結。
* 選單攜帶自己要操作的資料，因此即使在分組面板或只讀的子 Agent 側欄上開啟，也作用於它被開啟的那份轉錄；子 Agent 側欄只保留複製和引用。
* 會話設定新增 **自動摺疊工具呼叫**。開啟後，進行中的工具活動只畫一行摘要——改動檔案、命令、讀取和失敗的數量——展開後才顯示具體呼叫；含待核准行的執行保留即時規則。
* 該偏好儲存在 `SessionUiState`，通過 `AgentTimelineDisplaySettings` 同步到移動端與遠端，並參與回合形狀鍵與高度指紋。

**Provider 與 Agent**

* 已儲存 Provider 的模型標籤頁改為選擇器：左側是抓取到的模型、核取方塊和過濾，右側是所選模型的設定；確認只加入所選模型，已有行保留能力、顯示名稱和啟用狀態。
* 選擇器是完整的雙欄介面，佔用整個視窗並逐幀讀取視口，開啟期間的縮放會被跟隨；關閉某行時通過與設定欄關閉按鈕相同的命令收起設定欄。
* 兩個編寫對話框改為在各自欄內滾動：滾輪落在哪一欄就只移動哪一欄，不再帶動表單帶或整個對話框頁面。
* Agent 頁面的 **自訂 Provider** 與 **新建路由組** 固定在圖庫下方的獨立條帶裡，較長的 Provider 圖庫不會再把它擠到摺疊線以下。
* `vibex_read_approvals` 返回呼叫者自己的子任務所停駐的卡片——標題、風險類別、截止時間和圍欄內詳情；不帶 `taskRefs` 時報告所有等待項。`mayAnswer` 與裁決執行相同的規則，不可逆操作會直接讀作需要人決定。
* 只有繼承了父級沙箱與工具集的被委派子任務才能被回答，且只能由該任務自己的父級回答；同級或更上層會被拒絕。拒絕會讓卡片保持待處理，每次裁決都會記錄作出者。

**委派與協作**

* chip 把思考檔位、對話模式和功能值編碼進 token id，解析器既接受精確的選項引用，也接受應用請求覆蓋項後匹配目錄條目的引用。
* 沒有獨立面板或模式：游標落在 `@Agent` chip 上就編輯該協作者，移開或刪除 chip 就是退出手勢。每個 Agent 的選擇對映及其讀取規則已刪除。
* 選擇 `@Agent` 行後游標落在 chip 右邊緣，一次 Enter 既選中協作者又開啟其引數；新建會話頁面新增 **委派給** 徽章。
* 新會話按草稿所指的配置啟動；第一條訊息會帶上 chip 的提及，立即傳送不再丟棄它。
* Provider 選單從 chip 自身的 Agent 與認證來源開啟；chip 寫入器跟隨所選 Agent 的 id 與名稱。
* 調校會隨委派進入子任務，並寫入與會話切換相同的偏好儲存，下一次輸入 `@` 時建構的行會帶上這份配置。

## 修復

* 取消任務不再死鎖會話：核准卡片隨取消關閉，遲到的核准不會執行被停止的工作，傳送前佇列的派發圍欄按會話隔離。
* 從 POSIX shell 回顯的 Windows 路徑（`/C:/...`）與編輯器位置（`:line`）可以正確開啟；工作區根目錄按同樣方式歸一化，`file:` URL 與 POSIX 絕對路徑不受影響。
* 移除遠端執行個體後列表立即更新，不再等到下一次重新整理。
* chip 的選區不再多出一個字元，編輯中的 chip 會畫出選中態；新建會話頁面的 chip 也會讓頁面進入編輯。
* 已結算的回合不會被停止操作重寫，遲到的結果會標記為遲到。

## 效能

* 關閉的執行環境選單不再逐幀重建：Provider 與模型面板只在彈出層開啟或播放退出動畫時建構，指標劃過轉錄時不再反覆遍歷並複製整個模型目錄。

## 內部、建構與文件

* 版本號升到 `0.1.6`。
* 未調校的 chip 仍保留原來的精確 id，因此舊草稿和舊的 `@Agent` token 仍可解析。
