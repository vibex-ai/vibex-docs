## 亮點

* **本地模型閘道器** — 一個迴環端點擋在所有共享 Provider 前面。它說 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Google Generative AI 四種協議，在它們之間翻譯，並把每次呼叫轉給服務所請求模型的 Provider。
* **會故障轉移的路由** — 一條路由是一個可選擇的模型。你可以用整個 Provider 或 `(Provider, model)` 組合它，選七種策略之一，並在某個成員無法作答時讓閘道器移到下一個。
* **重建的 Provider 工作區** — Providers、路由組和閘道器共享一個工作區，帶可摺疊側欄、身份頭和原地編輯。手寫配置的 Provider 會成為可複用模板，預設模型列表來自 models.dev 目錄。
* **SSH 與 WSL 遠端執行環境** — 桌面端可以把權威執行環境放到另一臺機器：通過 SSH 安裝 `vibex-server`、開啟隧道、自動配對，並用保留執行環境身份的版本回滾升級。
* **會自己釋出的託管產物** — Linux x86_64/aarch64 與 macOS 的無頭服務端產物在固定 Debian 12 建構器裡生成，釋出把穩定映象映象到 Docker Hub 與 CNB，AUR 包重新發布 Linux `.deb`，Linux 載荷縮小約三分之一。
* **時間線讀起來像文件** — 工具呼叫按結構渲染而不是 JSON：路徑與值欄位、待辦清單、提問列表，以及作為 diff 的編輯。回合頭先講意圖、結果和耗時。
* **每個印出來的鍵都是按鈕** — TUI 裡的 `鍵 標籤` 圖例就是控制元件：點選會通過與鍵盤相同的分發器按下它命名的鍵。
* **多出十位守護者** — 新建會話的競技場從六場遭遇擴充套件到十六場，每位守護者有自己的入場、路線節奏和同伴效果。

## 新功能

**本地模型閘道器**

* 一個迴環端點服務四種編碼 Agent 已經在說的協議，並通過單一的中間表示翻譯，包括跨流式形狀重新編碼的工具呼叫。
* 一段對話停留在持有其提示快取的 Key 上，固定 Key 不會帶來快取未命中；路由狀態（冷卻、固定、輪換、在途）不進入 Agent 程序指紋，更換 Key 不會重啟程序。
* 併發與請求速率按 Key 設限：通道限制在途請求，滿通道在有界 FIFO 佇列裡等待，之後才回答 429；滾動一分鐘限制啟動數，突發會退化成等待而不是無界積壓。
* 路由組有兩種形狀：`ProviderGroup` 組合整個 Provider 並提供它們啟用目錄的**交集**，`ModelGroup` 把 `(Provider, model)` 組合在一個面向 Agent 的 id 後面。只有一個 Provider 提供的模型刻意不進入組，因為組的策略絕不能把模型發給從未聽說過它的 Provider。
* 七種策略——有序、輪詢、最少使用、智慧、最低延遲、加權和手動——都可以從本地觀察計算。路由可以設定首 token 期限，同時約束響應頭和第一個流式 token。
* 熔斷器按路由組而不是按 Provider 劃分，未宣告的協議會被探測而不是被拒絕。
* 請求帳本記錄請求實際走的路由：因不可用而跳過的成員與嘗試失敗分開記錄；跟蹤只帶 id 和失敗型別，絕不帶提示、回答或 Key 材料。
* Gateway 頁面是獨立工作區：即時路由圖回放每個請求、可展開的請求歷史、可選擇區間的 p50/p95、告警閾值、預設超時、上游順序，以及一個說明保留視窗並先詢問的清除動作。

**Provider 與遠端執行環境**

* 共享 Provider 記錄是寫入權威：在一個地方編輯會到達所有繫結它的 Agent，繫結也可以刻意不指定 Provider，讓 Agent 自己認證。
* Provider 工作區重建為：左側一列把閘道器、Providers 和路由組摺疊在一個 **新建** 選單下，共享身份頭、下劃線標籤和分割槽卡片，設定原地編輯，路由組在自己的頁面編輯。
* 65 個預設以資料形式釋出且不再攜帶模型 id：應用預設會從內建 models.dev 目錄（53 個 Provider）讀取廠商條目，包括限制和能力標誌。
* 手寫配置的 Provider 成為 **使用者定義** 下的可複用模板：每次讀取時從記錄投影，不攜帶秘密值請求頭，用 `user:` 字首定址因此不會遮蔽內建預設，可以隱藏和恢復而不觸碰 Provider、Key 或模型。
* Provider Key 行用遮蔽指紋而不是生成的標籤標識憑據，眼睛按鈕通過顯式讀取揭示值，普通快照只帶遮蔽值。
* 請求頭覆蓋會投影到原生 Agent 與閘道器；匯入一次預覽一個來源、分頁大模型列表、儲存前測試草稿；草稿地址與 Key 可以抓取模型；每個 Key 的模型範圍和代理可配置。
* 桌面端通過 SSH 在遠端 Linux 主機安裝 `vibex-server`，用固定 TLS 證書在迴環上啟動、開啟 `ssh -L` 隧道、自己通過 SSH 領取一次性配對碼，並用 Remote Protocol v2 連線——不需要 Docker、公網埠或手動複製配對碼。
* 九步配置狀態機擁有順序、取消安全點、失敗重試和“執行環境 id 只在就緒後暴露”的不變數；重複開始會返回正在執行的嘗試。
* 環境探測檢查 Linux、架構、glibc、磁碟餘量、home 可寫、`sha256sum` 和目標埠，並以型別化錯誤阻止；Git、`SHELL` 和未知埠只作為警告。
* 隧道受監督：看門狗每 500 毫秒檢查子程序，必要時重建同一份隧道規格一次，並把重啟或失敗擺到檯面上，而不是留下靜默死掉的迴環端點。
* 升級是事務性的：新產物安裝在當前產物旁邊，執行環境身份保留，啟動失敗會回滾到上一版本並啟動檢查。
* 解除安裝可以保留 home；SSH 配置可以編輯、移除和重新配置；已配對的 SSH 連線即使在配置前也可以移除。
* macOS 遠端主機通過 LaunchAgent 支援，釋出 arm64 與 x86_64 服務端產物；WSL2 發行版完全不需要 sshd，上傳、安裝、啟動、等待 localhost 轉發、在迴環領取配對，並能在 `wsl --shutdown` 後恢復。
* 遠端執行個體現在位於工作區分組的 **設定 → 遠端執行個體**，始終出現在導航、搜尋和命令面板裡；此前的開發者開關及其環境變數已被移除。標題欄執行環境面板變成已配對執行個體的切換器，底部動作開啟設定。

**時間線與會話**

* 工具呼叫渲染成可讀結構：`path: value` 欄位、待辦清單、提問與回答列表、解包的 harness 輸出信封，以及帶 `+N/-M` 的編輯 diff，並計入回合的改動檔案與移動端。
* 只命名工具的標題會讓位給呼叫自己的命令、路徑或查詢，`cd <絕對路徑> &&` 字首不再把命令本身擠出截斷點。
* 活動頭先講意圖與結果：失敗呼叫在摺疊時顯示它列印的第一行，結束的命令與 Agent 呼叫顯示執行環境長，抓取有自己的型別和地球圖示，組摘要先講改動的檔案。
* 訊息裡引用的工作區圖片——相對、根相對、絕對或 `file://`——會內聯渲染並限制在工作區內，點選開啟全視窗預覽；時間線圖片變成可點選縮圖。
* 內建工具面板按會話而不是按 Agent 選擇：新建會話頁面記錄每個面板的顯式開關，缺失項跟隨 Agent，分叉或委派會複製這張對映。
* 長正文通過自己的視口讀取，執行中的會話開啟在歷史上而不是即時執行上，讀者所在的位置在內容從上方落下後仍然保留。
* 新建會話輸入框新增全屏控制元件，自動繼續成為 shell 級預設設定，無需顯式選擇就會繼續。
* 側欄用會話行已有的漏斗姿態選單收窄列表——全部、執行中、等待你、未讀、失敗和已置頂——批次操作跟隨可見行。
* 開啟的編輯器標籤跟隨磁碟上變化的檔案，淺色主題重調為冷中性階梯與實心不透明模組填充。

**市場、TUI、移動端與競技場**

* MCP 市場用讀者自己的問題詢問登錄檔，而不是遍歷有上限的後臺目錄，釋出順序很深的名字也能立刻找到；分頁走登錄檔游標，每個問題保留一組結果。
* 市場條目攜帶釋出者自己的圖片和遠端條目必需的請求頭，後者成為安裝輸入並路由到伺服器的請求頭而不是環境變數。
* Skill 市場讀取約一秒回答的公開目錄：排名首頁解析一次並共享六小時，瀏覽頁把一個倉庫摺疊到最多四條，安裝從目錄點名的倉庫取出。
* 市場卡片點選即安裝，搜尋在輸入時執行，按功能的 Agent 膠囊選擇哪些 Agent 接收該功能。
* TUI 的每個 `鍵 標籤` 圖例都是可按目標：佇列與停靠帶、模態頁尾、設定頁尾和新會話頁的方括號提示都發布自己的矩形與所指的組合鍵，按下走與鍵盤相同的 `handle_key`。
* `Chord::from_hint` 按讀者的讀法解析圖例——`^S`、`Space`、`↑`、`J/K`、`Alt+↑↓`——成對的箭頭拆成兩個一單元格目標。
* 佇列帶與停靠面板會滾動以保持游標可見，點選通過帶子繪製的視窗對映，而不是從矩形頂部數行。
* Providers 表可以切換閘道器並顯示帶價格的套餐預設；匯入的 Key 按用途命名；放不下的列會被丟棄而不是擠壓。
* 已結算的工具呼叫保持摺疊，落在讀者面前的回答保持展開，`Ctrl+C` 只中斷會話頁面；提示帶按輸入框真正繪製的寬度設定尺寸。
* 移動端按實際繪製的大小讀取文字階梯，連線頁帶 Vibex 字標，同步徽章畫成文字，CBDT emoji 字型作為 APK 資產釋出；檔案和提交在輸入時搜尋，時間線滾動時保留讀者的位置，會話結束後把螢幕交還給讀者；恢復路徑不再因連線已死而中止，新會話提前開啟，鍵盤關閉時終端保持不動。
* 十位守護者加入原來的六位，共十六場遭遇：Cursor、Cline、Grok、ZCode、Kimi、CodeBuddy、Antigravity、Devin、Gemini 和 Hermes。每位擁有自己的入場、退場和路線節奏，每個同伴效果由各自的勝利解鎖。

## 效能

* 閘道器虛擬化請求帳本並分頁歷史，請求在執行環境就出現在帳本裡，而不是結束後才出現。
* 長對話正文通過視口分塊讀取，帶視窗的正文在邊緣淡出，而不是佈局它持有的全部內容；模型列表虛擬化，草稿的端點與 Key 只探測一次。
* Skill 市場的搜尋把 8 到 13 秒的往返縮短到約一秒，MCP 市場不再依賴後臺遍歷完成。
* Linux x86_64 釋出連結用 lld 的 `--icf=all`，摺疊重複的單態化函式體。

## 內部、建構與文件

* 版本號升到 `0.1.0-rc.9`；新增 `crates/model-gateway` 與 `crates/model-catalog` 兩個工作區成員，資料庫模式從 63 到 87。
* 工作區升級到 `gpui-kit` `0.8.0`，`rustls` 到 `0.23.46`，`zip` 到 `9.1.3`。
* 已清除的安全發現包括配置中心裡的路徑注入讀取、一個看起來像憑據日誌的測試斷言，以及 Linux GTK 棧遷移到 gtk 0.19 與 `tray-icon` 的 StatusNotifierItem 後端，移除鎖檔案裡的 `glib` 0.18 公告。
* Linux `.deb` 改為 xz 重新打包，從 119.8 MB 降到 69.8 MB；打包機現在需要 `xz` 和 `ld.lld`。
* 許可證 SBOM 與第三方宣告按當前依賴圖重新生成：1080 個 Cargo 包、10 個資源與字型包、5 個原生與安裝器輸入，全部已批准。
