## 亮點

* **首個正式版** — `0.1.0` 是從候選版本進入穩定支援的分界點，提供 `latest` 容器標籤與 AUR 釋出，正式版與 RC 版使用彼此隔離的資料目錄。
* **真實終端會話** — 通過 13 款已驗證的 Agent CLI，在 PTY 終端裡直接執行 Agent，同時保留側欄、搜尋、移動端和 TUI 整合。
* **真正的工作臺** — 會話、原始碼、Git、終端、嵌入式瀏覽器、本地模型閘道器、Agent 團隊、目標和多窗格會話組在同一個介面裡。
* **執行環境在你自己手裡** — 權威 `DesktopRuntime` 可以跑在本機、區域網內的 `vibex-server`，或由 SSH / WSL 自動部署的遠端執行環境上。
* **三個介面，一個執行環境** — 桌面端、移動端和終端客戶端（`vibex`）驅動同一個權威執行環境，並從同一份釋出安裝。
* **支援 10 種語言** — 英語、簡體中文、繁體中文、日語、韓語、德語、法語、西班牙語、巴西葡萄牙語和俄語。

## 核心功能

**會話與工作臺**

* 區分 ACP 時間線與純終端兩種傳輸，支援分屏會話組、命令面板式搜尋、會話過濾、內聯目標和生命週期任務委派。
* 側欄、搜尋、通知、移動端與 TUI 都能看到終端模式會話，並在同一行上工作。

**終端**

* 回滾區搜尋、向量製表符、內建 Nerd Font、連字、OSC 剪貼簿 / 標題 / 顏色查詢，以及滑鼠上報。

**桌面端**

* 20 套內建主題、跟隨系統的視窗邊框、基於 Chrome 的可互動嵌入式瀏覽器、Provider 工作區和智慧托盤 / 退出選項。

**閘道器與模型**

* 統一的本地模型閘道器（OpenAI、Anthropic、Google）、可自訂的故障轉移路由，以及詳細的模型能力。

**遠端與移動端**

* `vibex-server` 掃碼配對、SSH / WSL 遠端配置，以及功能與桌面端對齊的移動客戶端。

## 效能與底層

* 終端網格渲染從 242 毫秒降到 3 毫秒，會話搜尋改為索引式即查，時間線虛擬化，後臺資源清理把 Android APK 從 429 MB 降到 73 MB。
* 正式版與 RC 版使用隔離的應用目錄，並提供安全的資料庫遷移與匯入；環境變數做白名單清理，SBOM 與許可證清單更新。

## 從候選版本升級

正式版與 RC 版是兩個獨立應用，各自擁有獨立的資料目錄，因此正式版安裝後從空資料開始。要繼承 RC 版本的工作，開啟 **設定 → 資料與診斷 → 本地儲存 → 從 RC 版本匯入資料** 並確認。Vibex 會先對 RC 資料庫做快照、遷移並校驗副本，在下次啟動時換入；工作區、會話和 Provider 配置會一併帶過來，匯入失敗時保留當前資料。RC 安裝本身不會被修改，可以繼續把它作為退路。
