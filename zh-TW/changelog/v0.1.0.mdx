## 亮點

* **首個正式版本** — `0.1.0` 結束了候選階段。穩定通道擁有自己的應用身份與資料目錄，容器映像的 `latest` 標籤指向它，AUR 的 `vibex-bin` 也隨它發佈。
* **真實終端會話** — Agent 可以在自己的 CLI 裡執行，由 PTY 承載對話；已驗證十三款 Agent，側欄、搜尋、通知、行動端與 TUI 仍然在同一個會話列上工作。
* **一個完整的工作台** — 會話、原始碼、Git、終端、內嵌瀏覽器、本機模型閘道、Agent 團隊、目標與分屏會話組合在一起，不用在工具之間搬運上下文。
* **執行階段在你自己手裡** — 權威執行階段可以跑在本機、你自己的 `vibex-server` 上，或由桌面端透過 SSH / WSL 自動部署到另一台機器。
* **三個介面，一個執行階段** — 桌面端、行動端與終端客戶端 `vibex` 驅動同一個權威執行階段，並從同一份發佈裡安裝。
* **十種語言** — 英語、簡體中文、繁體中文、日語、韓語、德語、法語、西班牙語、巴西葡萄牙語和俄語。

## 新功能

**會話與工作台**

* 會話按執行方式分成兩種：ACP 會話擁有時間線與執行階段綁定，終端會話啟動一個 Agent CLI 並只記錄觀測事實；兩者在側欄、搜尋和通知裡是同一列（`35916d16`、`55c0c32d`）
* 會話組把同一個 Worktree 下的多個會話放在一起，可以分屏、合併窗格、整組自動繼續，也可以拖動到資料夾或解散（`7348c84b`、`e6f49bd7`）
* 側欄把草稿按資料夾歸檔，會話可以拖進組裡，組用分支導軌畫出成員來源（`7348c84b`、`0058ab32`、`cd6f299b`）
* 側欄篩選是可多選的集合，會話可以按建立、更新、標題或手動順序排列（`125bea0c`、`7d99b489`）
* 命令面板一次輸入同時檢索會話、設定項和快捷操作；會話搜尋只索引對話文字並高亮符合項（`e30fdf14`）
* 目標透過 ACP 的 `_meta.goal` 擴充發佈，歸一成目標列裡的階段、統計和控制按鈕
* 委派有生命週期：任務可以保持開啟、追加跟進、接受或取消，重試落到最初那次接受
* 內建工具面板按會話選擇，缺省條目跟隨 Agent，分叉或委派複製這份對應（`2acc9b7a`、`3866693d`）

**終端**

* 回滾緩衝區搜尋覆蓋每一條保留的列，上一處／下一處會把符合項捲動到視野內（`9efd0d49`）
* 製表字元按筆畫畫成相連的向量線，表格與面板邊框跨儲存格對齊（`9efd0d49`）
* 隨包的 `Symbols Nerd Font Mono` 讓 Agent 的狀態圖示不再畫成方塊（`9efd0d49`）
* 儲存格度量取自字型自身的步進，CJK 仍佔兩欄；連字是可以關掉的偏好項（`9efd0d49`、`bef85503`）
* 回應 OSC 52 剪貼簿、OSC 0/2 標題與顏色查詢，以及 1005、1015、1016 三種滑鼠回報方言（`9efd0d49`）
* 終端背景可以設透明度，主題墨色被提亮到最低對比度（`9efd0d49`）
* 終端模式的 CLI 透過各自真正讀取的啟動輸入收到 MCP 伺服器、Vibex 委派、瀏覽器與電腦操作，憑證不進入 argv（`06e89ac7`、`7b30af79`）

**桌面端**

* 內建二十套淺色與深色主題，主題模式跟隨系統，視窗邊框可以浮動（`f9e4bc2d`）
* 工作台背景可以放靜態圖、GIF 或 WebP，支援填充、適應、拉伸和一層可調遮罩
* 內嵌瀏覽器由 Chrome 驅動，Agent 可以讀取和操作頁面
* 供應商工作區把閘道、供應商與路由組合在一處，支援可折疊側欄與原地編輯（`9c5f2498`、`e2b94939`）
* 關閉主視窗的行為是一個二選一：繼續在系統匣執行，或直接結束（`6cc327a1`）
* 標題列的執行階段面板是已配對執行個體的切換器，遠端執行個體始終出現在導覽與搜尋裡（`33571d2e`、`ce9d6afa`）

**閘道與模型**

* 一個回環端點提供 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 與 Google Generative AI 四種協定，並在它們之間翻譯（`6e7d1513`、`69dcf747`）
* 路由由 `(Provider, model)` 成員組成，支援七種策略、首 token 期限、按 Key 的並行與速率上限（`3bec21f2`、`41956368`、`c166d3b8`）
* 預設作為資料發佈並從 `models.dev` 目錄讀取模型資訊，手工設定的 Provider 可以存成可重複使用範本（`f9dfd52c`、`c7e58564`）
* 請求帳本記錄每次請求真正走過的路由，只帶 id 與失敗類型；即時路由圖可以重放一次請求的路徑（`60974688`、`37193353`）
* 模型能力從維護好的目錄建議，上下文視窗與思考檔位是宣告資料，不會從模型 id 猜測

**遠端與行動端**

* 桌面端透過 SSH 在遠端 Linux 或 macOS 主機上安裝 `vibex-server`，建立通道、自動配對，並在升級失敗時回滾且保住執行階段身份（`4aa8b4a6`、`ec66c998`、`349d09bc`）
* WSL2 發行版不需要 sshd 就能作為本機 Linux 執行階段，`wsl --shutdown` 後會自動恢復（`6de4ca9e`、`4ccdd60a`）
* 沒有 sshd 的 Linux 主機可以用一次性 bootstrap 命令初始化，命令帶到期時間並校驗 payload 雜湊（`c5df1c5c`、`bb67ef78`）
* 行動端掃碼配對同一個執行階段，可以檢視進度、回覆提問、處理核准並使用終端
* 行動端跟隨「減少動態效果」，開啟會話時保持自己的 workspace 與對話（`252329db`、`5d88cbf5`）

**TUI**

* `vibex` 開啟目前目錄的新建會話頁，目錄與上次使用的執行階段已經填好（`97ca1952`）
* 介面是一列全寬橫帶，任意終端尺寸下都自動重排，沒有最小尺寸
* 每個畫出來的 `鍵 標籤` 圖例都是可點目標，點擊走與鍵盤相同的分發路徑（`7d031085`）
* 管理頁是桌面風格的設定中心，配對頁合併了配對、已配對裝置與遠端存取
* 語言、主題與鍵位寫入 `~/.vibex/tui-interface.json` 與 `~/.vibex/tui-keys.toml`

**語言與在地化**

* 桌面端、行動端與 TUI 都繪製十種語言；新增的七種語言由一份共享目錄承載，未翻譯的句子回退到英語（`36d65e63`）
* 語言選擇器在兩個客戶端上都列出全部十種語言加「跟隨系統」（`36d65e63`）
* 韓語的間距按隨包 CJK 字型的真實步進排布（`c1c421d3`）

## 從候選版本升級

穩定版與候選版是兩個獨立應用，各自擁有獨立的資料目錄，因此穩定版安裝後從空資料開始。要繼承候選版本的工作，請開啟 **設定 → 資料與診斷 → 本機儲存 → 從 RC 版本匯入資料** 並確認。

Vibex 會先對候選版資料庫做快照、遷移並校驗副本，在下次啟動時換入；工作區、會話與供應商設定會一併帶過來，匯入失敗時保留目前資料。候選版安裝本身不會被修改，可以繼續把它作為退路。

首次啟動時如果偵測到旁邊的候選版資料，也會彈出一次匯入提示，選擇 **匯入資料** 或 **暫不匯入**。
