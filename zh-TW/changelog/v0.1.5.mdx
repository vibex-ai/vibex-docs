## 亮點

* **委派跟隨輸入框所示** — TUI 把選中的執行環境選項引用帶進草稿、被持有的訊息佇列和傳送路徑；桌面端在編輯委派行時改寫已插入的 `@Agent` chip；權威端把子會話繫結到最新使用者訊息中的 Agent 提及。與提及不一致的委派會以 `target_mismatch` 拒絕，而不是悄悄換一個 Provider 或模型執行。
* **WSL 執行環境可以選埠** — 新增對話框新增 **執行環境埠**（預設 `8765`），在下載開始前校驗和探測；埠被佔用時對話框保持開啟，並把所選埠寫進提示裡。埠儲存在連線配置中，安裝、啟動、配對和每次重連都會複用。
* **配對連結回歸** — **設定 → 遠端執行個體 → 用配對連結連線** 可以直接新增 `vibex://pair#/code/...` 列印的執行環境，不需要 SSH、隧道或 Docker 映象。已完成的配對面板現在提供 **完成**，可以在不撤銷裝置的情況下關掉。
* **思考檔位可以由 models.dev 建議** — 模型編輯器在 **思考檔位** 下提供 models.dev 釋出的檔位值和一個明確的 **應用** 行。不會自動採納；已經宣告相同檔位的配置保持不變。
* **Agent 更新不再丟帳號目錄** — 託管 Agent 更新或應用升級可能在目錄重新發現之前改變啟動標識。上一次完整的目錄會繼續支撐顯式模型的會話，直到重新整理落地；只影響執行環境的啟動輸入不再改變目錄標識。
* **失敗的回合保留回答** — 已經給出回答、隨後遇到邊界錯誤的回合會把回答保留為結論，錯誤收在摺疊後面；向上載入更早歷史時，讀者所在的那一行也不會被挪走。

## 新功能

**桌面端**

* **新增 WSL 執行環境** 提供 **執行環境埠**，預設 `8765`；埠先在本地校驗，再在發行版內探測，失敗時對話框帶著埠號保持開啟。
* **遠端執行個體** 接受配對連結：連結自帶地址時隱藏地址欄位，只有配對碼時接受數字配對碼加位址，被拒絕或過期的配對碼連同原因留在欄位旁。配對成功會註冊執行環境、列入 **遠端連線** 並連線。
* 完成配對後的面板顯示 **完成**，關閉面板不會撤銷新授予的裝置權限。
* 即時標籤的掃掠改為以應用 33 毫秒的動畫預算為下限，故意按 30fps 繪製的幀不再被誤判為遲到而永久停止掃掠。

**Provider 與 Agent**

* 模型編輯器的 **思考檔位** 從 models.dev 快取的 `reasoning_options` 讀取建議值；只有點 **應用** 才寫入，已宣告相同檔位的配置隱藏建議。
* 帳號目錄在啟動標識變化後回退到同一帳號修訂號下最新的完整目錄，而不是讓顯式模型會話以 `agent_auth_model_catalog_unavailable` 失敗。
* 終端能力、繼承的環境值等只影響執行環境的輸入從目錄指紋中排除，換 shell 或 headless 啟動仍能找到同一份目錄。
* 重新發現得到空結果時借用上一次的模型並標記為不完整，等待後臺重新整理；重新整理迴圈每修復一個 Agent 就釋出會話可用的目錄，不再等整個清單。
* 一個 Agent 的發現失敗或操作鎖丟失只記錄並跳過，其餘目錄重新整理繼續；失敗的寫入稍後重試，不再中止迴圈。

**委派與協作**

* `vibex_delegate` 與 `vibex_create_session` 繫結最新使用者訊息中的 Agent 提及；衝突的 `selectionRef` 以 `target_mismatch` 拒絕，未指定目標時採納唯一的提及，多個提及時要求呼叫方點名或用 `agentId` 收窄。人類直接執行的 **委派** 動作攜帶自己的精確引用，不受影響。
* TUI 接受 `@Agent` 行時記住穩定的執行環境選項引用，它隨草稿、佇列和傳送請求一起走；刪除可見標籤會撤回引用。
* 桌面端修改委派行的 Provider 或模型時，會重寫草稿中匹配的 `@Agent` token，可見標籤仍是 `@Agent`，編碼的提及 id 指向剛選的配置。

**移動端與終端**

* 冷啟動時讀到空尾不會再清掉已恢復的字首：只有帶缺口且非空的回答才能替換字首，已配對的會話不會先顯示再變成「沒有訊息」。
* TUI 中先給出回答、後報邊界錯誤的回合把回答保留為結論，錯誤留在可展開的工作裡。
* 在視口上方載入更早歷史時同時錨定塊與塊內行，長回答中間的閱讀位置不會被拉回第一行。
