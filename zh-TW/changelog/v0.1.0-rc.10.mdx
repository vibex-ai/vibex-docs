## 亮點

* **Agent 會話進入真實終端** — 會話可以建立為終端模式：Agent 自己的 CLI 在 PTY 裡擁有整段對話，而不是由 Vibex 繪製時間線。13 款 Agent 已通過驗證，側欄、搜尋、通知、移動端和 TUI 仍在同一行上工作。
* **終端網格讀起來像終端** — 回滾區搜尋與匹配跳轉、可拖動捲軸、按筆畫繪製的製表符、內建 Symbols Nerd Font、連字、URL 點選開啟、OSC 剪貼簿與標題，以及三種規範的滑鼠上報。
* **MCP 伺服器送達原生 CLI** — 你配置的 MCP 伺服器、Vibex 委派、嵌入式瀏覽器和電腦操控，通過每個終端模式 CLI 真正讀取的啟動輸入交給它，憑據不會進入 argv。
* **應用退出後不再留下程序** — 游離的 Agent 守護程序按它執行的內容回收，電腦操控驅動在空閒五分鐘後歸還記憶體，被遺棄的幀泵自行退休。
* **gpui-kit 0.9.0** — 工作區升級到新套件與 `gpui-pre` `0.3.11`，並用上兩項能力：編輯器查詢欄的總覽標尺，以及兩個客戶端都跟隨減少動效的游標。
* **會自己組裝的釋出頁** — 釋出任務從打標籤的說明、執行實際產出的資產和 GitHub 貢獻者名單合成一頁；macOS 應用包做 ad-hoc 簽名，Gatekeeper 不再稱它已損壞。

## 新功能

**終端會話**

* `SessionTransport` 命名會話的執行方式：ACP 會話擁有時間線與執行環境繫結，終端會話啟動 CLI 且兩者都不擁有。終端建立是獨立入口，不是 ACP 建立上的一個標誌。
* 13 款 Agent CLI 通過終端模式驗證：Claude、Codex、OpenCode、Gemini、pi、Grok、Cline、Copilot、Cursor、Kimi、CodeBuddy、Devin 和 Hermes。每款的提示介面、模型 / 檔位 / 模式引數、重啟命令和退出提示都集中在一張 `TerminalCli` 表裡。
* 配置的模型隨命令列傳遞，因為終端會話沒有別的通道；Agent 預設不傳任何 id，未知引數則不傳。終端模式只攜帶 Provider Profile，切換器會直接說明這一點。
* 新會話草稿作為位置引數提示傳給 CLI，附件以路徑跟隨，因此 Agent 從你已經描述的那一輪開始。
* 終端網格之外仍欠讀者的資訊記錄為觀察事實：存活、活動、Agent 自己的會話 id，以及未讀與通知路徑讀取的時間戳。`Unknown` 是一等值，因為 CLI 等待核准時聲稱空閒會誤導讀者。
* 活動從螢幕底部讀取而不是視口，向上滾動不會改變 Agent 正在做什麼；`working -> idle` 需要多次一致的掃描，因為它是觸發完成通知的依據。
* 程序結束的會話會被關閉而不是看起來仍然健康；重啟會重新提供同一份 argv、工作目錄和 Provider Profile，Profile 會重新解析，金鑰留在鑰匙串。
* 桌面端把網格包進圓角的嵌入式視窗，選擇模式時輸入框會變成終端自己的形狀；手機可以選擇終端會話並通過常規路徑附著；TUI 用與桌面端相同的投影報告活動，對無法顯示的時間線則點名桌面端。

**終端渲染**

* 搜尋覆蓋所有保留行而不只是已繪製的視口，高亮全部匹配，並用上一個 / 下一個把匹配滾進視野。
* 網格上有可拖動捲軸，支援 `Shift+PageUp/PageDown`、`Shift+Home/End`；備用螢幕裡的滾輪會變成方向鍵，全屏 Agent 因此可以滾動。
* Box Drawing 字元按筆畫繪製成相連的向量線，覆蓋粗線、雙線、虛線、圓角和斜線，表格與面板邊框跨單元格對齊。
* 隨應用釋出 `Symbols Nerd Font Mono`，私有區符號按單元格輪廓適配，消除 Agent 狀態圖示畫出的豆腐塊。
* 單元格尺寸取自字型自身的步進而不是固定的 8x18，行按 run 塑形而不是逐個字形，寬單元格保留字型步進，CJK 仍佔兩列。
* 連字是偏好項，純 HTTP(S) URL 點選開啟，雙擊或三擊選擇單詞或整行。
* 應答 OSC 52 剪貼簿讀寫、OSC 0/2 標題、OSC 4/10/11/12 顏色查詢，以及 1005、1015、1016 三種滑鼠上報；新增終端背景不透明度，主題墨色抬到最低對比度，同時保留程式自己的真彩色。

**MCP 送達與桌面端**

* 終端模式 CLI 通過各自讀取的附加啟動輸入收到 MCP 伺服器：Claude Code 與 CodeBuddy 用 `--mcp-config`，Copilot 用 `--additional-mcp-config`，Codex 用 `-c` 覆蓋，OpenCode 用 `OPENCODE_CONFIG_CONTENT`，Hermes 用受管作用域，Cline 用 `CLINE_MCP_SETTINGS_PATH`，pi 用程序環境。
* Provider 投影遷移 Agent home 時，真實 home 裡的伺服器會被重新宣告，不會丟失。
* 憑據不進 argv：檔案在按會話建立、隨會話刪除的目錄裡且權限為 `0600`，Codex 收到的是環境變數名而不是值；建立、重啟和崩潰恢復時都會重新生成。
* Cursor、Gemini、Grok、Kimi Code 和 Devin 沒有按程序的 MCP 輸入，因此終端模式下兩個工具面板會顯示為不可用，而不是宣稱可用後靜默丟棄。
* 側欄會話過濾改為多選集而不是單一姿態，第二個過濾會加寬列而不是清空它；專案內會話可以按建立、更新、標題或手動順序排序，置頂會話留在上方獨立分組。
* `@` 檔案提及列表裡輸入路徑會直接瀏覽該目錄，大工作區裡深層目錄也能到達。
* 每個 Agent 的委派行保留自己的執行環境配置，由該行的編輯按鈕選擇，優先於預設來源和 Agent 上次使用的組合；它不會跟隨最後一次會話選擇，因為委派是另一個決定。
* 電腦操控面板在 Agent 開始驅動時浮出，不搶鍵盤，有獨立的預設開啟設定；被拒絕的呼叫不會彈出面板，已在螢幕上的面板保持不動。
* 不屬於任何專案的會話在側欄、右鍵選單、新建會話選擇器和搜尋裡讀作 **臨時會話**，綠色火花按規則解析而不是存成預設圖示。
* 新建會話頁面可以提供 Adapter 仍在下載的 Agent，脈衝畫在 Agent 自己的標記輪廓裡，頂部中央的卡片指向配置中心；下載完成後同一個按鈕會立即建立會話。
* 傳輸切換器移出輸入框，放到工作區行的最遠端，因為“誰擁有介面”不是另一個“在哪裡執行”；沒有終端模式的 Agent 會完全隱藏它。
* 輸入框佔位文字說明快捷短語、引用和歷史，`@` 彈出層把會話引用畫在獨立標籤頁；編輯器查詢欄在總覽標尺上標出每個命中，關閉查詢欄會清掉標記。
* 執行環境失敗以頂部輕提示到達，一個 Agent 的失敗讀作一條提示並帶可複製詳情，失敗的回合不再在輸入框的錯誤條裡重複。

**移動端與 TUI**

* 減少動效到達 gpui 自己的標誌，詢問上下文的套件元件停止動畫，游標在主題與輸入框繪製的基礎層裡都保持靜止。
* 開啟的會話保留自己的工作區與對話：先按會話行重定向導軌再讀快照，讀取失敗不會把上一個會話的檔案、改動和終端留在新頁面下。
* 不得不切掉即時回合的時間線視窗會在沒有回合帶的情況下重試，三個殼都安裝連續的視窗，而不是在從未空過的會話上畫“還沒有訊息”。
* 手機終端的 Backspace 能到達 shell：IME 接收器保留一個空格，並從它轉發的變更裡重新播種，按住或快速 Backspace 會按真正要被編輯的文件計算。
* TUI 在執行環境探測應答後重新整理執行選項，遲到的探測不再讓頁面停在舊目錄上。

## 效能

* 終端網格按文字、樣式和尺寸快取塑形後的行，只通過預繪製快取重塑受損行，並按 run 繪製每一行而不是逐字定位。
* 調整視窗大小會立刻填滿窗格，而不是等往返結束才更新；整趟繪製被裁剪到網格自己的內容遮罩。
* 配置中心寫入、Provider 探測、路由組儲存、閘道器讀取和終端啟動 / 重啟都移出幀執行緒，並有源檢查在跨執行緒語句寫錯時失敗。
* 電腦操控驅動在空閒五分鐘後停止：先 `stop` 讓它移除自己的 socket，不離開再殺掉；只停止本客戶端啟動的守護程序。
* 幀泵在每次捕獲前檢查接收者是否仍在，無人觀看時自行退休並關閉通道；失敗的捕獲以倍增延遲重試，上限十秒。
* 短命的驅動子命令領導自己的程序組，超時會殺掉整組，超時不再留下等待守護程序的孤兒。
* 游離的 Agent 守護程序按執行內容回收：候選由 init 或使用者的 `systemd --user` 接管，命令列指向 `<home>/acp-agents/agents/<agent>/` 下的檔案；只有同一 Agent 在任何地方都不再掛有程序並持續兩分鐘後才結束它。

## 內部、建構與文件

* 版本號升到 `0.1.0-rc.10`；資料庫模式從 87 到 88，會話行新增 `transport`，並新增 `session_terminals` 關聯表。
* 工作區升級到 `gpui-kit` `0.9.0` 與 `gpui-pre` `0.3.11`；預設主題的 diff 狀態色跟隨套件新的綠 / 琥珀 / 紅家族並新增 `deleted` 色。
* 內建 Symbols Nerd Font 登記為已稽核字型輸入，與其他內嵌字型走同一套來源門。
* Agent 固定版本移到各通道釋出的版本，包括 Claude `0.101.0`、Codex `2.5.0`、OpenCode `2.2.6`、Cursor `2026.11.05`、Gemini `0.67.0`、Grok `1.0.78` 和 Kimi `2.5.2` 等，各自保留上一個版本作為相容下限。
* `_session/steering` 接受 `queued` 與 `startedNewTurn` 作為 Agent 已擁有文字的答案，避免同一訊息被提交兩次。
* 使用者可見文字不再被替換成 `[redacted-sensitive-output]`：廠商拒絕、權限標題、模型 id、閘道器與瀏覽器帳本、型別化表單值和 Provider 端點都保留，金鑰引用仍是儲存邊界。
