## 亮點

* **目標（Goal）成為會話的一部分，而不再是記錄裡的一列** — Vibex 現在把 ACP Agent 本就發佈的目標資訊——通用的 `_meta.goal` 擴充和 Codex 舊的 `_meta.codex.goal` 命名空間——歸一成同一套模型，每次變化都存成一條目標時間線條目，並且會把回合之外到達的目標狀態變化推送出來，不再丟棄。目標從記錄裡移到輸入框上方的固定欄，緊接在佇列訊息欄下面，顯示階段、目標和 Agent 自己上報的統計；只有轉接器明確宣告支援時，才會出現 **Edit goal**、**Pause goal**、**Resume goal** 和 **Clear goal**。鉛筆圖示會在原處編輯目標，並透過目標控制而不是輸入框重新下發；被阻塞或額度用盡的目標現在也能清除，而以前只有進行中和已暫停的目標才有清除（`f90d55e`、`b7496f5`、`cd33868`、`f9afb09`）。
* **預覽面板可以獨立成窗，全螢幕也不再吞掉整個工作台** — 面板標題列新增了彈出按鈕，把多標籤預覽面板轉移到獨立視窗，停靠按鈕則把它收回來；面板實體始終沒有易主，所以開啟的標籤、編輯緩衝區和終端都會跟著走，並且同一時間只存在一個面板。關閉獨立視窗會把面板交還工作台欄，而不是把它關掉；關閉面板則會關掉它的視窗。以前全螢幕會蓋住整個外殼，側欄和右側欄都會消失；現在全螢幕把工作台欄交給面板，兩者都保留原來的位置、寬度和活動欄。工作台設定裡可以選擇預覽開啟的位置——預設內嵌，或獨立成窗（`ebf868d`、`e9737b5`、`a877bf9`）。
* **會話搜尋升級為工作台命令面板** — 側欄原本只能搜會話的搜尋框改為基於介面工具包的命令面板，入口也從某個專案的工具列移到標題列、緊接在執行環境控制項之前，因此在任何位置按 Cmd-K 都能開啟。一次輸入會同時給出三組結果：會話（標題和訊息內文，走已有的背景索引，開啟會話並跳到命中的那則訊息）、設定項（開啟設定並定位到對應分區、高亮那一列）和快速操作（註冊在工作台上的真實 Action，因此每一列都會顯示快捷鍵，鍵盤和選單裡也能觸發；前置條件不滿足時顯示為無法使用而不是沒有反應）。輸入非空時按 Esc 先清空，再按一次才關閉（`f7c1ab3`、`7341c1b`、`c8f7f4b`）。
* **更新會自己下載、結束時安裝，並說明改了什麼** — 在 **Update prompts** 旁邊新增了 **Automatic updates** 設定：開啟後一發現新版本就立刻下載，否則 Vibex 會先詢問並等待確認。原本一閃而過的版本提示改為標題列箭頭下方常駐的圓角面板，顯示下載進度和安裝操作，底部還能開啟 **About**；如果沒有手動安裝，已下載的更新會在結束時安裝。**About** 現在會顯示該版本的版本號、發佈時間、下載大小，並把發佈說明渲染成 Markdown；沒有更新時則回退到目前安裝版本對應的發佈說明，因此這張卡片總能回答你正在執行或即將執行的是什麼（`0ed31c2`、`9b252a7`、`12605e3`、`642eefd`、`905c894`）。
* **佇列訊息可以「引導」正在執行的回合** — DeepSeek Harness 0.4.32 宣告了 `_meta.steering.supported` 並接受 `_session/steering`，可以把使用者訊息注入正在執行的回合；Vibex 之前兩者都忽略，佇列訊息只能先取消目前回合才能送達繁忙的 Agent。現在 Vibex 會記錄這項宣告，只對協商成功的 Agent 提供「引導」操作，其他 Agent 仍然回退為「打斷並重送」。投遞方式會記錄在使用者訊息的時間線條目上（`prompt`、`steer`、`resend`），因此記錄裡能解釋回合為什麼中斷；當後面已經存在更新的回合時，舊回合會標記為被取代——它的即時狀態、執行時長和串流列的展開都會停止，但已經產生的列仍然可見並保持展開（`b99920f`、`dbab0ba`、`b866300`）。
* **時間線不再為整個會話逐幀買單** — 時間線按回合虛擬化，也就是說一個虛擬列就是一整個回合，而展開的回合每一幀都會重建、佈局並繪製它的每一條程序列；跑了幾個小時的會話就是一個擁有數百列的回合。開啟 **Expand reasoning by default** 後，每條推理列會變成兩個 Markdown 檢視而不是一列截斷文字，桌面端因此從 60 fps 掉到 30，版面穩定前還會掉到 12。現在展開的推理列只保留一個 Markdown 檢視，投影快取按展開的回合而不是按螢幕大小分配，版面指紋也做了記憶化；回合的程序區改為視窗化繪製，資料夾的會話列同樣視窗化，不再為每一列重新掃描資料夾的會話清單（`7c5aa8c`、`2dedcde`、`01c823c`、`40f51b8`）。
* **外觀內建二十套配色，主題也終於涵蓋到每個控制項** — 外觀從十套內建配色增加到二十套：新增五套淺色（Rosé Pine Dawn、Everforest Light、Ayu Light、One Light、Kanagawa Lotus）和五套深色（Rosé Pine、Everforest Dark、Ayu Dark、Dracula、Kanagawa Wave）。每套都在共享 token 源的 67 個角色模型裡編寫，新增配色的次要文字會沿自身色相調整，直到在頁面和弱化底板上都達到 4.5:1 的對比度。另外，介面框架在每次切換主題時都會重新載入自己的中性色板，導致開關、分段標籤、描邊按鈕、捲軸、載入骨架和文字選取的顏色在帶色調的主題裡一直是框架內建的灰色；現在主題橋會把框架剩餘的每個 token 都用目前主題填滿（`1556492`、`d29c59e`、`5e2af95`、`a7b5fa2`）。
* **模型供應商編輯器圍繞拉取到的模型目錄重建** — 探測到的模型現在只會填充選擇器，不再自動寫入設定：勾選一列會把這個模型加入草稿，取消勾選會移除它但保留已宣告的能力，重新勾選即可還原；手動輸入的 id 也仍然可以加入清單。選擇器是唯一的模型清單，右欄顯示目前點選那一列的可編輯欄位，而不是把清單再重複一遍並在每一列放一個編輯按鈕；選取狀態按模型 id 追蹤，因此重新命名後右欄仍然停在正在編輯的模型上。已儲存的供應商金鑰會以遮罩形式回填到編輯器，並可用眼睛圖示顯示；沒有改動過的欄位不會改寫已儲存的值（`4848f52`、`46f7990`、`8df655b`、`27ac399`、`a52e213`）。
* **輸入框記得你送過什麼，編輯過的檔案會自己儲存** — 在輸入框裡按上下方向鍵可以翻出目前會話早先的使用者訊息，不用重新輸入就能再次傳送；上鍵只在輸入框為空時開始，往翻出的訊息裡輸入會結束這次翻閱，因此編輯不會被舊草稿覆蓋，下鍵逐步回到最新，越過最新則還原開始翻閱時的草稿。編輯過的緩衝區不再需要明確儲存——停止輸入一段時間（預設 1000 毫秒）後，或編輯器、視窗失去焦點時就會寫回；工作台設定裡提供 **Manual** 模式還原只手動儲存，並可調整閒置延遲。全螢幕輸入框也改為整寬可編輯；它此前仍沿用摺疊狀態下的兩到八列高度上限，導致大約八列之後全是點不到的死區（`f477b4c`、`65bd62b`、`fdc87bc`）。

## 新功能

**目標**

* 目標狀態歸一成同一套模型並持久化為目標時間線條目，回合之外到達的狀態變化會被推送而不是丟棄；ACP 轉接器會解析初始化宣告、`session_info_update` 中的目標、`_session/goal`，以及舊的 `_codex/session/goal_control`（`f90d55e`）
* 桌面端和行動端都有帶暫停、繼續、清除門控和本地化文案的目標卡片（`f90d55e`）
* 輸入框上方的固定目標欄緊接在佇列訊息欄下面，顯示階段、目標和 Agent 統計，記錄裡不再投影目標列（`b7496f5`）
* 目標可以在欄內原處編輯；儲存時透過 ACP 控制參數和 mock agent 下發 `set` 或 `edit` 目標控制（`cd33868`）
* 被阻塞或額度用盡的目標也能清除，不再只限於進行中和已暫停（`f9afb09`）
* `/goal` 使用者訊息保留自己的氣泡，並帶有一個幽靈目標圖示，提示這是目標指令（`b7496f5`、`cd33868`）
* 目標徽標掛在氣泡下邊緣的反應區，和佇列投遞用的是同一枚膠囊、目標徽標靠內，因此內文保持完整寬度，換行位置也和一般訊息一致（`23d25f8`）

**更新**

* **Update prompts** 旁的 **Automatic updates** 設定在開啟時一發現新版本就下載，否則先詢問並等待確認（`0ed31c2`）
* 標題列箭頭下方的常駐圓角面板顯示下載進度和安裝操作，底部可開啟 **About**；沒有手動安裝時，已下載的更新會在結束時安裝（`0ed31c2`）
* **About** 顯示版本號、發佈時間、下載大小和渲染為 Markdown 的本地化發佈說明，並帶有狀態標籤、描述和唯一可執行的下一步操作（`9b252a7`）
* 沒有更新時，同一張卡片會顯示目前安裝版本的發佈說明；該版本早於發佈說明機制時則不顯示（`642eefd`、`905c894`）
* 發佈流水線會把標記提交裡的 `docs/operations/release-notes-v<version>.md` 暫存為 `vibex-release-notes.md`，檔案缺失或沒有 `## English` 段落時直接讓發佈失敗；桌面端在限定大小和更短逾時下從已驗證的標籤取得它，並按介面語言選擇段落，依次回退到通用中文和英文（`12605e3`）

**預覽視窗**

* 把多標籤預覽面板彈出為獨立視窗，也可以停靠回來；開啟的標籤、編輯緩衝區和終端都跟著面板實體走，同一時間只存在一個面板（`ebf868d`）
* 關閉獨立視窗會把面板交還工作台欄而不是關掉它，關閉面板則會關掉視窗；獨立視窗透過外殼同一套編輯器操作保留 Ctrl+S 和跳至指定行（`ebf868d`）
* 全螢幕把工作台欄交給面板，側欄和右側欄保留位置、寬度和活動欄，右側欄也保留自己的拖曳調整寬度手柄（`e9737b5`）
* 工作台設定決定預覽開啟的位置——預設內嵌，或獨立成窗；標題列的彈出和停靠按鈕寫入同一項設定，還原版面時會在執行環境就緒後按設定重新開啟預覽（`e9737b5`）

**全域搜尋**

* 在任何位置按 Cmd-K 都能開啟工作台命令面板，入口位於標題列、緊接在執行環境控制項之前（`f7c1ab3`）
* 一次輸入同時檢索會話（標題和訊息內文，開啟會話並跳到命中處）、設定項（開啟設定並定位分區、高亮對應列）和快速操作（真實 Action，顯示快捷鍵，前置條件不滿足時無法使用）（`f7c1ab3`）
* 面板使用大號控制項尺寸繪製自己的輸入框，在會話、設定和快速操作三組之間畫分隔線，並修正了方向鍵高亮移動和 Esc 先清空再關閉的行為（`7341c1b`）
* 會話搜尋只索引和高亮對話文字——使用者訊息、Agent 回答、推理和計畫——並且只給命中的關鍵詞著色，目前命中顏色更重，逐條跳轉時會捲動到可見位置（`c8f7f4b`）
* 面板內容與邊框之間留出一個間距，捲軸也不再壓在會話時間和快捷鍵提示上（`baa227b`、`a4cec5b`）
* 該命令在入口提示和快捷鍵表中統一稱為 **Global search**（`7341c1b`）

**輸入框與會話**

* 在輸入框裡用上下方向鍵翻出早先的使用者訊息；預留位置提示會在已有的命令、提及和技能觸發詞旁標出這兩個鍵（`f477b4c`）
* 全螢幕輸入框整寬可編輯，摺疊狀態的輸入框仍維持兩到八列的成長範圍（`fdc87bc`）
* 自動儲存會在停止輸入一段時間（預設 1000 毫秒）後，或編輯器、視窗失去焦點時寫回編輯過的檔案；提供 **Manual** 模式、工作台設定裡可調的閒置延遲，並在關閉標籤時沖刷尚未寫回的編輯（`65bd62b`）
* 引導或打斷回合的佇列訊息會記錄在使用者時間線條目上，並在氣泡邊緣顯示帶文字說明的反應標記——引導為主色，重送為警告色——因此上方被打斷的回合不靠顏色也能看懂（`dbab0ba`、`b866300`）
* 原生引導只對宣告了 `_meta.steering.supported` 的 Agent 提供「引導」操作，其他 Agent 以及引導失敗或需要提示的情況一律回退為打斷並重送（`b99920f`）
* 停在權限確認或追問上的會話不再顯示載入轉圈，而是在會話列和彙總它的工作區列上顯示警告色的圓圈問號行動提示，並帶有本地化提示文字（`fe89fb8`）
* 捲動到底部的控制項改為浮在時間線上方，不再用自己的高度壓縮可視區域（`09b98e5`）
* 會話預覽導軌只為帶使用者訊息的回合編號，自動繼續的回合會併入觸發它的回合，只有繼續回合的對話不會掛載導軌（`130a70c`）

**Agent 與 ACP**

* DeepSeek Harness 在預備附件視窗期間不再遺失斜線命令目錄，會話建立前輸入框也會顯示固定的預置目錄（`/status`、`/model`、`/compact`、`/goal`、`/permission`、`/plan`、`/feedback`）（`aec42c2`、`dc23ae4`）
* DeepSeek Harness 的 `danger-full-access` 權限開關不再每次嘗試都失敗（`da3bffc`）
* DeepSeek Harness 的目錄版本固定到 0.4.32，也就是宣告支援引導的版本（`b99920f`）

**模型供應商編輯器**

* 從拉取到的目錄中挑選模型：勾選一列加入草稿，取消勾選會移除但保留已宣告的能力，手動輸入的 id 也能加入清單；寬視窗下兩欄並排，窄視窗下上下堆疊，各自獨立捲動（`4848f52`）
* 選擇器是唯一的模型清單，右欄顯示點選列的可編輯欄位，供應商不提供的模型會給出加入它的命令，選取狀態按模型 id 追蹤（`46f7990`）
* 已儲存的供應商金鑰以遮罩回填，可用眼睛圖示顯示；未改動的欄位不會改寫已儲存的值，「清除」是明確命令（`8df655b`）
* 編輯器重建為帶說明條的面板、可捲動主體和各自的底欄，目錄、介面、推理和思考等級分組共用同一種標籤樣式（`27ac399`）
* 編輯器的表面更安靜：身分與連線區保持內容高度，各欄改為普通列，列狀態用一層淺色而不是實心膠囊表達，「測試連線」與取消、儲存一起排在尾端（`a52e213`）

**配對與遠端**

* 連接手機裝置對話框新增「已配對裝置」模式：狀態、權限、最後上線時間、帶確認的撤銷、重新整理、數量統計和空狀態；對話框開啟時載入註冊資料，配對或撤銷後重新載入（`3901a8a`）
* 已配對裝置清單每頁六台，只有註冊資料分頁時才顯示翻頁器，並顯示「第 13-18 台，共 24 台」的說明；撤銷導致目前頁面為空時會自動收攏頁碼（`d26c2de`）

**設定與外觀**

* 設定頁可以宣告帶標籤的分組，每組有小標題、可選的全寬控制項和自己的面板，組與組之間的間距大於組內（`c3b9182`）
* 外觀模式用預覽卡片選擇，卡片會用該模式解析出的配色畫一個微縮工作台；跟隨系統會把卡片分成兩半，選取卡片保留主色邊框和名稱，卡片本身是可存取的單選按鈕（`5e2af95`）
* **Light theme** 和 **Dark theme** 改為下拉式選單，收起狀態和選單裡都顯示色塊和主題名（`a7b5fa2`）
* 新增十套內建配色，總數達到二十套（`1556492`）
* 設定裡的快捷鍵以鍵帽形式繪製，介面工具包無法解析的按鍵仍保留原始文字作為回退（`a262799`）
* 所有快捷鍵名稱和分組都會本地化到目前語言，字串表現會帶上解析時使用的語言，而不是去讀處理程序層級的語言設定（`f1367ec`）
* Agent 通知開關從 **General** 移到 **Session** 設定（`ca1eec1`）
* 目錄選擇器可以給專案目錄加星：加星的資料夾會作為獨立分組出現在「位置」欄，最新的在前、最多十二個，在列內或欄內再次點擊即可取消（`16f798b`）

**工作台與編輯器**

* 載入中的介面改為按真實清單已有的列高繪製載入骨架，而不是轉圈或誤導性的空狀態，判定條件固定在原始碼契約裡（`96af670`）
* 桌面端和行動端的空狀態改用工具包的空狀態元件，替換掉七個手寫輔助函式和十幾處內聯實作（`695c1ae`）

## 修復

**桌面端——版面、視窗裝飾與可讀性**

* 設定對話框和命令面板的內容保持在圓角內：介面工具包會把子元素裁成方形，因此兩者自己把內容表面也做成圓角，位置在邊框圓角內一像素（`e5e0092`、`85c3f37`）
* 命令面板的列、輸入框和底欄與邊框之間留出一個間距，捲軸軌道預留在兩列高的列內，時間和快捷鍵提示不再被滑塊壓住（`baa227b`、`a4cec5b`）
* 提交內文真正摺疊為三列：原先的截斷會按換行分別計算，導致分段內文整段顯示；現在預覽只投影開頭的邏輯列，並去掉重複的標題（`2d4ebfe`）
* 檔案預覽標題列改為扁平樣式，編輯圖示換成鉛筆（`5bf7818`）
* 預覽標籤的操作按鈕改為標準的小號圖示按鈕尺寸，懸停時畫出圓角矩形；單擊開啟的預覽標籤使用內建的無襯線斜體（`8d49875`）
* 用量範圍控制項與分段條保持一致——填充軌道、抬起的頁面色膠囊，沒有描邊（`7910b20`）
* 設定裡的字型選擇改用可搜尋清單，在浮層裡輸入會真正縮小字型族清單，而不是接受輸入卻毫無反應（`5a8f729`）
* 快捷鍵對話框的輸入框在重繪後仍可編輯：輸入框實體原先在對話框建置函式裡建立，而該函式每次重繪都會重新執行，導致輸入過程中焦點控制代碼和文字被替換；被拒絕的按鍵組合現在也會在對話框內顯示原因（`1b0d087`）
* 切換會話不再讓輸入框卡住：fork 的視窗級操作鎖原先只在沒有會話被宣告時才釋放，正常路徑下會讓所有傳送按鈕一直轉圈，新會話首頁也失去執行環境控制項，直到重新啟動才還原；現在 fork 結算時會無條件釋放該鎖，其他取得方也套用同一規則（`a25c532`）

**桌面端——會話、側欄與時間線**

* 串流程序單元會在實測高度和估算高度之間逐幀跳動，因為它的內容修訂號每來一塊資料都會前進，導致執行中的會話在跟隨底部時時間線上下抖動；現在串流單元不會低於上一次實測高度（`1115b36`）
* 視窗化程序執行的兩處遺留接線補上：共享的單元走訪透過它自己算出的配對旗標讀取顯示偏好，虛擬清單的回合渲染器也會拿到該次執行解析回合時使用的索引（`1999ed2`）
* 側欄分組列重新成為展開／摺疊控制項：專案列和工作區列可以收起和展開而不切換焦點，撤銷了本週期早些時候加入的「點擊分組即切換會話」行為（`72b798d`）
* 點擊側欄的專案列或工作區列不再切換會話，新會話首頁仍會直接啟用工作區（`72b798d`）

**桌面端——Agent 回合呈現**

* 引導和重送訊息的投遞標記從氣泡內文裡的內聯圖示移到氣泡下邊緣反應區裡的純圖示幽靈按鈕，顏色加在字形上，因此懸停時色相不會遺失，文字說明保留在提示和無障礙名稱裡（`b866300`）
* 等待權限確認或追問的會話顯示行動提示圖示而不是進度轉圈，錯誤狀態也不再被樂觀回合掩蓋（`fe89fb8`）
* 自動繼續的回合不再佔用會話預覽導軌的位置，也不會在錯誤上方預覽一個孤零零的回合編號（`130a70c`）

**Agent 與 ACP**

* 只改狀態的會話更新（包括可用命令和設定項更新）現在會在自己的確切圍欄處生效，即使附件仍處於預備狀態；此前遺失 DeepSeek Harness 目錄會讓已提交的附件報告一個權威的空目錄，從而壓掉會話前的回退目錄，只要該附件仍然有效，輸入框的斜線命令就一直不顯示（`aec42c2`）
* 設定項更新不再作用於預備狀態的附件：DeepSeek Harness 橋在回答模式切換之前先發佈設定項更新，抬高了執行環境設定修訂號，使確認邏輯把自己判為過期，因此每個新建的 DeepSeek Harness 會話的 `danger-full-access` 開關都會失敗（`da3bffc`）
* 剩餘目標 token 用零下限截斷，線上 token 只在 camelCase 邊界摺疊，因此全大寫的 `RESUME` 仍是一個 token，而不會變成 `r_e_s_u_m_e`（`acc5026`）
* `GoalPhase` 改為衍生預設值，不再手寫實作（`eebcaad`）
* 刪除了未使用的目標卡片繫結和未使用的目標階段匯入（`3a6a38a`、`f35bddc`）

**Markdown 與渲染**

* 串流思考內容會把解析中的回退塊交給程式碼渲染器，導致每條推理列先顯示成帶複製按鈕的邊框程式碼卡片，然後突然變成內文；現在字面塊按可選取的自動換行文字渲染，高度估算方式也一致，與行動端對齊（`c5f1364`）

**主題**

* 介面框架自己的中性色板會用目前主題填滿，帶色調的外觀不再把開關、分段標籤、描邊按鈕、捲軸、載入骨架和文字選取畫成框架內建的灰色（`d29c59e`）

**本地化**

* 新建會話位置控制項裡不再出現光禿禿的英文「Worktree」與已翻譯選項並排；兩種中文現在都會翻譯它（`34585b4`）
* 快捷鍵名稱不再硬編碼英文，此前快捷鍵頁、設定搜尋和命令面板快速操作會同時出現中英混排（`f1367ec`）

**建置、發佈與相依性**

* 發佈上傳最多重試三次，並在兩次嘗試之間清理殘留的 release：`gh release create` 會先建草稿再並行上傳資源，而它的傳輸層重試會重複使用資源名卻沒有刪除中斷的上傳，於是 GitHub 回傳 HTTP 422，gh 把整個草稿還原——rc.4 的發佈正是在 Android arm64 APK 上這樣失敗，且沒有留下任何 release（`e115770`）

## 效能

* **展開的推理列** — 開啟 **Expand reasoning by default** 時，桌面端從 60 fps 掉到 30，版面穩定前還會掉到 12。現在展開的推理列只保留一個 Markdown 檢視：展開標題只是一列截斷的樣式文字，第二個檢視卻為每一列多買了一套元素樹、帶 key 的狀態項目、選擇緩衝區和命中區域；投影快取按展開的回合而不是按螢幕大小分配，因為原先 32 條的表在數百列的會話裡幾乎每列都落空，還會把每段內文重新複製成新的分配；版面指紋也針對廉價的回合級形狀鍵做了記憶化（`7c5aa8c`）
* **Markdown 檢視狀態** — 選擇緩衝區每一幀都會把整篇文件拼成一個字串，並且無論是否有選取內容，都為每個文字片段格式化一個元素 id；現在改為按需產生，片段 id 來自每個檢視只建置一次的前綴。塊虛擬化閾值原本是 24 塊或 16 KB 配 8 塊，導致典型的推理列總是走完整渲染路徑；現在閾值調到了虛擬化真正划算的位置。不超過 16 KB 的非串流文件原先會在建立檢視時於主執行緒解析，而每個推理列都要建立一個檢視，於是卡住那一幀；現在思考內容超過很小的預算就走背景解析，回答和文件預覽仍保留更大的預算（`2dedcde`）
* **回合程序列** — 一個虛擬列就是一整個回合，因此展開的回合每一幀都會建置並繪製所有程序列；現在回合的程序區透過視窗化執行繪製，預留這些單元佔用的高度，只建置視口內可見的部分。執行和高度估算共用同一次走訪，實測單元高度按單元 id 和修訂號儲存；尋找列的待定命中即使落在視窗之外也會建置，因此仍能捲動過去（`01c823c`）
* **側欄會話列** — 擁有數百個會話的資料夾每一幀都會建置、佈局並繪製所有列，而且每一列都要重新掃描資料夾的會話清單來解析自己，導致幀開銷隨資料夾大小而不是螢幕列數成長。現在每一段連續的會話列透過一個元素渲染，只建置視口能看到的列；列按索引從快取投影中解析，選取的列即使捲出視口也會建置；舊資料夾遷移在沒有舊格式資料夾時提前返回，並只索引一次工作區（`40f51b8`）
