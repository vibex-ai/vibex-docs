## 亮點

* **Vibex TUI：整個工作台進得了終端** — 會話、串流 Markdown、核准、佇列、設定與配對都搬進了終端，介面是一列全寬橫帶並隨視窗自動重排，因此沒有最小尺寸這回事。它隨每個桌面安裝包一起發佈，在 SSH 和 tmux 裡都能用，既能自己啟動執行環境，也能附著到桌面端正在運行的那一個。
* **Agent 團隊化協作** — 委派不再是一問一答：任務在回合結束後可以保持開啟，你在同一個子會話裡追加跟進，再決定接受或取消。側欄的所有權樹和會話組的團隊狀態列會同步顯示工作推進到了哪裡。
* **訊息定時傳送** — 給訊息挑一個整點，它就留在佇列裡等你。定時跨重啟保留，在彈出面板裡編輯，也能看到另一個客戶端正在持有的傳送。
* **自訂工作台背景** — 在工作台後面放一張自己的圖，靜態或動圖都行，填充、適應或拉伸，再加一層可調遮罩，文字在任何背景下都讀得清。圖片按專案圖示同樣的方式匯入，存放在執行環境 home 下。
* **Agent 電腦操控** — 在你授權之後，Agent 可以接管宿主機的桌面。它在設定裡安裝和管理，有獨立的浮動外殼與在地化面板，驅動的主控台視窗不會跑到你的桌面上，總開關隨時能關。
* **行動端重建，對齊桌面端** — 手機端跟隨桌面端的模型：會話組與所有權樹、帶檔案樹和差異的右側欄、定時傳送、worktree、目標、觸感回饋，以及重建的配對與首次執行流程。
* **自動更新預設開啟** — 桌面端預設自動更新，既有安裝會升級到這個行為；iOS 在模擬器包之外發佈未簽名的真機 IPA，安裝者用自己的 Apple ID 重新簽名即可。

## 新功能

**Vibex TUI（終端版）**

* 介面由一列全寬橫帶組成——狀態、時間線、回合狀態、輸入框、快捷鍵列——取代了原來的分欄格線，任意終端尺寸下都自動重排，因此沒有最小尺寸，也不再提示「視窗太小」（`1aa9e4d5`、`dedafc55`、`eb95f780`）
* 時間線把 Markdown 邊串流邊就地繪製，強調、程式碼和表格按真實語法繪製並有一整套顏色階層，而不是白底白字（`e9b05a27`、`2acf4d03`、`10507286`）
* 結束的回合折到 `▸ Worked for 12s` 分隔線後面，這條線本身就是開關；折疊展開時重新量列高，執行中展開也不會頂掉讀者所在的位置（`eb4ed877`、`f39d5163`、`13ba42e6`）
* 捲走的輸入訊息釘在視埠上方且只畫一遍，`/` 支援智慧大小寫正規表達式搜尋，捲動到頂端會載入更早的歷史（`ae610ee3`、`28dda9e3`、`71fee6c1`、`f4d6e9a2`）
* 可以用滑鼠選擇時間線文字並透過 OSC 52 複製，SSH 和 tmux 裡都能用；選取範圍涵蓋的儲存格會被完整複製（`143b82fb`、`39a59f3b`）
* 輸入框支援 readline 式編輯——復原、kill buffer、按詞移動，草稿內可以選擇和取代，Shift+Enter 插入換行而不是傳送（`5897bd40`、`114b7b30`、`63b44766`）
* 長文字貼上收成 `[Pasted: 42 lines]` 晶片並可以預覽其中的內容，已傳送的訊息可以用方向鍵召回（`864cba66`、`499a7ea5`、`9503ed2e`）
* 剪貼簿、貼上和拖入的圖片都變成晶片，按終端自身的解析度繪製，SSH 連線下也能貼上圖片（`260a9b6e`、`94b1a22b`、`beacbd90`）
* `/`、`@`、`$` 開啟桌面端自己的補全面板——命令與 Prompt、工作區檔案與 Agent 委派列表、Skill；抽屜在行中開啟，Enter 取走它給出的那一列（`d5f7b041`、`f2259a44`）
* Agent 的請求就地呈現：提問開在輸入框橫帶上並用真正的表單回答，核准是頁面上的卡片；停靠面板集中放 Agent、計畫和被持有的訊息（`2cd7cb59`、`918e8a21`、`0300847d`）
* 回合軌只按回合打刻度，視埠涵蓋的每個回合都會點亮；捲動到底部會停住並恢復跟隨（`1b5704e3`、`627bf5c3`、`6699797c`）
* 主題、語言和最近命令會被記住；`?` 快捷鍵一覽按分組排列，按鍵綁定可以直接在介面裡編輯，衝突會被拒絕（`c4d28c0e`、`4a49d297`、`4f9ef96c`）

**TUI 的會話、執行環境與配置中心**

* 會話列表按桌面端側欄的排布繪製，列上直接給重新命名和刪除控件；可以置頂、分組和手動排序，分組段落帶摘要（`b4e6b30c`、`2f7d75f2`、`b4dc89a8`）
* 讀不到桌面端排布時，你自己的置頂與順序儲存在 `~/.vibex/tui-sidebar.json`（`31c9e9bb`）
* 委派的子會話嵌在會話列表裡，用樹狀導軌畫成分支，分支止於子會話的 Agent 標記，也不會從沒有會話的上方長出一條豎線（`2faf67a7`、`42297e47`、`77f72704`）
* 另一個客戶端讀到或刪掉的會話會同步過來：已讀點消失，刪除的列、開啟的頁面和各自的會話狀態一起清掉（`7025a3f4`、`68aa778c`、`f364a0c4`）
* 客戶端開啟就是當前目錄下的新會話輸入頁，目錄和上次使用的執行環境都已經填好，`Esc` 在輸入頁與會話列表之間切換，送出第一條訊息後直接落到該會話（`4c29a366`、`34dd24c2`、`d9397935`）
* 新建會話在頁面裡完成而不是對話方塊，`Ctrl+W` 能改工作區，選中的目錄會保留；工作區選擇器開啟在頁面已經指向的目錄，Space 進入游標所在的資料夾（`359be634`、`b7eaeb7c`、`bec4918c`）
* 執行環境切換器圍繞分組、搜尋和暫存選項重建，座位顯示為本地模式或遠端模式，附著遠端座位前先連上傳輸（`46959e90`、`f6551002`、`78e34b78`、`0527d8dc`）
* 管理頁重建為桌面風格的配置中心——Agent、供應商設定、Model、MCP、Skill、Prompt、配對與遠端存取都在其中（`5460a842`）
* 列表裡的開關按下即回應，先畫狀態再等權限方確認，被拒絕時會畫回原樣；沒讀過的區域畫骨架而不是空表，讀取失敗留在發起它的區域上並給出錯誤碼和重試鍵（`7e4bc14d`、`729145af`、`898fed38`、`64df2814`）
* 供應商設定可以新建、複製、按讀者自己的順序排列，可以編輯網站、請求標頭和分協定位址，也可以清掉一個 key、固定端點、限定預設，並與其他 CLI 工具已有的設定互相匯入匯出（`95dea462`、`6e719bda`、`f0f9b1c2`、`259d7c37`、`7cf9bfab`、`7e1bce36`）
* 可以編輯一個供應商設定提供哪些 Model 和單個 Model 的設定，`y` 一次提供目錄裡的全部 Model，`z` 全部收回（`a103a9ef`、`b86bb346`、`833c6599`）
* Agent 目錄分成三段排好序並帶角標，可以發現本機的 Agent CLI、看著它安裝，也支援註冊自訂 ACP Agent（`48cb6e82`、`3a311efb`、`38596fc5`）
* Agent 帳號面板把帳號讀成一份登入方式列表，可以按方式登入並開啟憑證頁；終端方式的登入在面板裡畫出真正的終端，結束前先說明它會結束什麼（`845278ab`、`9d0e9630`、`667c6aa5`）

**TUI 的通知、Skill 與配對**

* 通知透過終端跳脫序列送達，通道按執行環境選擇：附著到桌面端時退讓給桌面端，同一個事件只從一個通道來（`bdeb8126`、`3adac8f0`、`905bcd4e`）
* Skill 市場可以分頁和收窄，卡片會說出自己的狀態（已安裝的條目提供「重新安裝」，被撤下的條目優先），安裝前先讀一遍將要寫入的說明、檔案清單和不會寫入的檔案，再問哪些 Agent 接收（`eef35bb4`、`e4cd2c08`、`2591dddd`）
* 配對頁與裝置管理合併成一頁，二維條碼畫成圖片而不是半塊字元，配對 offer 會列出並讓你選擇它攜帶的路由，關閉時把一次性代碼交回去（`5fdb096c`、`8ed48f1a`、`3c2c075e`）
* 客戶端隨每個桌面安裝包發佈——`/usr/bin/vibex`、macOS `.app` 旁、`vibex.exe`——容器裡則用 `docker exec -it <container> vibex-server tui`（`24654f20`）

**Agent 團隊**

* 委派的任務在回合結束後可以保持開啟，向同一個子會話追加跟進、接受或取消，舊的單回合路徑不受影響（`019d4f14`、`021d6324`）
* 重試會落到最初那次接受，不會覆蓋早先的工作；意圖變了則直接拒絕；只有真正結束的回合才會被接受，只有真正執行的任務才會被跟進（`642b655e`）
* 被委派的會話拿到的上下文正好是呼叫方宣告的那些，不多也不少（`019d4f14`）
* 轉發的子 Agent 標題不再跑到根會話上，Agent 會先發佈一個已結算的回合再壓縮它的串流列（`b4fd32ef`、`96d6c7ea`）
* `@` 引用選單拆成檔案和 Agent 委派兩個標籤頁，每個 Agent 設定帶上名字，因此引用指向檔案還是 Agent 一眼可辨（`46c4f918`、`85bd90e4`）

**桌面端**

* 在工作台後面放一張自己的圖：靜態圖、GIF 或 WebP 動圖，填充、適應或拉伸，還有一層可調遮罩；淺色外觀下背景會當作玻璃處理，啟動載入頁始終不透明（`e322e5e8`、`0b854ba1`、`83a21940`、`50bf639d`）
* 訊息可以定時傳送：選一個整點，定時跨重啟保留，在彈出面板裡編輯，Enter 從時間欄位確認；另一個客戶端持有的傳送也會顯示出來（`89785005`、`91c826be`、`b25c1cbb`、`979810f3`、`1e45d7f3`）
* 每個 Agent 的內建工具面板可以在 Agent 列表裡開關，啟用的工具圖示亮成綠色（`5bf529f9`、`692dd6d0`、`a7537272`）
* 專案選單提供臨時會話，側欄資料夾列新增新建會話操作，資料夾列的操作保持在一列內（`1b8111d4`、`d9216e9a`、`dc1a0883`）
* 失敗資訊和右側欄結果統一變成頂部輕提示，點擊卡片即可關掉，也可以用按鈕複製而不是靠拖曳（`0e948fc7`、`15510430`、`37ba9363`、`d6fdf4d0`、`e6fc6fd4`）
* 設定對話方塊的導覽重新分組，TUI 監聽開關從配對頁移到設定裡（`caa5c067`、`9ecfabd4`）
* 輸入框裡的終端改為開啟在底部面板，終端格線鋪滿整個工作台寬度（`3207bdb8`、`aec2c82d`）
* 會話活動指示器改成一列 V 形標記（`e89ace24`）
* 繪製後的 Markdown 預覽可以直接搜尋，開啟時把工作分攤到多個影格，大檔案預覽也改為虛擬化（`a7119836`、`df7dd245`、`1bac0ed1`）
* 時間線改讀有界視窗並支援向更早翻頁：冷開落在會話末尾，向上翻頁時把更早的歷史前置而不移動讀者所在的位置，回合預覽軌被固定在視埠上（`d727fbc6`、`ae6689ac`、`ed4feab8`）
* 執行中的思考透過一個固定視窗串流顯示（`5dd873bf`）

* 可以把本機 Chrome 設定的登入狀態匯入隔離設定，不必在新設定裡重新登入（`36a8725a`）
* Git 介面把拉取和重新整理抓取分開，拉取會把抓到的提交放進當前檢出的分支（`09dc17cb`、`aa4587d6`）

**行動端**

* 客戶端圍繞桌面端的模型重建：側欄的列、分組與標籤和桌面端一致，專案列、會話列和 Agent 標記都對齊桌面端（`edfbbeaf`、`ca7ca90f`、`f127e9c3`、`ed74f978`、`223ff22c`）
* 會話組可以在手機上建立和保留，折疊的組會說明自己藏了多少，組段落以成員開頭並畫出完整分支（`446593ca`、`1c39695e`、`88f35234`）
* 委派會話掛在桌面端的樹狀導軌下，並會說明被委派的會話正在做什麼（`3d71cd46`、`6f761aaa`、`a1086698`）

* 輸入框自帶執行環境抽屜——命令、佇列與終端補全——佇列帶一個選擇等待傳送改到哪個整點的選擇器；抽屜可以拉高以顯示更多內容，也能用手指上下拉動（`6e09e106`、`907ef249`、`5151de22`、`13b6dc00`、`21e308df`）
* 定時傳送：給訊息選一個更晚的整點入列，可以看到會話正在等待一次佇列傳送，等待的傳送能回答一個問題並說出自己的會話（`bd616ab4`、`3b1e93d7`、`3472bd3c`）
* 未送出的輸入框內容跨重啟保留，草稿和已傳訊息可以編輯、召回和分享（`88549c59`、`dbd15c75`）

* 電腦操控在設定裡安裝和管理，帶浮動外殼和在地化面板；Agent 可以驅動執行環境宿主機的桌面（`debcaa1a`、`e2d7f735`、`b3d10fec`、`4737d8a5`）
* 電腦操控的總開關以已安裝驅動為前提，剛打開開關之後啟動的會話也會拿到桌面工具（`fb06f9ab`、`0cc1dbbb`）
* 驅動的主控台視窗不會跑到你的桌面上，Windows 驅動能越過預設指令碼原則安裝；無頭執行環境也能提供 helper，獨立客戶端也有了電腦操控命令列（`f9d8ea65`、`e0a6ead7`、`8b4956d4`、`e82abfab`）
* 一個桌面端可以在同一台機器上服務客戶端——這正是 TUI 能本地附著的前提（`0d0816b5`）
* 配對視窗可以在沒有發佈路由的區域網路上開啟，已配對的客戶端可以還原或遺忘裝置（`82d8142f`、`671fc662`）
* 遠端會發佈每個受管 worktree 的狀態、定時傳送將附帶的內容、資料夾的封存視窗、會話的擱置狀態，以及執行環境自己發佈的名字（`07a60b56`、`46ab88b8`、`43f10451`、`341b6c4c`）
* 客戶端可以把訊息排到更晚的整點；過大的會話列表回應不再產生（`9cc507a7`、`82100f1c`）

**工作台與側欄**

* 按住 Shift/Ctrl 選取多列後右鍵，選單讀到的是整個選取範圍：自動繼續設成同一個值，置頂與分叉作用於每一列，刪除先確認數量（`3eef716b`）
* 資料夾列在批次模式下帶核取方塊，一次點擊就能勾選或清空它管轄的全部會話，包括多層和組內的成員，委派出的子會話仍被排除（`2bac920e`）
* 封存不再只藏在標題列：會話列選單、多選選單和批次列都能封存，因為可逆所以不彈確認，誤封存去封存頁復原（`c43ec865`）
* 會話列右鍵選單可以直接分叉這個會話，落在源會話的當前位置，而不是先要求你在時間線裡挑一個位置（`b2ce63b7`）
* 委派會話用懸停在列尾才出現的開關展開分支，開關佔位固定所以標題不會在懸停時重排，父子列共享同一套高度、圓角與狀態欄（`65834757`、`41a073d8`）
* 會話組可以整組拖曳：放進資料夾、與其他組換位、回到工作區根；拖曳組內成員則重排組內順序，拖到組外就把這個會話移出組（`e9ef0bbe`）
* 工作區列顯示正在執行的會話數，執行中的會話用點陣動效表示活動，標題帶一道微光（`6d2f9c49`、`83a9b179`、`8aa5f9f1`）
* 回合預覽軌按視埠點亮它涵蓋的每個槽位，跨回合邊界時兩個回合同時亮（`b55b81f0`、`c545d89c`）
* 冷開會話落在會話末尾：沒有游標時讀最新視窗，分頁在回合邊界切開，所以一個回合不會分幾次塞進來，回合標頭也不再顯示持續變長的時長（`0f7b88b8`、`27c7c38d`、`2f355bbd`）

* 自動繼續在沒有選取會話時也能啟動；已結束的回合會讓佇列的自動傳送放行；樂觀派發在權限方判定回合時結束（`cdc06217`、`b6b1086a`、`3ac5dfef`）

## 效能

* TUI 只重繪讀者眼前的那一面：展開的處理程序組按列開窗，視窗有自己的 overscan，一整組不再逐格全部佈局（`eac6def7`、`768c97e7`）
* 每個處理程序單元保留一棵自己的元素樹，已結束的單元複用它，不再每個影格重建（`e45b5288`、`fb567d07`）
* 工具活動組的摘要改讀以列版本與語言為鍵的有界投影表，不再每個影格重新投影每一個成員列、重新解析工具輸入（`7299a056`）
* 即時標籤測量時間線兩個影格之間的間隔，掉格時退回靜態文字，回到顯示節奏內再恢復掃掠（`7299a056`）
* 會話開啟不再分頁整個封存：按回合與位元組讀有界視窗，頁面只帶折疊活動要用的欄位，工具詳情在展開時才單獨讀，已結束的回合還把相鄰的串流分塊合併成一列（`ca7a1d62`、`e6295130`）
* 檢視在時間線填不滿視埠時繼續擴窗，不再停在一屏都不到的列數上等一次捲動（`e6295130`）
* 側欄在折疊或展開標題時跳過會話查詢，只走已有的組織結果（`f164c9fe`）
* 多選每個影格只解析一次：一份作用域對應、每個專案一份拖曳乘載，列的批次選單從同一份切片讀取（`48055044`）
* 側欄的執行提示改為在固定的 20px 畫布上逐點繪製六點環並掃掠高亮，取樣跟隨時間線的 30fps 預算——不再以 10fps 重放 TUI 的盲文影格，也不再落到字型缺少該區塊時的替換方塊上（`828749ed`、`aa705410`、`5642cf83`）
* 子 Agent 的時間線不再逐格折疊；子 Agent 側軌拿到自己的繪製邊界和按會話劃分的 Markdown 保留表（`2e89866e`、`92a7e905`）
* 保留單元只在繪製鍵變化時重建，展開或收起才觸發一次重繪，通知本身不再引起重建（`1ee6f666`）
* 每一列都有自己的 id，不再兩列共用一個元素和一份保留文字檢視，串流回答不會只剩背景塊（`5d11e308`）
* 桌面端把重繪範圍收窄到側欄與時間線，Markdown 檔案預覽改為虛擬化，開啟時把工作分攤到多個影格（`e3e0f5f2`、`1bac0ed1`、`df7dd245`）
