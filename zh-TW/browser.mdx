---
title: "內嵌瀏覽器"
description: "在隔離的瀏覽器面板中檢視頁面，並讓 Agent 讀取和操作它。"
---

內嵌瀏覽器是一個**工具面板**，和終端機、文件預覽同級。它由系統安裝的 Chrome、Chromium 或 Edge 驅動，執行在執行階段自己的隔離配置裡，不是應用外殼，也不是另一個 WebUI 產品。

人和 Agent 看到的是同一個頁面：你看到的是即時畫面，Agent 通過結構化的頁面快照和操作工具工作。這樣它點選的元素和你眼前的元素不會分叉。

## 開啟瀏覽器面板

在預覽面板的 **+** 選單裡選擇 **瀏覽器**，或新建一個瀏覽器標籤。位址列支援：

- 輸入完整地址並回車。
- 輸入關鍵詞，用 **設定 → 瀏覽器** 裡選擇的搜尋引擎搜尋。
- 後退、前進、重新載入，以及在新標籤頁中開啟連結。

瀏覽器面板和檔案、差異、終端機共用同一套標籤和分欄。可以把面板彈出為獨立視窗，或全屏顯示。

<Note>
  內嵌瀏覽器需要本機安裝 Chrome、Chromium 或 Edge。沒有可用瀏覽器時，面板會說明缺少什麼，而不是顯示空白頁。
</Note>

## 閱讀和操作頁面

| 能力 | 說明 |
| --- | --- |
| 標籤 | 新建、切換、關閉；Agent 開啟的標籤也會出現在這裡。 |
| 查詢 | `cmd-f` 在頁面內查詢，顯示匹配數並迴圈跳轉。 |
| 下載 | 預設拒絕。允許後文件寫入執行階段自己的下載目錄，頁面不能決定路徑。 |
| 對話方塊 | `alert`、`confirm`、`prompt` 和 `beforeunload` 會在面板內顯示為卡片，由你回答。 |
| 檔案選擇 | 頁面觸發的檔案選擇會被攔截，由你選擇要上傳的檔案。 |
| 頁面診斷 | 控制台訊息、未捕獲異常、失敗的網路請求會作為 Agent 可讀的診斷資訊保留。 |
| 操作記錄 | 面板底部可以展開本標籤的操作記錄，區分你和 Agent 發起的操作。 |

頁面內容是不可信輸入。Agent 的工具說明會明確要求它不要執行頁面裡偽裝成指令的文字；你在批准導航、上傳或敏感操作時也應保持同樣的判斷。

## Agent 能做什麼

Agent 通過內建的瀏覽器工具工作，主要包括：

- **觀察**：讀取頁面的可訪問性樹和可互動元素，返回短期有效的元素引用。
- **操作**：點選、填寫、按鍵、懸停、滾動、選擇下拉項、拖拽、上傳檔案。
- **導航與標籤**：開啟、切換、關閉標籤，等待某個條件出現。
- **讀取**：提取頁面文本、讀取控制台和網路診斷、擷取螢幕截圖。
- **測試**：錄製操作並匯出 Playwright 測試；儲存頁面基線並比較變化。
- **請求幫助**：遇到驗證碼、登入或無法決定的事情時，請人接手。

元素引用只在下一次觀察之前有效。頁面重新渲染、導航或再次觀察後，舊引用會被拒絕，Agent 必須重新觀察——這能避免“點選落到了剛好移到這個位置的東西上”。

## 你始終可以接管

當 Agent 正在操作當前標籤時，面板右下角會顯示 **Agent 正在操作**。點選暫停按鈕可以立即收回控制權；暫停後 Agent 仍能觀察頁面，但不能繼續點選或輸入。處理完後點擊播放按鈕，把標籤交還給 Agent；它會重新觀察頁面再繼續。

你自己在頁面裡輸入也會暫停 Agent 在該標籤上的操作。面板會顯示原因，並給出交還控制的入口。

<Warning>
  瀏覽器裡的操作可能提交表單、傳送訊息、產生費用或修改外部系統。批准前確認目標站點、賬號和操作範圍；不要把密碼、支付資訊或一次性驗證碼交給 Agent。
</Warning>

## 設定

**設定 → 瀏覽器** 控制瀏覽器面板自己的標籤頁：

| 選項 | 說明 |
| --- | --- |
| **起始頁** | Google、Bing、百度或自定義地址。隻影響你新建的標籤頁，不影響 Agent 自己開啟的標籤。 |
| **搜尋引擎** | 位址列輸入關鍵詞時使用；支援 Google、Bing、百度、DuckDuckGo 或自定義模板。 |
| **無損畫面** | 文字更清晰，但畫面更大、更慢；面板上的 **HD** 按鈕切換同一個設定。 |
| **允許下載** | 預設關閉。開啟後頁面可以儲存檔案到執行階段的下載目錄。 |
| **匯入本機 Chrome 登入狀態** | 把本機 Chrome、Edge 或 Brave 的 Cookie 與 localStorage 複製到隔離配置，讓 Agent 直接開啟你已登入的站點。只讀取源配置，不寫回。 |
| **清除瀏覽器資料** | 刪除隔離配置裡的 Cookie、localStorage、快取和已匯入的登入狀態；已開啟的標籤會關閉。 |

<Note>
  連線到遠端執行階段後，瀏覽器畫面和顯示設定所依賴的通道尚未完整實現，顯示選項會在下次使用本機執行階段生效。檔案選擇等本地能力也不會跨執行階段使用。
</Note>

## 安全邊界

- 瀏覽器使用獨立的 `user-data-dir`，不會讀寫你日常瀏覽器的配置，除非你明確匯入登入狀態。
- 下載預設拒絕；允許後也只能寫入執行階段下載目錄，不能寫入工作區。
- 頁面不能靜默開啟原生檔案選擇器或儲存對話方塊。
- Agent 的每一次導航和操作都會寫入脫敏審計記錄；Cookie、token 和輸入值不會進入審計。
- 跨源導航、訪問本機迴環地址或上傳檔案可能需要你額外批准。

## 遇到問題

| 現象 | 處理 |
| --- | --- |
| 面板提示找不到瀏覽器 | 安裝 Chrome、Chromium 或 Edge，然後重新打開面板。 |
| 頁面能開啟但 Agent 看不到元素 | 讓 Agent 重新觀察；沒有可訪問性樹的視窗或跨源 iframe 可能無法操作。 |
| 點選位置偏移 | 調整視窗縮放後重新開啟標籤；座標按視口 CSS 畫素換算，縮放變化會讓舊畫面失效。 |
| 下載沒有開始 | 在設定裡開啟 **允許下載**；被拒絕的下載會在面板裡提示。 |
| 登入狀態沒有匯入 | 關閉正在使用該配置的標籤頁後重試；源瀏覽器必須已經退出或允許讀取其配置。 |
| Agent 被暫停 | 點選面板右下角的播放按鈕，或使用 **交還給 Agent**。 |
