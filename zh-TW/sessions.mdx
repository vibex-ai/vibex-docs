title: "Agent 會話"
description: "建立、觀察、暫停、分叉和恢復 Vibex Agent 會話。"
---

會話把一次開發任務的輸入、Agent 輸出和工具操作儲存為結構化時間線。**權威執行環境**儲存權威時間線，其他客戶端只顯示它的投影。

## 建立會話

1. 選擇目標專案和位置（**Local** 或 **New Worktree**，見[專案與工作區](/zh-TW/workspaces)）。
2. 在 Composer 頂端選擇 Agent、供應商設定、模型、**思考深度**和**對話模式**。
3. 輸入任務。用 `/` 選命令，用 `@` 引用工作區檔案，用 `$` 插入 Skill，或用 `↑` / `↓` 翻出這個會話早先送過的訊息；也可以加入附件。
4. 傳送前確認工作區和權限範圍。Agent 可能需要讀取檔案、執行終端機命令或請求額外授權。

切換 Agent 或模型只影響後續執行。已寫入時間線的訊息會保留其原始執行身份。

## 閱讀時間線

| 項目 | 你會看到什麼 |
| --- | --- |
| 使用者與 Agent 訊息 | Markdown 文字和附件。 |
| Reasoning | Agent 的推理摘要，可用 **Expand reasoning** / **Collapse reasoning** 展開或收合。 |
| Plan | 待辦步驟及其進度。 |
| 工具與程序詳情 | 工具名稱、參數摘要、程序和結束結果，以及 **{n} process events** 計數。 |
| 權限請求 | 等待你核准或拒絕的操作。 |
| 詢問表單 | Agent 需要你填寫的型別化表單。 |
| 委派 | 子 Agent 或委派任務的狀態和結果。 |
| 狀態事件 | 執行、排隊、等待、完成、失敗、停止和重連。 |

回合上方會顯示 **Worked for** 的耗時。產生過程中會顯示 **Thinking...** 或 **Waiting for confirmation...**。

工具參數、終端機輸出和檔案差異可能包含敏感內容。分享診斷資料前先檢查並去識別化。

## 目標

支援目標的 Agent 會透過 ACP 發佈目標狀態：通用的 `_meta.goal` 擴充，以及 Codex 舊的 `_meta.codex.goal` 命名空間。Vibex 把這些歸一成同一套模型，並把每次變化存成一條目標時間線條目。

目標顯示在輸入框上方的固定目標欄裡，緊接在佇列訊息欄下面：

- 目標欄顯示階段、目標和 Agent 自己上報的統計（已用時間、token 用量、回合數）。
- 鉛筆按鈕（**Edit goal**）開啟原處編輯器改寫目標；儲存時透過目標控制下發，不經過輸入框。
- **Pause goal** / **Resume goal** 暫停或繼續目標。
- **Clear goal** 清除目標；進行中、已暫停、已阻塞和額度受限的目標都能清除。

只有轉接器明確宣告支援時，對應的按鈕才會出現。以 `/goal` 送出的訊息保留自己的氣泡，並在氣泡邊緣帶一個目標圖示。

## 控制執行

| 操作 | 說明 |
| --- | --- |
| **Stop current response** | 停止目前執行。已寫入的檔案或已執行的命令**不會**自動復原。 |
| **Continue** | 在同一會話中繼續傳送任務。 |
| **Retry** | 依 Agent 支援的重試語義重新執行失敗回合；不確定是否已執行的外部操作應先檢查結果。 |
| **Fork** | 從目前時間線建立分支會話，適合比較兩種實作。 |
| **Rename** | 修改會話標題，不會改變 Agent 上下文。 |
| **Edit message** | 改寫最後一則使用者訊息；已完成的時間線事件不會被改寫。 |

<Warning>
  停止 Agent 只停止執行過程，不會撤銷檔案、Git 或外部服務變更。請在 Git diff 和終端機中分別檢查結果。
</Warning>

## 訊息佇列與自動繼續

執行期間傳送的後續訊息會進入佇列。Composer 上的佇列區域提供：

- **Auto send** / **Manual send** —— 切換自動或手動提交佇列。
- **Steer** —— 只對宣告了原生引導（native steering）的 Agent 出現：它把這則訊息注入正在執行的回合，而不是先打斷。其他 Agent 仍然回退為打斷並重送。
- **Send queued message**、**Edit queued message**、**Delete queued message** —— 逐項操作。
- **Resume queued messages** / **Clear queued messages** —— 整體恢復或清空。

投遞方式會記在使用者訊息上，並渲染成氣泡下邊緣的反應標記：**Steered into the running turn**（主色）或 **Interrupted the turn and resent**（警告色）。當後面已經存在更新的回合時，舊回合會標記為被取代：即時狀態、執行時長和串流列展開停止，但已經產生的列仍然可見並保持展開。

取消或刪除佇列項目不會撤銷已經完成的操作。

啟用 **Auto-continue** 後，只有符合會話設定和 Agent 能力的回合會自動推進。遇到權限請求、詢問表單、失敗或需要使用者選擇時會停下來等待。

## 權限請求與詢問表單

當 Agent 請求終端機、檔案寫入或其他受保護能力時，時間線會顯示請求原因和範圍，通常包含工作目錄、參數和環境變數。可選操作為 **Approve**、**Deny** 和 **Always allow for session**。

詢問表單需要填寫結構化內容。提交前確認值和作用範圍；取消表單會讓 Agent 收到取消結果，而不是隱含核准。

## 全域搜尋

`cmd-k` 在任何位置都能開啟 **Global search**（工作台命令面板），入口是標題列裡的搜尋圖示，緊鄰執行環境控制項之前。一次輸入同時檢索三組結果：

| 分組 | 範圍 | 選取後 |
| --- | --- | --- |
| **Recent sessions** / **Sessions** | 會話標題和訊息內文 | 開啟會話並跳到命中的那則訊息 |
| **Settings** | 設定項目 | 開啟設定、定位到對應分區並高亮那一列 |
| **Quick actions** | 註冊在工作台上的真實 Action | 直接執行；每一列顯示自己的快速鍵，前置條件不滿足時顯示為無法使用 |

- 面板頂端有自己的查詢框，三組之間畫有分隔線；查詢為空時只列出 **Recent sessions**。
- 會話搜尋只索引和高亮對話文字——使用者訊息、Agent 回答、推理和計畫——並且只給命中的關鍵詞著色，目前命中顏色更重。
- 輸入非空時按 `escape` 先清空輸入，再按一次才關閉。
- 索引在背景建立並保留，再次開啟是瞬間完成的。已封存的會話不參與搜尋。

單一會話內的尋找仍然用 `cmd-f`（**Find in conversation**）。

## 匯入本機歷史

透過側欄 **More** 選單或專案右鍵選單中的 **Import sessions** 匯入其他 Agent 的歷史。

支援 14 個來源：**Claude Code**、**Codex**、**OpenCode**、**Gemini CLI**、**Cline**、**Hermes**、**CodeBuddy Code**、**Kimi Code**、**Pi**、**Grok**、**Cursor**、**DeepSeek Harness**、**ZCode**、**Google Antigravity**。

流程：

1. Vibex 掃描本機歷史，顯示 **Scanning local Agent sessions...**。
2. 在預覽清單中依專案分組勾選要匯入的會話，可以依 Agent 篩選或重新掃描。
3. 點擊 **Import {n} sessions**，等待 **Import complete**。

結果會分成 **Imported**、**Already imported**、**Not found**、**Failed** 四類。

<Note>
  掃描器只讀取中繼資料：標題、時間、工作區路徑、訊息數量和來源路徑。匯入時才會重新讀取內容並一次性寫入時間線。憑證、金鑰和完整 Agent home 設定**不會**匯入。已匯入過的會話不會重複匯入，也不會被重新整理覆蓋。
</Note>

## 通知與未讀

會話完成、失敗或等待輸入時，權威執行環境可以傳送桌面通知。三類通知可以在 **Settings → Session** 的 **Agent notifications** 中分別開關，它們已從 **General** 移到那裡。

有未讀完成項目的會話在側欄顯示圓點提示；開啟會話後提示消失，以權威時間線為準。系統匣選單也提供 **New chat**、**Config Center** 和 **Settings** 的快捷入口。

## 子 Agent 時間線

當會話使用了委派（delegation）時，右側欄會出現 **Child Agent timelines** 入口，可以查看子 Agent 的獨立時間線，並從父會話跳轉過去。
