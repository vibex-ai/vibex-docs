---
title: "Agent 會話"
description: "建立、觀察、暫停、分支與恢復 Vibex Agent 會話。"
---

會話把一次開發任務的輸入、Agent 輸出與工具操作保存為結構化時間線。桌面端保存權威時間線，行動端只顯示遠端投影。

## 建立會話

1. 選擇目標工作區。
2. 在 Composer 頂端選擇 Agent、供應商設定、模型、推理深度與 conversation mode。
3. 輸入任務。用 `/` 選 Prompt、`@` 引用檔案、`$` 插入 Skill，也可以加入附件。
4. 傳送前確認工作區和權限範圍。Agent 可能需要讀取檔案、執行終端機命令或請求授權。

## 閱讀時間線

| 項目 | 你會看到什麼 |
| --- | --- |
| 使用者與 Agent 訊息 | Markdown 文字與附件。 |
| reasoning | Agent 的推理摘要，是否顯示取決於 Agent 與設定。 |
| plan | 待辦步驟與進度。 |
| tool/process details | 工具名稱、參數摘要、程序與退出結果。 |
| permission approval | 等待你核准或拒絕的操作。 |
| elicitation | Agent 要求你填寫的結構化表單。 |
| 狀態事件 | 執行、等待、完成、失敗、停止與重連。 |

工具參數、終端機輸出和檔案差異可能含有敏感內容。分享截圖或診斷前先脫敏。

## 控制執行

- **Stop**：停止目前執行；已寫入的檔案或已執行的命令不會自動回復。
- **Continue**：在同一會話繼續傳送任務。
- **Fork**：從目前時間線建立分支會話。
- **Rename**：修改會話標題，不改變 Agent 上下文。
- **Resume**：從持久化歷史恢復會話。

<Warning>
  停止 Agent 只停止執行，不會撤銷檔案、Git 或外部服務變更。請分別檢查 Git diff 與終端機。
</Warning>

## 權限與詢問表單

Agent 請求終端機、檔案寫入或其他受保護能力時，時間線會顯示原因與範圍。選擇 **Approve** 或 **Deny**，結果會記錄在時間線。取消 elicitation 表單會傳回取消結果，不會隱式核准。

## 匯入歷史、搜尋與通知

支援的 Agent 歷史可用 **Local history import** 匯入。確認來源和目標工作區；不會匯入憑證或完整 Agent home。使用 `cmd-f`（Windows/Linux 通常為 `ctrl-f`）搜尋時間線。桌面端可在完成、失敗或等待輸入時發送通知。

## 行動端操作

配對後，行動端可以查看同一時間線、傳送後續訊息、回答問題與處理允許的核准。它不在本機啟動 Agent，也不持有工作區檔案；斷線後會先 catch-up 再接收即時事件。
