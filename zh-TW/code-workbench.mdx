程式碼工作台把檔案樹、搜尋、編輯器、Git 差異和內容預覽放在同一個視窗。所有檔案操作都以目前工作區為邊界。

## 檔案樹和搜尋

從右側欄的 **檔案** 圖示開啟檔案樹：

1. 展開工作區目錄，或用檔名直接輸入定位（type-ahead）。
2. 使用 **搜尋工作區檔案** 依內容搜尋，可以切換 **區分大小寫**、**符合整個詞** 和正規表示式模式。
3. 點擊檔案在預覽分頁中開啟；多個分頁可以並列或分割顯示。

檔案樹的右鍵選單提供 **新建檔案**、**新建資料夾**、**剪下**、**複製**、**貼上**、**複製相對位置**、**複製絕對位置**、**複製檔案名**、**重新命名**、**刪除**，以及 **Open In** 子選單（**編輯器** / **預設應用程式** / **終端機** / **本機終端** / **檔案管理器**）。檔案也支援拖放移動。

搜尋不會自動修改檔案。大型檔案、無法解碼的內容和工作區外路徑會被檔案服務拒絕。

## 編輯和儲存

- 在編輯器中直接修改文字。
- 用 **儲存檔案** 儲存目前檔案（`cmd-s`）。
- 預設開啟自動儲存：停止輸入一段時間（預設 1000 毫秒）後寫回，編輯器或視窗失去焦點時也會寫回；在 **設定 → 工作台** 裡可以改成 **手動**（只用 `cmd-s`）或 **失焦儲存**，並調整閒置延遲。
- 工具列可以切換 **soft wrap** 和 **whitespace** 顯示。
- 狀態列顯示 `Ln N, Col N`、總行數、語言、編碼（`UTF-8` / `UTF-8 BOM` / `Binary`）、行尾（`LF` / `CRLF` / `Mixed EOL`）和檔案大小。
- 標題列狀態顯示 **已修改**（有未儲存變更）、**正在儲存** 或 **已儲存**。

<Note>
  編輯器**沒有** Save As：儲存一律寫回原路徑。也沒有檔案內尋找列——`cmd-f` 開啟的是 **在目前會話中尋找**。
</Note>

### 大型檔案與唯讀

以下情況檔案會以唯讀方式開啟，並在標題列標記 **大型檔案 - 唯讀** 或 **二進位檔案 - 唯讀**：

- 大於 8 MiB
- 超過 5 萬行
- 內容被截斷
- 被辨識為二進位

## 編輯器保護與恢復

每個編輯緩衝區同時記錄已儲存內容、外部 revision 和本機 revision。儲存請求使用樂觀並行控制：如果磁碟上的內容已經變更，儲存會失敗並傳回 `file_external_revision_changed`，而不是無聲覆蓋。

有未儲存變更的分頁在關閉時會提示 **Save or discard the dirty editor before closing it**；自動儲存開啟時，待寫回的變更會先落盤再關閉，不再打斷你；切換工作區時同樣會攔截。

權威執行環境重新啟動後，Vibex 會恢復未儲存的緩衝區，它們仍然標記為 **已修改**，仍需你主動儲存，不會自動覆蓋磁碟檔案。檔案在磁碟上已被刪除時，標題列狀態顯示 **已刪除 - 復原緩衝區**。

<Warning>
  刪除檔案會改變工作區內容。刪除前查看 Git 狀態，必要時先複製內容或建立提交。
</Warning>

## 內容預覽

| 類型 | 副檔名 | 能做什麼 |
| --- | --- | --- |
| Markdown | `md` `mdx` `markdown` | 渲染檢視，支援程式碼區塊、表格、工作清單、註腳、公式和圖表（Mermaid / PlantUML）。 |
| 圖片 | `png` `jpg` `jpeg` `gif` `webp` `svg` | 預覽圖片。 |
| PDF | `pdf` | 原生 PDF 預覽，支援 **Fit width**、50%–200% 縮放和頁碼跳轉。 |
| Office | `docx` `xlsx` `ods` `pptx` | 唯讀內容預覽。 |
| 音訊與影片 | `mp4` `mp3` `wav` 等 | **不在應用程式內播放**，交給系統預設應用程式。 |
| 其他 | 其餘文字格式 | 以編輯器開啟。 |

Markdown 預覽提供 **Contents** 大綱、**Copy document text**、逐區塊 **Copy code** / **Copy diff**、圖表原始碼檢視和全螢幕。工作區相對連結在預覽內開啟，外部連結交給系統瀏覽器。

Office 預覽是**唯讀的擷取檢視**，不是版面還原：

- `docx` —— 標題與段落。
- `xlsx` / `ods` —— **僅第一個工作表**，最多 80 列 × 20 欄。
- `pptx` —— 投影片文字，最多 200 頁。

PDF 預覽同樣唯讀，不支援搜尋、註解和表單。

### 無法預覽的格式

| 格式 | 現象 |
| --- | --- |
| `.bmp` | 顯示 **不支援的檔案**。 |
| `doc` `xls` `ppt` | 回報 `office_legacy_format_unsupported`，請先轉換為新格式。 |
| `odt` `odp` | 沒有處理程式。 |
| `.html` | 以帶高亮的原始文字開啟，**不會渲染頁面**。 |
| `.json` `.yaml` `.csv` | 以原始文字開啟，不做格式化或表格化。 |
| `.ipynb` | 當作 JSON 文字開啟，不是 Notebook。 |

<Info>
  語法高亮涵蓋 Rust、TypeScript/TSX、JavaScript、JSON、Markdown、TOML、YAML、Python、Go、Java、CSS、HTML 和 Shell。其他語言以純文字顯示。
</Info>

## 圖片編輯

圖片編輯器用於**在傳送前標註附件圖片**，不是工作區圖片檔案的通用編輯器。在輸入框的附件區點擊 **編輯圖片** 進入。

可用工具：**裁剪**、**筆畫**、**文字**、**矩形框**、**圓形框**、**箭頭**、**馬賽克**，以及 **復原編輯** / **重做編輯**。支援 25%–400% 縮放和拖曳平移。

- macOS：`cmd-z` 復原，`cmd-shift-z` 重做。
- Windows/Linux：`ctrl-z` 復原，`ctrl-shift-z` 重做。

儲存時會重新編碼為 **PNG**，不支援選擇其他格式，也沒有旋轉、縮放、翻轉或圖層。

## 預覽分頁和分割

拖曳分頁或使用分頁選單中的 **向右分割** / **向下分割** 把檢視分割，分割邊界可以拖曳調整。程式碼、差異、終端機和文件都可以放在同一個視窗裡。

預覽面板標題列的 **彈出為獨立視窗** 按鈕把整個多分頁面板彈出為獨立視窗，**嵌入主視窗** 把它收回工作台。面板實體始終沒有易主，所以開啟的分頁、編輯器緩衝區和終端機都會跟著走，同一時間只存在一個面板；關閉獨立視窗會把面板交還工作台欄，關閉面板則會關掉它的視窗。獨立視窗沿用外殼同一套編輯器操作，`cmd-s` 儲存和跳轉到行都仍然可用。

全螢幕把工作台欄交給預覽面板，側欄和右側欄保留各自的位置、寬度和活動列，右側欄也保留拖曳調整寬度的手把。

在 **設定 → 工作台** 的 **預覽視窗** 裡選擇面板預設開啟的位置：**內嵌**（預設，內嵌在工作台欄）或 **獨立視窗**；標題列的彈出和停靠按鈕會寫入同一項設定。

關閉分頁不會刪除檔案或終端機，只關閉目前檢視。

## 分頁操作

- 將游標懸停在檔案或差異分頁上可查看完整路徑。
- 分頁右鍵選單：**關閉標籤**、**關閉其他標籤**、**關閉左側標籤**、**關閉右側標籤**、**關閉所有標籤**、**向右分割**、**向下分割**、**固定標籤** / **取消固定標籤**、**定位檔案**、**Open In**。
- 釘選的分頁必須先取消釘選才能關閉。關閉其他分頁時，釘選分頁和未儲存的分頁會保留。
- `cmd-w` 關閉目前預覽分頁；`cmd-tab` / `cmd-shift-tab` 和 `cmd-pageup` / `cmd-pagedown` 循環切換分頁。終端機分頁不使用這些快速鍵。

完整快速鍵清單見[快速鍵參考](/zh-TW/reference/shortcuts)。
