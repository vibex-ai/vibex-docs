程式碼工作台把檔案樹、搜尋、編輯器、Git 差異與內容預覽放在同一個視窗。所有檔案操作以目前工作區為邊界。

## 檔案樹與搜尋

1. 開啟側欄的檔案樹並展開工作區目錄。
2. 用檔名搜尋定位路徑。
3. 用內容搜尋查找文字；結果會顯示路徑與匹配位置。
4. 點擊檔案，在預覽分頁開啟。多個分頁可並列或分欄顯示。

大型檔案、無法解碼的內容和工作區外路徑可能被檔案服務拒絕。

## 編輯與儲存

- 在編輯器直接修改文字。
- 使用 **Save** 儲存檔案；快捷鍵為 `cmd-s`（Windows/Linux 通常為 `ctrl-s`）。
- 新建、重新命名或刪除檔案前確認目標路徑。
- 編輯器會保存軟換行和顯示空白字元偏好，可在工具列切換。
- **Save** 會攜帶已讀取的內容 revision。若檔案已被外部程序修改，儲存會暫停並要求重新載入或比較差異，不會靜默覆蓋。
- 若外部程序刪除檔案，編輯器會標記為缺失；未儲存內容會保留在恢復緩衝區，供你另存或放棄。

<Warning>
  刪除檔案會改變工作區內容。刪除前查看 Git 狀態，必要時先建立提交或備份。
</Warning>

## 編輯器保護與恢復

每個編輯緩衝區同時記錄已儲存內容、外部 revision 和本機 revision。只有三者仍然匹配時才會接受儲存；並發修改會回傳衝突狀態，要求你重新讀取後決定如何合併。切換工作區或關閉分頁前，桌面端會檢查 dirty、儲存中、外部衝突和檔案缺失狀態，必要時阻止操作。

重啟或重新載入工作區時，桌面端會恢復受限的未儲存緩衝區。恢復內容仍需你主動儲存，不會靜默覆蓋磁碟檔案。

## 內容預覽

| 類型 | 能做什麼 |
| --- | --- |
| Markdown | 在編輯與渲染視圖切換，查看程式碼、表格、公式與圖表。 |
| 圖片 | 查看圖片並進入圖片編輯器，支援復原與重做。 |
| PDF | 使用原生 PDF 預覽逐頁查看。 |
| Office 文件 | 預覽受支援的 Office 內容。 |
| 其他文字 | 以編輯器開啟並保留編碼與換行。 |

二進位檔案和超過編輯器限制的大檔案保持唯讀。Markdown 資源會遵守工作區路徑、大小與資源數量限制；無法解碼的內容不會強制當作文字開啟。

## 圖片編輯

圖片編輯器提供 macOS 的 `cmd-z`/`cmd-shift-z` 和 Windows/Linux 的 `ctrl-z`/`ctrl-shift-z` 復原/重做。儲存前確認輸出路徑與格式。

## 預覽分頁和分欄

拖動分頁或使用分欄入口，可以同時查看程式碼、差異、終端機與文件。關閉分頁不會刪除檔案或終端機，只會關閉目前視圖。

## 常用快捷鍵

| 操作 | macOS | Windows/Linux |
| --- | --- | --- |
| 儲存檔案 | `cmd-s` | `ctrl-s` |
| 開啟預覽 | `cmd-shift-p` | `ctrl-shift-p` |
| 側欄 | `cmd-b` | `ctrl-b` |
| 前進/後退 | `alt-left` / `alt-right` | `alt-left` / `alt-right` |
