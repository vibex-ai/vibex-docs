Vibex 終端機使用原生 PTY 和 ANSI 模擬，適合執行開發伺服器、測試與 Git 命令。終端機屬於桌面端；行動端只有在獲得權限後才能要求遠端視圖或輸入。

## 開啟終端機

1. 開啟工作台的終端機面板。
2. 選擇工作區目錄和 shell。
3. 在分頁執行命令，可建立多個分頁並調整尺寸。
4. 使用滾動緩衝區或終端機搜尋查看舊輸出。

```bash
git status --short
pnpm test
```

## 終端機操作

- 建立、關閉與切換分頁。
- 調整 PTY 尺寸，程式會收到最新 rows/columns。
- 搜尋輸出、複製選取文字和貼上輸入。
- 切換可用 shell；安裝與權限由作業系統決定。
- 正確處理原始位元組與 ANSI 控制序列。

Agent 要求執行命令時，時間線會顯示程序詳情和退出結果。核准前檢查命令、工作目錄與參數。終止程序不會撤銷已完成的外部操作。

## 與 Agent 配合

Agent 要求執行命令時，時間線會顯示程序詳情和退出結果。核准前檢查命令、工作目錄與參數。終止程序不會撤銷已完成的外部操作。

## 預覽生成結果

在程式碼工作台開啟 Markdown、圖片、PDF 或受支援的 Office 文件。行動端收到的是終端機快照與經授權的輸入通道；輸入帶工作區範圍、generation 檢查與審計記錄。

開發伺服器產生的網頁預覽不等於 Vibex 的遠端 Web 後端；Vibex 只為支援的工作區內容提供原生預覽。

<Note>
  終端機快照可能含有金鑰、路徑和使用者資料。不要把完整輸出貼到公開 Issue、日誌或診斷證據。
</Note>

## 行動端終端機

行動端收到終端機快照與經授權的輸入通道。輸入帶工作區範圍、generation 檢查與審計記錄。網路中斷時，行動端不能假設命令已執行；重連後以桌面端快照為準。
