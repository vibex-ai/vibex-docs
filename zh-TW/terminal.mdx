Vibex 的終端機使用原生 PTY 和 ANSI 模擬，適合執行開發伺服器、測試和 Git 命令。終端機由**權威執行環境**承載，因此行動端也能在取得權限後使用同一批終端機。

## 開啟終端機

從右側欄的 **New terminal** 圖示開啟，或在檔案樹裡對某個路徑選擇 **Open In → Terminal**，讓終端機以該目錄為初始工作目錄。

```bash
git status --short
pnpm test
```

Composer 上方還有一個**內嵌終端機面板**，可以用 `cmd-shift-t` 在對話和終端機之間切換。

## 終端機操作

| 能力 | 說明 |
| --- | --- |
| 分頁 | 新增、關閉、重新命名（**Rename terminal** / `Terminal name`）和切換。 |
| 分割 | 分頁選單提供 **Split right** 和 **Split down**，分割邊界可拖曳。 |
| 調整大小 | 拖曳面板邊界，PTY 會收到最新的 rows/columns。 |
| 捲動緩衝區 | 固定 **10000 行**，不可設定。 |
| 搜尋 | **Search terminal** 開啟搜尋列，顯示 `0 matches` 或 `{n} / {total}`。**只支援下一個符合項目**，循環前進。 |
| 複製貼上 | 工具列 **Copy** / **Paste**，或 `ctrl-shift-c` / `ctrl-shift-v`。 |
| 搜尋快速鍵 | `ctrl-shift-f`。 |
| 開啟連結 | 游標懸停在超連結上時出現 **Open link**。 |
| 狀態 | 分頁上顯示 `running`、`exited`、`killed` 或 `stale`。 |

終端機按原始位元組處理輸出和 ANSI 控制序列，不會把二進位輸出當作文字。

## Shell 選擇

工具列提供可用的 shell，選取後會切換目前分頁的 shell：

- Windows：**PowerShell**、**Command**。
- 其他平台：**bash**、**zsh**、**fish**（只列出系統上實際存在的）。

每個分頁可以獨立選擇 shell。修改預設 shell 見[設定](/zh-TW/settings)。

## 與 Agent 搭配

Agent 請求執行命令時，時間線會顯示程序詳情和結束結果。命令可能等待權限核准；核准前請檢查命令、工作目錄和參數。

<Warning>
  終止終端機程序不會撤銷它已經完成的外部操作。停止 Agent 也不會回收它已經建立的終端機。
</Warning>

## 陳舊終端機

權威執行環境重新啟動後，終端機會話內容不會保留（只保留分頁中繼資料）。遺失的終端機會被標記為 `stale`。

遇到 `stale` 時，請重新開啟分頁並以新的快照為準，**不要**根據舊快照重複執行命令。

## 行動端終端機

行動端收到的是終端機快照和經過授權的輸入通道，輸入會帶工作區作用域、generation 檢查和稽核記錄。網路中斷時，行動端不會假設命令已經執行，重連後以權威端的快照為準。

<Note>
  終端機輸出可能包含金鑰、路徑和使用者資料。不要把完整終端機輸出複製到公開 Issue、日誌或診斷資料中。
</Note>
