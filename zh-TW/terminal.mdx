Vibex 的終端機使用原生 PTY 和 ANSI 模擬，適合執行開發伺服器、測試和 Git 命令。終端機由**權威執行階段**承載，因此行動端也能在獲得權限後使用同一批終端機。

## 開啟終端機

從右側欄的 **新建終端機** 圖示開啟，或在檔案樹裡對某個路徑選擇 **Open In → 終端機** 讓終端機以該目錄為初始工作目錄。

```bash
git status --short
pnpm test
```

輸入框上方的終端機按鈕會開啟一個**底部終端機面板**，用 `cmd-shift-t` 在對話和終端機之間切換。面板鋪滿工作台寬度，不再擠在輸入框裡。

## 終端機操作

| 能力 | 說明 |
| --- | --- |
| 標籤 | 新建、關閉、重新命名（**重新命名終端機** / `Terminal name`）和切換。 |
| 分欄 | 標籤選單提供 **向右拆分** 和 **向下拆分**，分欄邊界可拖動。 |
| 調整尺寸 | 拖動面板邊界，PTY 會收到最新的 rows/columns。 |
| 滾動緩衝區 | 固定 **10000 行**，不可配置。 |
| 搜尋 | **Search terminal** 開啟搜尋欄，顯示 `0 matches` 或 `{n} / {total}`。**只支援下一個匹配**，迴圈前進。 |
| 複製貼上 | 工具欄 **複製** / **貼上**，或 `ctrl-shift-c` / `ctrl-shift-v`。 |
| 搜尋快捷鍵 | `ctrl-shift-f`。 |
| 開啟連結 | 游標懸停在超連結上時出現 **Open link**。 |
| 狀態 | 標籤上顯示 `running`、`exited`、`killed` 或 `stale`。 |

終端機按原始位元組處理輸出和 ANSI 控制序列，不會把二進位制輸出當作文本。

## Shell 選擇

工具欄提供可用的 shell，選中後會切換當前標籤的 shell：

- Windows：**PowerShell**、**命令**。
- 其它平台：**bash**、**zsh**、**fish**（只列出系統上實際存在的）。

每個標籤可以獨立選擇 shell。修改預設 shell 見[設定](/zh-TW/settings)。

## 與 Agent 配合

Agent 請求執行命令時，時間線會顯示程序詳情和退出結果。命令可能等待權限批准；批准前請檢查命令、工作目錄和引數。

<Warning>
  終止終端機程序不會撤銷它已經完成的外部操作。停止 Agent 也不會回收它已經建立的終端機。
</Warning>

## 陳舊終端機

權威執行階段重啟後，終端機會話內容不會保留（只保留標籤後設資料）。丟失的終端機會被標記為 `stale`。

遇到 `stale` 時，請重新開啟標籤並以新的快照為準，**不要**根據舊快照重複執行命令。

## 行動端終端機

行動端收到的是終端機快照和經過授權的輸入通道，輸入會帶工作區作用域、generation 檢查和審計記錄。網路中斷時，行動端不會假設命令已經執行，重連後以權威端的快照為準。

## TUI 與 SSH

Vibex TUI 是終端機裡的客戶端，不是終端機標籤的替代品：它把會話、核准、佇列和設定都畫在字元網格里，適合通過 SSH 或 tmux 使用。它隨桌面安裝包釋出，執行 `vibex` 即可；詳見 [Vibex TUI](/zh-TW/tui)。

TUI 的複製使用 OSC 52，所以在 SSH 和 tmux 裡也能工作。它不會接管桌面端已經開啟的終端機標籤，兩者是同一執行階段的不同客戶端。

<Note>
  終端機輸出可能包含金鑰、路徑和使用者資料。不要把完整終端機輸出複製到公開 Issue、日誌或診斷資料中。
</Note>
