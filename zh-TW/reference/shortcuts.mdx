---
title: "快捷鍵"
description: "Vibex 的所有預設快捷鍵，以及如何重新綁定。"
---

Vibex 的快捷鍵可以在 **設定 → 快速鍵** 中檢視、修改和重設。衝突的按鍵組合會被拒絕，並提示 **快速鍵無效或已被占用**。

## 可重新綁定的快捷鍵

以下 15 個動作可以在設定中重新綁定：

| 操作 | 預設鍵 | 分組 |
| --- | --- | --- |
| 切換側邊欄 | `cmd-b` | 工作台 |
| 切換預覽 | `cmd-shift-p` | 工作台 |
| 切換右側欄 | `cmd-shift-r` | 工作台 |
| 開啟執行階段 | `cmd-shift-o` | 工作台 |
| 切換對話/終端機模式 | `cmd-shift-t` | 輸入框 |
| 在目前會話中尋找 | `cmd-f` | 導覽 |
| 開啟設定 | `cmd-,` | 導覽 |
| 全域搜尋 | `cmd-k` | 導覽 |
| 返回 | `alt-left` | 導覽 |
| 前進 | `alt-right` | 導覽 |
| 重試執行階段 | `cmd-r` | 執行階段 |
| 儲存目前檔案 | `cmd-s` | 編輯器 |
| 跳轉到行 | `ctrl-g` | 編輯器 |
| 復原圖片編輯 | `cmd-z` / `ctrl-z` | 圖片編輯器 |
| 重做圖片編輯 | `cmd-shift-z` / `ctrl-shift-z` | 圖片編輯器 |

<Note>
  表中寫的是 `cmd-` 前置字元，它在 macOS 上是 Command 鍵，在 Windows / Linux 上是 Ctrl 鍵。只有圖片編輯器的復原 / 重做是依平台分別定義。
</Note>

**重設** 會還原單項的預設值，**全部重設** 會清除所有自訂對應。

## 不可重新綁定的快捷鍵

這些快捷鍵是固定行為：

| 操作 | 按鍵 | 作用範圍 |
| --- | --- | --- |
| 關閉目前預覽分頁 | `cmd-w` | 非終端機分頁 |
| 循環切換分頁 | `cmd-tab` / `cmd-shift-tab` | 非終端機分頁 |
| 切換上一個 / 下一個分頁 | `cmd-pageup` / `cmd-pagedown` | 非終端機分頁 |
| 終端機複製 / 貼上 / 搜尋 | `ctrl-shift-c` / `ctrl-shift-v` / `ctrl-shift-f` | 終端機分頁 |
| Tab 補齊 | `tab` / `shift-tab` | 終端機分頁（傳送給 shell 而非移動焦點） |
| 調取歷史訊息 | `up` / `down` | 會話輸入框（上鍵只在輸入框為空時開始；輸入即結束翻閱；下鍵回到最新，越過最新則恢復草稿） |
| 關閉彈出視窗 | `escape` | 執行環境管理員、搜尋列、全域搜尋（第一次清空輸入，第二次關閉） |

## 滑鼠操作

| 操作 | 效果 |
| --- | --- |
| 拖曳分頁 | 重新排列，或拖曳至邊緣進行分欄 |
| 拖曳面板邊界 | 調整側欄 / 右側欄 / 終端機的尺寸 |
| 在檔案樹項目上按滑鼠右鍵 | 開啟檔案操作選單 |
| 在分頁上按滑鼠右鍵 | 開啟分頁操作選單（關閉、分欄、釘選等） |
| 拖曳檔案 | 在檔案樹內移動檔案，靠近邊緣時會自動捲動 |
| 縮放圖片編輯器 | 使用滾輪縮放，拖曳平移 |

## 搜尋入口一覽

Vibex 有多個作用範圍不同的搜尋功能，不要把它們的範圍搞混：

| 搜尋 | 範圍 | 入口 |
| --- | --- | --- |
| **在目前會話中尋找** | 目前會話時間線 | `cmd-f` |
| **全域搜尋** | 所有會話標題與訊息內文、設定項目、快捷操作 | 標題列的搜尋圖示或 `cmd-k` |
| **搜尋工作區檔案** | 目前工作區的檔案內容 | 檔案樹 |
| **搜尋 MCP** / **搜尋技能** / **搜尋 Agent** | 對應的配置中心清單 | 各自清單頂部 |
| **搜尋提交資訊或代碼** | Git 提交歷程 | Git 面板的提交分頁 |
| **搜尋設定** | 設定項目 | 設定頂部 |

<Note>
  **全域搜尋** 是唯一的跨類型入口：一次輸入會同時給出會話、設定項目和快捷操作三組結果，按 `cmd-k` 在任何位置都能開啟。會話搜尋不再掛在側欄，入口移到了標題列、緊鄰執行環境控制項之前。
</Note>
