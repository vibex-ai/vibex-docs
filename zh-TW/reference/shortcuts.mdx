Vibex 的快捷鍵可以在 **設定 → 快捷鍵** 中檢視、修改和重置。衝突的鍵位會被拒絕，並提示 **快捷鍵無效或已被佔用**。

## 可重繫結的快捷鍵

以下 15 個動作可以在設定裡重新繫結：

| 操作 | 預設鍵 | 分組 |
| --- | --- | --- |
| 切換側欄 | `cmd-b` | 工作台 |
| 切換預覽 | `cmd-shift-p` | 工作台 |
| 切換右側欄 | `cmd-shift-r` | 工作台 |
| 開啟執行階段 | `cmd-shift-o` | 工作台 |
| 切換對話/終端機模式 | `cmd-shift-t` | 輸入框 |
| 在當前會話中查詢 | `cmd-f` | 導航 |
| 開啟設定 | `cmd-,` | 導航 |
| 全域性搜尋 | `cmd-k` | 導航 |
| 後退 | `alt-left` | 導航 |
| 前進 | `alt-right` | 導航 |
| 重試執行階段 | `cmd-r` | 執行階段 |
| 儲存當前檔案 | `cmd-s` | 編輯器 |
| 跳轉到行 | `ctrl-g` | 編輯器 |
| 撤銷圖片編輯 | `cmd-z` / `ctrl-z` | 圖片編輯器 |
| 重做圖片編輯 | `cmd-shift-z` / `ctrl-shift-z` | 圖片編輯器 |

<Note>
  表中寫的是 `cmd-` 字首，它在 macOS 上是 Command 鍵，在 Windows / Linux 上是 Ctrl 鍵。只有圖片編輯器的撤銷 / 重做按平台分別定義。
</Note>

**重置** 恢復單項預設值，**全部重置** 清除全部自定義對映。

## 不可重繫結的快捷鍵

這些快捷鍵是固定行為：

| 操作 | 按鍵 | 作用範圍 |
| --- | --- | --- |
| 關閉當前預覽標籤 | `cmd-w` | 非終端機標籤 |
| 迴圈切換標籤 | `cmd-tab` / `cmd-shift-tab` | 非終端機標籤 |
| 切換上一個 / 下一個標籤 | `cmd-pageup` / `cmd-pagedown` | 非終端機標籤 |
| 終端機複製 / 貼上 / 搜尋 | `ctrl-shift-c` / `ctrl-shift-v` / `ctrl-shift-f` | 終端機標籤 |
| Tab 補齊 | `tab` / `shift-tab` | 終端機標籤（傳送給 shell 而非移動焦點） |
| 調取歷史訊息 | `up` / `down` | 會話輸入框（上鍵只在輸入框為空時開始；輸入即結束翻閱；下鍵回到最新，越過最新則恢復草稿） |
| 關閉彈層 | `escape` | 執行階段管理器、查詢欄、全域性搜尋（第一次清空輸入，第二次關閉） |

## 滑鼠操作

| 操作 | 效果 |
| --- | --- |
| 拖動詞標籤 | 重新排列，或拖到邊緣分欄 |
| 拖動面板邊界 | 調整側欄 / 右側欄 / 終端機尺寸 |
| 右鍵檔案樹條目 | 開啟檔案操作選單 |
| 右鍵標籤 | 開啟標籤操作選單（關閉、分欄、固定等） |
| 拖動檔案 | 在檔案樹內移動檔案，靠近邊緣會自動滾動 |
| 縮放圖片編輯器 | 滾輪縮放，拖拽平移 |

## 搜尋入口一覽

Vibex 有多個作用域不同的搜尋，不要把它們的範圍搞混：

| 搜尋 | 範圍 | 入口 |
| --- | --- | --- |
| **在當前會話中查詢** | 當前會話時間線 | `cmd-f` |
| **全域性搜尋** | 全部會話標題與訊息正文、設定項、快捷操作 | 標題欄的搜尋圖示或 `cmd-k` |
| **搜尋工作區檔案** | 當前工作區檔案內容 | 檔案樹 |
| **搜尋 MCP** / **搜尋 Skill** / **搜尋 Agent** / **搜尋供應商** / **搜尋路由組** | 對應配置中心列表 | 各自列表頂部 |
| **搜尋提交資訊或程式碼** | Git 提交歷史 | Git 面板提交標籤 |
| **搜尋設定** | 設定項 | 設定頂部 |

<Note>
  **全域性搜尋** 是唯一的跨型別入口：一次輸入會同時給出會話、設定項和快捷操作三組結果，按 `cmd-k` 在任何位置都能開啟。會話搜尋不再掛在側欄，入口移到了標題欄、緊挨執行階段控制元件之前。
</Note>

## Vibex TUI

TUI 有自己的一套鍵位，和桌面端分開。完整說明見 [Vibex TUI](/zh-TW/tui#快捷鍵速查)。

| 按鍵 | 作用 |
| --- | --- |
| `?` | 開啟快捷鍵速查表。 |
| `Ctrl+P` | 命令面板。 |
| `Ctrl+L` / `1` | 開啟會話列表。 |
| `n` | 新建會話。 |
| `Ctrl+G` | Agent 設定。 |
| `Ctrl+W` | 切換工作區。 |
| `Ctrl+S` | 引導正在執行的回合。 |
| `Ctrl+C` | 清空草稿 / 打斷回合 / 詢問退出。 |
| `Alt+D` | 開啟 Dock（子 Agent、計劃、佇列）。 |
| `Alt+↑↓` | 在佇列中選擇。 |
| `Alt+Enter` | 打斷當前回合並立即傳送排隊訊息。 |
| `F2` | 展開或摺疊所有塊。 |
| `F9` | 重新載入鍵位檔案。 |
