Vibex 提供原生 Git 審查介面。停止 Agent 不會自動回復工作區，也不會替你決定何時提交。

## 查看變更

Git 面板提供 **Status**（未追蹤、已修改、已暫存、衝突）、**Diff**、**History** 和 **Blame**。選擇檔案後確認路徑、工作區與差異；行動端的寫入操作需要對應權限。

## 分支和暫存

1. 建立或切換分支。
2. 按檔案或區塊執行 **Stage** / **Unstage**。
3. 使用 **Revert** 放棄單一變更前，先確認內容。
4. 輸入訊息執行 **Commit**，必要時用 **Amend** 追加。
5. 用 **Fetch** 更新遠端引用，用 **Push** 發布提交。

<Warning>
  **Revert**、切換分支、Amend 與 Push 可能改變歷史或遠端狀態。執行前確認分支、遠端與待處理差異。
</Warning>

## VibexWorktree

使用 **VibexWorktree** 時，建立隔離 worktree 和分支，在其中執行 Agent，檢查差異後合併或 rebase。衝突時逐檔處理並重新檢查狀態；確認結果後才丟棄 worktree，因為未提交內容會一併刪除。

<Info>
  **CurrentCheckout** 直接修改目前檢出目錄；**VibexWorktree** 為並行任務提供獨立目錄。兩者都以桌面端 Git 狀態為準。
</Info>

## 建議流程

```text
查看 status -> 閱讀 diff -> 執行測試 -> stage -> commit -> fetch -> rebase/merge -> push
```
