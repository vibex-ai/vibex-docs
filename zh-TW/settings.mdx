開啟 **設定**（`cmd-,`）可以修改桌面端的本地偏好。設定不會替代配置中心中的 Agent、供應商、MCP 或 Skill 配置。

頁面頂部有 **搜尋設定** 輸入框，可以按名稱或關鍵字直接跳到某一項。改動過的項旁邊會出現 **撤銷更改**。

## 分區

| 分區 | 可調整內容 |
| --- | --- |
| **常規** | 語言、關閉到托盤、Vibex TUI、網路代理、啟動行為、開機啟動、系統通知、更新。 |
| **外觀** | 主題、工作台背景、視窗縮放、介面字型與程式碼字型、動效與對比度。 |
| **工作台** | 側欄檢視、新會話預設位置、預覽視窗位置、版面記憶、Git 改動計數和編輯器自動儲存。 |
| **連線** | SSH / WSL 遠端執行階段。預設隱藏，需在 **開發者** 裡開啟開關。 |
| **會話** | 會話內容寬度、時間線顯示、訊息佇列、自動繼續和 Agent 通知。 |
| **已歸檔會話** | 自動歸檔視窗、恢復和永久刪除。 |
| **終端機** | 預設 shell 和新建終端機的初始目錄。 |
| **瀏覽器** | 起始頁、搜尋引擎、畫面質量、下載和登入狀態。 |
| **電腦操作** | 驅動安裝、系統權限、核准策略、面板和超時。 |
| **快捷鍵** | 檢視、修改和重置鍵盤快捷鍵。 |
| **資料與診斷** | 本地儲存用量與清理、診斷與恢復入口。 |
| **開發者** | 幀率監視器、SSH 遠端執行階段開關。 |
| **關於** | 版本、通道、軟體更新、許可證和平台資訊。 |

## 常規

| 選項 | 說明 |
| --- | --- |
| **語言** | 系統預設 / 簡體中文 / 繁體中文 / English。 |
| **關閉視窗後繼續執行** | 關閉視窗後保留在系統托盤。 |
| **Vibex TUI** | 允許本機上的 TUI 附著到這個執行階段。關閉後，TUI 會提示 home 被鎖，並給出其它連線方式。 |
| **網路代理** | 讓 Vibex 的網路請求和 Agent 工具走本地或企業代理。支援 `http`、`https`、`socks5`、`socks5h`。啟用前會校驗地址。 |
| **啟動行為** | 啟動後恢復工作台，或直接新建會話。 |
| **開機啟動** | 登入系統時啟動 Vibex。 |
| **系統通知** | 桌面通知總開關。 |
| **更新提示** | 顯示標題欄更新按鈕和更新浮層。後臺安全檢查始終保持啟用。 |
| **自動更新** | 預設開啟。發現已簽名的新版本後自動下載；可以在應用內立即安裝，或在退出應用時安裝。 |

<Note>
  自動更新只接受同通道的版本。RC 安裝包只看 `-rc.*`，Stable 只看正式版本；通道不會互相回退。
</Note>

## 外觀

控制主題模式（跟隨系統 / 淺色 / 深色）、視窗縮放（75%–200%）、**介面字型** 與 **程式碼字型** 的字號和字重、**減少動效**、**失焦時暫停動畫** 和 **高對比度**。程式碼字型同時影響程式碼塊、整合編輯器和終端機。

**主題** 用三張預覽卡片選擇 **跟隨系統** / **淺色** / **深色**，每張卡片都會用該模式解析出的配色畫一個微縮工作台。**淺色主題** 與 **深色主題** 是各自獨立的下拉框，收起狀態和選單裡都顯示色塊與主題名。內建二十套：淺色為 Vibex Light、Catppuccin Latte、Gruvbox Light、Solarized Light、GitHub Light、Rosé Pine Dawn、Everforest Light、Ayu Light、One Light、Kanagawa Lotus，深色為 Vibex Dark、Catppuccin Mocha、Gruvbox Dark、Tokyo Night、Nord、Rosé Pine、Everforest Dark、Ayu Dark、Dracula、Kanagawa Wave。你也可以把只寫想改顏色的 JSON 主題檔案放進執行階段 home 目錄的 `themes` 資料夾來擴充列表；檔案裡沒寫的顏色會按它實際所在的背景補齊。

**工作台背景** 可以放一張自己的圖：靜態圖、GIF 或 WebP 動圖，支援 **填充**、**適應** 或 **拉伸**，並有一層可調遮罩。淺色外觀下背景會當作玻璃處理，啟動載入頁始終不透明。圖片按專案圖示同樣的方式匯入，存放在執行階段 home 下。

字型會從系統已安裝的字型中列出，缺失時回退。

## 工作台

| 選項 | 說明 |
| --- | --- |
| **側欄層級** | **會話檢視**（按會話分組）或 **工作區檢視**（按工作區分組）。 |
| **新會話預設位置** | **當前檢出** 或 **新建 Worktree**（中文介面顯示「新建 Worktree」）。 |
| **編輯器視窗** | **內嵌**（在工作台列內嵌開啟，預設）或 **獨立視窗**（彈出為獨立視窗）。預覽面板標題欄的彈出和停靠按鈕寫入同一項設定。 |
| **記住工作台版面** | 記住側欄、預覽、右側欄和分欄版面。 |
| **顯示 Git 變更數量** | 在 Git 圖示上顯示待處理改動數。 |
| **專案覆蓋項** | 清除各專案的版面覆蓋。 |
| **工作區狀態** | 清除記住的工作區選擇。 |
| **重置工作台版面** | 把工作台版面恢復預設。 |
| **自動儲存** | **手動**（只用儲存快捷鍵）、**延遲儲存**（停止輸入後寫回）或 **失焦儲存**（編輯器或視窗失去焦點時寫回）。 |
| **自動儲存延遲** | 停止輸入多久之後寫回，250–5000 毫秒，預設 1000 毫秒；只在 **延遲儲存** 時出現。 |

## 連線

SSH 和 WSL 遠端執行階段是**測試版，預設關閉**。在 **設定 → 開發者 → SSH 遠端執行階段** 開啟後，這個分區才會出現。

開啟後可以：

- **新增 SSH 連線**：從 SSH 配置發現主機，探測環境並開始配置。
- **新增 WSL 執行階段**：選擇本機 WSL2 發行版。
- **初始化 SSH**：為沒有 sshd 的 Linux 主機生成一次性 bootstrap 命令。
- 檢視配置進度、診斷卡、日誌和執行階段相容性。
- 編輯或移除連線，解除安裝遠端執行階段。

完整步驟見[SSH 與 WSL 遠端執行階段](/zh-TW/ssh-runtime)。

## 會話

控制會話內容寬度（窄屏 / 標準 / 全屏）、時間線條目顯示（**會話預覽條**、**Agent 生成狀態**、**推理顯示方式**、**預設展開推理**、**命令卡片渲染**、**檔案編輯卡片渲染**），以及訊息佇列行為：

- **佇列傳送** —— 自動或手動。
- **訊息傳送按鍵** —— Enter 或 Cmd/Ctrl+Enter。
- **自動繼續** —— 讓滿足條件的回合自動推進；無法繼續時會停下來等待你處理。預設開啟。
- **Agent 通知** —— **Agent 完成** / **Agent 需要輸入** / **Agent 失敗** 三類通知開關；**系統通知** 總開關關閉時這三項不可用。
- **已記住的執行階段** / **自動繼續預設項** —— 清除已記住的選擇。
- **Agent 配置** —— 開啟配置中心的 Agent 分區。

## 已歸檔會話

已歸檔會話保留完整時間線，並從側欄移出。這個頁面可以：

- 設定 **自動歸檔** 的空閒視窗（關閉，或 1–14 天）。自動歸檔按專案/資料夾生效，只歸檔空閒、已結束且沒有執行中回合的會話；置頂會話和委派子會話不歸檔。
- 檢視已歸檔會話列表，**恢復** 到側欄，或 **永久刪除**。
- **全部刪除** 已歸檔會話。

歸檔是可逆的；刪除不是。誤歸檔可以在這裡撤銷。

## 終端機

設定預設 shell 和新建終端機的初始目錄（**Worktree** / **專案** / **當前檔案**）。

- 預設 shell 可以從系統檢測到的 shell 中選擇，也可以指定自定義路徑。
- 已開啟的終端機不會因為修改偏好而遷移。
- 滾動緩衝區固定為 10000 行，不可配置。

## 瀏覽器

控制內嵌瀏覽器面板自己的標籤頁：

| 選項 | 說明 |
| --- | --- |
| **起始頁** | Google、Bing、百度或自定義地址。隻影響你新建的標籤頁。 |
| **搜尋引擎** | 位址列輸入關鍵詞時使用；支援 Google、Bing、百度、DuckDuckGo 或自定義模板。 |
| **無損畫面** | 文字更清晰，但畫面更大、更慢；面板上的 HD 按鈕切換同一個設定。 |
| **允許下載** | 預設關閉。開啟後頁面可以儲存檔案到執行階段下載目錄。 |
| **匯入本機 Chrome 登入狀態** | 從 Chrome、Edge 或 Brave 複製 Cookie 與 localStorage 到隔離配置。只讀源配置，不寫回。 |
| **清除瀏覽器資料** | 刪除隔離配置裡的 Cookie、localStorage、快取和已匯入登入狀態；已開啟標籤會關閉。 |

詳見[內嵌瀏覽器](/zh-TW/browser)。

## 電腦操作

電腦操作預設關閉。這個頁面負責：

- 安裝和檢測桌面驅動。
- 檢視作業系統權限（輔助功能、螢幕錄製）。
- 設定核准策略（**允許** / **詢問** / **拒絕**）和是否允許 Agent 操作 Vibex 自身視窗。
- 開啟電腦操作面板，選擇 **視窗** 或 **浮動** 模式。
- 設定單次桌面呼叫的超時。
- 檢視當前平台支援的能力和 Wayland 實驗路徑。

完整說明見[電腦操作](/zh-TW/computer-use)。

## 快捷鍵

所有可重繫結的快捷鍵、預設鍵位和分組見[快捷鍵參考](/zh-TW/reference/shortcuts)。在這裡可以逐項修改，也可以 **重置** 單項或 **全部重置** 全部恢復預設。衝突的鍵位會被拒絕並提示 **快捷鍵無效或已被佔用**。

## 資料與診斷

顯示本地儲存用量明細（資料庫、會話、終端機、附件、診斷、Agent 安裝），並提供逐類清理入口：

| 操作 | 影響 |
| --- | --- |
| **清理會話與附件** | 刪除會話和附件記錄。 |
| **清理終端機資料** | 刪除終端機後設資料。 |
| **清理診斷資料** | 刪除診斷資料。 |
| **資料目錄** | 在檔案管理器中開啟資料目錄。 |
| **開啟用量統計** | 跳轉到用量統計。 |
| **診斷與恢復** | 開啟管理中心，檢視診斷與恢復入口。 |

<Warning>
  這些清理操作是**破壞性**的，且不會回滾。執行前先閱讀[隱私與恢復](/zh-TW/privacy-and-recovery)。
</Warning>

## 開發者

- **幀率監視器**：在工作台顯示幀率和重繪資訊，用於診斷效能。
- **SSH 遠端執行階段**：開啟或關閉 SSH / WSL 連線分區。`VIBEX_SSH_REMOTE_RUNTIME` 環境變數會覆蓋這個開關，並在介面上鎖定它。

## 關於

顯示當前**版本**與**通道**（預覽 / ReleaseCandidate / Stable）、平台資訊、許可證，並提供：

- **軟體更新** —— 更新狀態與操作按鈕（**立即檢查** / **下載更新** / **安裝更新** / **立即重啟** / **打開發行版** / **重試**）。更新清單經過簽名校驗，校驗失敗不會安裝。卡片還會列出 **最新版本**、**釋出時間** 和 **下載大小**，並把該版本的釋出說明渲染成 Markdown（**Vibex 更新內容**）；沒有更新時顯示當前已安裝版本的釋出說明。
- **環境摘要** —— 可複製的不敏感環境資訊，報問題時附上它。
- **原始碼** / **更新日誌** —— 跳轉到倉庫和釋出說明。

報告問題時請附上版本、通道、平台和結構化錯誤碼，不要附上完整日誌。
