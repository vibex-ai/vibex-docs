---
title: "設定"
description: "調整 Vibex 的介面、工作台、會話、終端機、快捷鍵和診斷選項。"
---

開啟 **設定**（`cmd-,`）可以修改桌面端的本機偏好。設定不會取代配置中心中的 Agent、MCP 或技能設定。

頁面頂部有 **搜尋設定** 輸入框，可以依名稱或關鍵字直接跳到某一項。曾修改的選項旁邊會出現 **撤銷變更**。

## 分區

| 分區 | 可調整內容 |
| --- | --- |
| **一般** | 語言、啟動行為、網路代理、通知與更新。 |
| **外觀** | 主題、視窗縮放、介面字型與程式碼字型、動效與對比度。 |
| **工作台** | 側欄檢視、新會話預設位置、預覽視窗位置、版面記憶、Git 變更計數和編輯器自動儲存。 |
| **會話** | 會話內容寬度、時間線顯示、訊息佇列、自動繼續和 Agent 通知。 |
| **終端機** | 預設 shell 和新增終端機的初始目錄。 |
| **快速鍵** | 檢視、修改和重設鍵盤快捷鍵。 |
| **資料與診斷** | 本機儲存用量與清理、診斷與還原入口。 |
| **開發者** | 用於診斷與分析工作台自身的效能：**幀率監視器** 幀率浮層。 |
| **關於** | 版本、通道、軟體更新、授權和平台資訊。 |

## 一般

| 選項 | 說明 |
| --- | --- |
| **語言** | 系統預設 / 简体中文 / 繁體中文 / English。 |
| **關閉視窗後繼續執行** | 關閉視窗後保留在系統匣。 |
| **網路代理** | 讓 Vibex 的網路要求和 Agent 工具走本機或企業代理。支援 `http`、`https`、`socks5`、`socks5h`。啟用前會驗證位址。 |
| **啟動行為** | 啟動後還原工作台，或直接新增會話。 |
| **登入時啟動** | 登入系統時啟動 Vibex。 |
| **系統通知** | 桌面通知總開關。 |
| **自動更新** | 發現已簽署的新版本後立即下載；可以立即安裝，或在結束應用程式時自動安裝。 |
| **更新提示** | 顯示標題列更新按鈕與更新浮層。背景安全檢查始終保持啟用。 |

## 外觀

控制主題模式（跟隨系統 / 淺色 / 深色）、視窗縮放（75%–200%）、**介面字體** 與 **程式碼字體** 的字級和字重、**減少動效** 與 **高對比度**。程式碼字型同時影響程式碼區塊、整合編輯器和終端機。

**主題** 用三張預覽卡片選擇 **跟隨系統** / **淺色** / **深色**，每張卡片都會用該模式解析出的配色畫一個微縮工作台。**淺色主題** 與 **深色主題** 是各自獨立的下拉框，收起狀態和選單裡都顯示色塊與主題名。內建二十套：淺色為 Vibex Light、Catppuccin Latte、Gruvbox Light、Solarized Light、GitHub Light、Rosé Pine Dawn、Everforest Light、Ayu Light、One Light、Kanagawa Lotus，深色為 Vibex Dark、Catppuccin Mocha、Gruvbox Dark、Tokyo Night、Nord、Rosé Pine、Everforest Dark、Ayu Dark、Dracula、Kanagawa Wave。你也可以把只寫想改顏色的 JSON 主題檔案放進執行環境 home 目錄的 `themes` 資料夾來擴充清單；檔案裡沒寫的顏色會按它實際所在的背景補齊。

字型會從系統已安裝的字型中列出，缺少時會回退。

## 工作台

| 選項 | 說明 |
| --- | --- |
| **側欄層級** | **會話視圖**（依會話分組）或 **工作區視圖**（依工作區分組）。 |
| **新會話預設位置** | **目前簽出** 或 **新增 Worktree**（中文介面顯示「新增 Worktree」）。 |
| **預覽視窗** | **內嵌**（在工作台欄內嵌開啟，預設）或 **獨立視窗**（彈出為獨立視窗）。預覽面板標題列的彈出和停靠按鈕寫入同一項設定。 |
| **記住工作台版面** | 記住側欄、預覽、右側欄和分欄版面。 |
| **顯示 Git 變更數量** | 在 Git 圖示上顯示待處理變更數。 |
| **專案覆寫項** | 清除各專案的版面覆寫。 |
| **重設工作台版面** | 把工作台版面還原為預設。 |
| **自動儲存** | **手動**（只用儲存快速鍵）、**延遲儲存**（停止輸入後寫回）或 **失焦儲存**（編輯器或視窗失去焦點時寫回）。 |
| **自動儲存延遲** | 停止輸入多久之後寫回，250–5000 毫秒，預設 1000 毫秒；只在 **延遲儲存** 時出現。 |

## 會話

控制會話內容寬度（窄屏 / 標準 / 全屏）、時間線條目顯示（**會話預覽條**、**Agent 生成狀態**、**推理顯示方式**、**預設展開推理**、**命令卡片渲染**、**檔案編輯卡片渲染**），以及訊息佇列行為：

- **佇列傳送** —— 自動或 手動。
- **訊息傳送按鍵** —— Enter 或 Cmd/Ctrl+Enter。
- **自動繼續** —— 讓符合條件的回合自動推進；無法繼續時會停下來等待你處理。
- **Agent 通知** —— **Agent 完成** / **Agent 需要輸入** / **Agent 失敗** 三類通知開關，已從 **一般** 移到這個分區；**系統通知** 總開關關閉時這三項無法使用。
- **已記住的執行階段** / **自動繼續預設項** —— 清除已記住的選擇。

## 終端機

設定預設 shell 和新增終端機的初始目錄（**Worktree** / **專案** / **目前檔案**）。

- 預設 shell 可以從系統偵測到的 shell 中選擇，也可以指定自訂路徑。
- 已開啟的終端機不會因為修改偏好而遷移。
- 滾動緩衝區固定為 10000 行，無法設定。

## 快速鍵

所有可重新綁定的快捷鍵、預設按鍵和分組請見[快捷鍵參考](/zh-TW/reference/shortcuts)。在這裡可以逐項修改，也可以 **重設** 單項或 **全部重設** 全部還原為預設。衝突的按鍵組合會被拒絕，並提示 **快速鍵無效或已被占用**。

## 資料與診斷

顯示本機儲存用量明細（資料庫、會話、終端機、附件、診斷、Agent 安裝），並提供分類清理入口：

| 操作 | 影響 |
| --- | --- |
| **清理會話與附件** | 刪除會話和附件記錄。 |
| **清理終端機資料** | 刪除終端機中繼資料。 |
| **清理診斷資料** | 刪除診斷資料。 |
| **資料目錄** | 在檔案管理員中開啟資料目錄。 |
| **開啟用量統計** | 跳至用量統計。 |
| **開啟管理中心** | 跳至配置中心。 |

<Warning>
  這些清理操作是**破壞性**的，且不會復原。執行前請先閱讀[隱私與復原](/zh-TW/privacy-and-recovery)。
</Warning>

## 關於

顯示目前的**版本**與**通道**（預覽 / ReleaseCandidate / Stable）、平台資訊、授權，並提供：

- **軟體更新** —— 更新狀態與操作按鈕（**立即檢查** / **下載更新** / **安裝更新** / **立即重新啟動** / **開啟發行版** / **重試**）。更新資訊清單經過簽章驗證，驗證失敗時不會安裝。卡片還會列出 **最新版本**、**發佈時間** 和 **下載大小**，並把該版本的發行說明渲染成 Markdown（**Vibex 更新內容**）；沒有更新時顯示目前安裝版本的發行說明。
- **環境摘要** —— 可複製的不敏感環境資訊，回報問題時請附上。
- **原始碼** / **更新日誌** —— 跳至儲存庫和發行說明。

回報問題時請附上版本、通道、平台和結構化錯誤碼，不要附上完整日誌。
