Vibex 將 Agent 會話、工作區檔案、編輯器、Git、終端機與預覽放進同一個原生工作台。你可以讓 Agent 修改程式碼，再檢查計畫、工具呼叫與差異，最後在同一個工作區裡執行並交付變更。

Vibex 採用**權威執行環境 + 型別化投影**的結構：

- **權威執行環境**持有 Agent 程序、會話時間線、工作區檔案、Git、終端機與供應商憑證。它有兩種形態，能力完全一致：
  - **桌面端內嵌的本機執行環境**（預設）。
  - **無頭執行環境 `vibex-server`**，執行在你自己的伺服器或家用機器上。
- **客戶端**是桌面工作台與 iOS / Android 行動端。它們渲染權威執行環境送來的投影，並傳送型別化操作。行動端不在本機執行 Agent，也不複製一份工作區。

也就是說，桌面端既可以**自己作為權威執行環境**，也可以**連線到遠端權威執行環境**。詳見[遠端存取與行動端](/zh-TW/remote-mobile)和[自託管無頭執行環境](/zh-TW/self-hosted-server)。

## 你可以用 Vibex 做什麼

- 在結構化時間線中查看 Markdown 回覆、推理、計畫、工具呼叫、程序詳情、附件、核准和詢問表單。
- 用 `/` 指令、`@` 檔案引用、`$` Skills 和附件組織 Composer 輸入。
- 讓 Vibex 自行下載、升級和解除安裝受支援的 Agent 執行環境。
- 在檔案樹和編輯器中搜尋、編輯、儲存、重新命名和預覽檔案。
- 查看 Git 狀態、差異、歷史和 blame，建立分支並提交或推送變更；用隔離的 Git worktree 並行推進多個任務。
- 使用帶 ANSI 模擬的原生 PTY，在多個終端機分頁中執行專案命令。
- 設定 Agent、模型供應商、MCP 和 Skills。
- 依時間、Agent、供應商、模型、專案和會話篩選用量，並區分完整、推導、部分和未知資料。
- 跨全部會話和訊息本文搜尋。
- 把桌面端會話安全地配對到行動端，在手機上查看進度、回覆問題和處理核准。
- 把桌面端或行動端配對到自託管的無頭執行環境，從任意裝置繼續同一批會話。
