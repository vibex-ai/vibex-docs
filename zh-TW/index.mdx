Vibex 把 Agent 會話、工作區檔案、編輯器、Git、終端機、內嵌瀏覽器、電腦操作和預覽放進同一個原生工作台。你可以讓 Agent 修改程式碼，再檢查計劃、工具呼叫和差異，最後在同一個工作區裡執行和交付改動。

Vibex 採用**權威執行階段 + 型別化投影**的結構：

- **權威執行階段**持有 Agent 程序、會話時間線、工作區檔案、Git、終端機、瀏覽器、電腦操作、供應商憑據和持久化狀態。它有三種形態，能力一致：
  - **桌面端內嵌的本地執行階段**（預設）。
  - **無頭執行階段 `vibex-server`**，執行在你自己的伺服器或家用機器上。
  - **SSH / WSL 遠端執行階段**，由桌面端在另一臺機器或本機 WSL2 裡配置和管理（測試版）。
- **客戶端**是桌面工作台、iOS / Android 行動端和 **Vibex TUI**。它們渲染權威執行階段發來的投影，併發送型別化操作。行動端和 TUI 不在本地執行 Agent，也不復制一份工作區。

也就是說，桌面端既可以**自己作為權威執行階段**，也可以**連線到一個遠端權威執行階段**。詳見[遠端訪問與行動端](/zh-TW/remote-mobile)、[SSH 與 WSL 遠端執行階段](/zh-TW/ssh-runtime)和[自託管無頭執行階段](/zh-TW/self-hosted-server)。

## 你可以用 Vibex 做什麼

- 在結構化時間線中檢視 Markdown 回覆、推理、計劃、工具呼叫、程序詳情、附件、核准和詢問表單。
- 用 `/` 命令與 Prompt、`@` 檔案與 Agent、`$` 技能和附件組織輸入框的內容。
- 把任務委派給子 Agent，保持任務開啟、追加跟進、接受或取消，並用目標跟蹤長回合。
- 讓 Vibex 自己下載、升級和解除安裝受支援的 Agent 執行階段，並按 Agent 配置模型供應商。
- 在共享 Provider、路由組和本地閘道器之間做故障轉移和協議轉換。
- 在檔案樹和編輯器中搜索、編輯、儲存、重新命名和預覽檔案。
- 檢視 Git 狀態、差異、歷史和 blame，建立分支並提交或推送改動；用隔離的 Git worktree 並行推進多個任務。
- 使用帶 ANSI 模擬的原生 PTY，在多個終端機標籤和分屏中執行專案命令；回滾搜尋、向量製表字元和 Nerd Font 讓表格與狀態圖示對齊。
- 在內嵌瀏覽器裡檢視頁面，讓 Agent 讀取和操作它；在批准後讓 Agent 操作本機桌面。
- 從應用內市場安裝 MCP 伺服器和 Skill，編寫可複用 Prompt，並按 Agent 限定作用域。
- 把訊息排進佇列、引導執行中的回合、安排稍後傳送，或讓自動繼續推進回合。
- 按時間、Agent、供應商、模型、專案和會話篩選用量，並區分完整、推導、部分和未知資料。
- 跨全部會話和訊息正文搜尋，匯入本地 Agent 歷史，歸檔並恢復會話。
- 讓會話以 **終端模式** 執行：對話交給 Agent 自己的 CLI，在原生 PTY 裡進行，已驗證十三款 Agent。
- 把桌面會話安全地配對到行動端，在手機上檢視進度、回覆問題、處理核准和使用終端機。
- 在終端機裡用 TUI 繼續同一批會話，或通過 SSH / WSL / 自託管執行階段從任意裝置繼續工作。
