Vibex 將 Agent 會話、工作區檔案、編輯器、Git、終端機與預覽放在同一個原生工作台。你可以讓 Agent 修改程式碼，再檢查計畫、工具呼叫與差異，最後在同一個工作區中執行和交付變更。

桌面端是 Vibex 唯一的權威執行環境。它負責啟動 Agent、保存會話與時間線、存取檔案與 Git、管理終端機和權限。iOS 與 Android 行動端是遠端伴侶，不會在手機上執行 Agent，也不會複製一份工作區。

## 你可以用 Vibex 做什麼

- 在結構化時間線中查看 Markdown 回覆、推理、計畫、工具呼叫、程序詳情、附件、核准與詢問表單。
- 使用 `/` 指令、`@` 檔案引用、`$` Skills 與附件組織 Composer 輸入。
- 在檔案樹與編輯器中搜尋、編輯、儲存、重新命名與預覽檔案。
- 查看 Git 狀態、差異、歷史與 blame，建立分支並提交或推送變更。
- 使用支援 ANSI 模擬的原生 PTY，在多個終端機分頁執行專案命令。
- 設定 Agent、模型供應商、MCP、Skills、Prompts、Hooks、排程任務與自動化圖。
- 依時間、Agent、供應商、模型、專案和工作階段篩選用量，並區分完整、推導、部分和未知資料。
- 將桌面端會話安全配對到行動端，在手機上查看進度、回答問題與處理核准。
