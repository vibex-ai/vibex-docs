title: "快速開始"
description: "安裝 Vibex，連上一個 Agent，完成第一次會話。"

這篇指南帶你安裝桌面端、加入一個 Agent、開啟專案目錄，然後讓 Agent 完成一個可檢查的小任務。第一次嘗試建議使用一個可丟棄的 Git 儲存庫。

## 1. 安裝桌面端

從 [GitHub Releases](https://github.com/vibex-ai/vibex/releases/latest) 下載與你平台相符的安裝套件並安裝。完整說明和各平台注意事項見[安裝](/zh-TW/install)。

<Note>
  macOS 和 Windows 的安裝套件目前沒有程式碼簽章，首次開啟會被 Gatekeeper 或 SmartScreen 攔一下。放行方法見[安裝](/zh-TW/install)。
</Note>

## 2. 加入一個 Agent

第一次啟動時，Vibex 會顯示 **Start something new** 頁面。沒有可用 Agent 時會提示 **No Agent has been added. Open Config Center to add one.**，點擊 **Add Agent** 進入 Config Center。

1. 在 **Agent** 分頁的清單中找到你想用的 Agent。內建預設包括 **Claude Code**、**Codex**、**ZCode** 和 **OpenCode**，另有十多個 ACP 整合。
2. 點擊項目右側的 **+** 將它加入。加入後項目會顯示啟用開關。
3. 如果該 Agent 由 Vibex 託管且尚未安裝，安裝卡片會顯示 **Install**。點擊後 Vibex 會下載並驗證執行環境；安裝過程中不能取消，裝好後按鈕會變成 **Check for updates**。
4. 如果項目顯示 **Managed by user**，代表它不在託管目錄裡，Vibex 會直接使用你 `PATH` 上的同名命令列程式——你需要先自行安裝好它。

接著展開詳細頁裡的 **Native credentials** 卡片完成登入（`Sign in` / `Open sign-in terminal`），再在 **Model provider configuration** 卡片裡設定模型供應商和憑證。

## 3. 開啟一個專案目錄

1. 在側欄點擊 **New project**，或使用 **New chat** 頁面上的 **Project directory**。
2. 在彈出的目錄瀏覽器裡選擇儲存庫根目錄，確認。
3. 第一次嘗試請使用測試分支或臨時儲存庫——Agent 會實際修改磁碟上的檔案。

## 4. 完成第一次會話

1. 在 Composer 頂端選擇 Agent、供應商設定、模型和**思考深度**。
2. 輸入一個範圍明確的任務，例如「在 `README.md` 中補充安裝步驟，並先顯示計畫」。
3. 查看時間線中的計畫和工具呼叫。需要檔案、終端機或權限時，Vibex 會顯示具體請求，你可以 **Approve** 或 **Deny**。
4. Agent 完成後開啟 **Git** 面板檢查 **Changes**，逐處確認變更，再決定是否提交或繼續追問。

<Tip>
  第一次任務先要求 Agent 提出計畫，再允許它修改檔案。這樣你能在時間線裡確認範圍和風險。
</Tip>

<Warning>
  **Stop** 只停止執行，不會復原已經寫入的檔案或已經執行的命令。停止後請在 Git diff 和終端機裡分別確認結果。
</Warning>

## 了解 Composer 輸入

在 Composer 中可以組合多種上下文：

| 寫法 | 作用 |
| --- | --- |
| `/` | 選擇可用的 Prompt 或 slash command。 |
| `@` | 從目前專案引用檔案或目錄。 |
| `$` | 插入已啟用的 Skill。 |
| 附件按鈕 | 加入圖片等會話附件。 |

傳送前可以選擇 Agent、供應商設定、模型、思考深度和對話模式。不同 Agent 支援的選項不同，介面會根據執行環境探測結果顯示可用項目。
