## 必須維持的約束

- 桌面端負責 Agent、會話、時間線、檔案、Git、PTY、Provider、權限和持久化。
- 行動端只消費共享遠端投影並傳送型別化操作，不複製業務狀態。
- Remote v2 的 DTO、錯誤、能力與序號契約位於共享 core 層。
- Relay 只轉發加密框，不擁有業務授權、檔案或會話資料庫。
- 跨層行為變更需補充確定性檢查或證據，並執行與風險匹配的測試集。
