## 工具鏈

| 工具 | 版本或說明 |
| --- | --- |
| Node.js | 22 |
| pnpm | 11.3.0，由 `package.json` 的 `packageManager` 欄位宣告 |
| Rust | 1.97.0，由 `rust-toolchain.toml` 固定 |
| Git | 用於克隆倉庫 |
| Linux 圖形 | 可用的 Vulkan 驅動和圖形會話 |

```bash
git clone https://github.com/vibex-ai/vibex.git
cd vibex
pnpm install --frozen-lockfile
```

## 啟動桌面端

```bash
pnpm dev:desktop
```

指令碼會準備開發圖示並執行 `vibex-desktop`。單獨檢查 Rust 時：

```bash
cargo check -p vibex-desktop --locked
cargo test -p vibex-desktop --locked
pnpm smoke:first-frame
```

TUI 可以直接從工作區執行：

```bash
cargo run -p vibex-tui -- --home /tmp/vibex-dev
```

內嵌瀏覽器需要本機安裝 Chrome、Chromium 或 Edge；電腦操作需要安裝驅動並在設定裡開啟。兩者都不是編譯依賴，但相關 smoke 和手動驗證需要它們。

## 可選：行動端環境

- **Android** —— Android SDK/NDK、`cargo-ndk`，以及目標 ABI 的 Rust targets。
- **iOS** —— macOS、Xcode、XcodeGen，以及 `aarch64-apple-ios` 和 `aarch64-apple-ios-sim` targets。

## 可選：自託管環境

本地開發需要一個可執行的 Rust 二進位制或 Docker：

```bash
docker compose -f deploy/relay/docker-compose.yml up --build -d relay-server
docker compose -f deploy/server/docker-compose.yml up --build -d vibex-server
curl -fsS http://127.0.0.1:9700/health
curl -fsS http://127.0.0.1:8765/api/v2/info
```

注意兩個服務的資訊端點不同。網路、HTTPS、Tailnet 和環境變數見[自託管無頭執行階段](/zh-TW/self-hosted-server)與[自託管 Relay](/zh-TW/relay)，協議細節見 [Remote v2 與 Relay](/zh-TW/developer/remote-protocol)。

## 桌面端除錯開關

```bash
VIBEX_DISABLE_REMOTE_CLIENT=1 pnpm dev:desktop   # 忽略已儲存的遠端憑據，強制使用本地執行階段
VIBEX_HOME=/tmp/vibex-dev pnpm dev:desktop       # 使用獨立的執行階段 home
VIBEX_PROVIDER_SECRET_STORE=file pnpm dev:desktop # 沒有鑰匙串時改用主機金鑰檔案
```

`vibex-desktop` 還提供若干探針入口（`--probe`、`--spike-*`、`--native-content-*`）。這些是開發者工具，不是使用者功能，不要在文件裡把它們當作產品能力。

## 倉庫約定

在倉庫根目錄執行指令碼。

- 不要提交 `target`、簽名包、PDFium 執行階段或本機憑據。
- 改動產品倉庫前，先確認工作樹中已有的未提交改動並保留它們。
- 使用者可見行為的改動需要同步更新三語文件，見[貢獻程式碼](/zh-TW/developer/contributing)。
