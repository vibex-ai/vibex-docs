Vibex 的终端使用原生 PTY 和 ANSI 仿真，适合运行开发服务器、测试和 Git 命令。终端由**权威运行时**承载，因此移动端也能在获得权限后使用同一批终端。

## 打开终端

从右侧栏的 **新建终端** 图标打开，或在文件树里对某个路径选择 **Open In → 终端** 让终端以该目录为初始工作目录。

```bash
git status --short
pnpm test
```

输入框上方的终端按钮会打开一个**底部终端面板**，用 `cmd-shift-t` 在对话和终端之间切换。面板铺满工作台宽度，不再挤在输入框里。

## 终端操作

| 能力 | 说明 |
| --- | --- |
| 标签 | 新建、关闭、重命名（**重命名终端** / `Terminal name`）和切换。 |
| 分栏 | 标签菜单提供 **向右拆分** 和 **向下拆分**，分栏边界可拖动。 |
| 调整尺寸 | 拖动面板边界，PTY 会收到最新的 rows/columns；面板会立刻铺满新尺寸，不会停在旧网格上等往返完成。 |
| 滚动缓冲区 | 固定 **10000 行**，不可配置。 |
| 搜索 | **Search terminal** 打开搜索栏，显示 `0 matches` 或 `{n} / {total}`。搜索覆盖每一条保留的行，而不只是已绘制的视口；**上一个匹配** / **下一个匹配** 会把命中滚动到视野内。 |
| 滚动 | 网格右侧有可拖动的滚动条；`shift-pageup` / `shift-pagedown` 与 `shift-home` / `shift-end` 也能滚动。在备用屏（全屏 Agent）里滚轮会转成方向键。 |
| 复制粘贴 | 工具栏 **复制** / **粘贴**，或 `ctrl-shift-c` / `ctrl-shift-v`。双击选中一个词，三击选中一行。 |
| 搜索快捷键 | `ctrl-shift-f`。 |
| 打开链接 | 光标悬停在超链接上时出现 **Open link**；纯 `http(s)` 地址点击即打开。 |
| 状态 | 标签上显示 `running`、`exited`、`killed` 或 `stale`。 |

终端按原始字节处理输出和 ANSI 控制序列，不会把二进制输出当作文本。

### 渲染

- **制表字符**（Box Drawing）按笔画画成相连的矢量线，包括粗线、双线、虚线、圆角和斜线形态，因此表格和面板边框跨单元格对齐。
- **`Symbols Nerd Font Mono`** 随应用发布，私用区符号字形贴合单元格轮廓，Agent 的状态图标不再画成方块。
- 单元格度量取自字体自身的步进，而不是固定的 8×18 常量；宽字符保留字体的步进，因此 CJK 仍占两列。
- **连字** 是偏好项，在 **设置 → 外观 → 连字** 里开关。关闭时每个字符各占一格，对齐列的输出依赖这一点。
- 终端背景可以设透明度（**设置 → 外观 → 终端不透明度**，60%–100%）；主题墨色会被提亮到最低对比度，而程序自己声明的真彩不受影响。

### 终端协议支持

除了常规的 ANSI 序列，终端还回应：

- **OSC 52** 剪贴板读写，因此 SSH 和 tmux 里也能复制。
- **OSC 0 / 2** 窗口与标签标题。
- **OSC 4 / 10 / 11 / 12** 颜色查询。
- **鼠标上报** 的 1005、1015 和 1016 三种方言。

## Shell 选择

工具栏提供可用的 shell，选中后会切换当前标签的 shell：

- Windows：**PowerShell**、**命令**。
- 其它平台：**bash**、**zsh**、**fish**（只列出系统上实际存在的）。

每个标签可以独立选择 shell。修改默认 shell 见[设置](/settings)。

## 与 Agent 配合

Agent 请求运行命令时，时间线会显示进程详情和退出结果。命令可能等待权限批准；批准前请检查命令、工作目录和参数。

<Warning>
  终止终端进程不会撤销它已经完成的外部操作。停止 Agent 也不会回收它已经建立的终端。
</Warning>

## 陈旧终端

权威运行时重启后，终端会话内容不会保留（只保留标签元数据）。丢失的终端会被标记为 `stale`。

遇到 `stale` 时，请重新打开标签并以新的快照为准，**不要**根据旧快照重复执行命令。

## 移动端终端

移动端收到的是终端快照和经过授权的输入通道，输入会带工作区作用域、generation 检查和审计记录。网络中断时，移动端不会假设命令已经执行，重连后以权威端的快照为准。

## TUI 与 SSH

Vibex TUI 是终端里的客户端，不是终端标签的替代品：它把会话、审批、队列和设置都画在字符网格里，适合通过 SSH 或 tmux 使用。它随桌面安装包发布，运行 `vibex` 即可；详见 [Vibex TUI](/tui)。

TUI 的复制使用 OSC 52，所以在 SSH 和 tmux 里也能工作。它不会接管桌面端已经打开的终端标签，两者是同一运行时的不同客户端。

<Note>
  终端输出可能包含密钥、路径和用户数据。不要把完整终端输出复制到公开 Issue、日志或诊断资料中。
</Note>
