---
title: "终端"
description: "在原生 PTY 中运行命令，并与 Agent 共享终端会话。"

Vibex 的终端使用原生 PTY 和 ANSI 仿真，适合运行开发服务器、测试和 Git 命令。终端由**权威运行时**承载，因此移动端也能在获得权限后使用同一批终端。

## 打开终端

从右侧栏的 **New terminal** 图标打开，或在文件树里对某个路径选择 **Open In → Terminal** 让终端以该目录为初始工作目录。

```bash
git status --short
pnpm test
```

Composer 上方还有一个**内嵌终端面板**，可以用 `cmd-shift-t` 在对话和终端之间切换。

## 终端操作

| 能力 | 说明 |
| --- | --- |
| 标签 | 新建、关闭、重命名（**Rename terminal** / `Terminal name`）和切换。 |
| 分栏 | 标签菜单提供 **Split right** 和 **Split down**，分栏边界可拖动。 |
| 调整尺寸 | 拖动面板边界，PTY 会收到最新的 rows/columns。 |
| 滚动缓冲区 | 固定 **10000 行**，不可配置。 |
| 搜索 | **Search terminal** 打开搜索栏，显示 `0 matches` 或 `{n} / {total}`。**只支持下一个匹配**，循环前进。 |
| 复制粘贴 | 工具栏 **Copy** / **Paste**，或 `ctrl-shift-c` / `ctrl-shift-v`。 |
| 搜索快捷键 | `ctrl-shift-f`。 |
| 打开链接 | 光标悬停在超链接上时出现 **Open link**。 |
| 状态 | 标签上显示 `running`、`exited`、`killed` 或 `stale`。 |

终端按原始字节处理输出和 ANSI 控制序列，不会把二进制输出当作文本。

## Shell 选择

工具栏提供可用的 shell，选中后会切换当前标签的 shell：

- Windows：**PowerShell**、**Command**。
- 其它平台：**bash**、**zsh**、**fish**（只列出系统上实际存在的）。

每个标签可以独立选择 shell。修改默认 shell 见[设置](/settings)。

## 与 Agent 配合

Agent 请求运行命令时，时间线会显示进程详情和退出结果。命令可能等待权限批准；批准前请检查命令、工作目录和参数。

<Warning>
  终止终端进程不会撤销它已经完成的外部操作。停止 Agent 也不会回收它已经建立的终端。
</Warning>

## 陈旧终端

权威运行时重启后，终端会话内容不会保留（只保留标签元数据）。丢失的终端会被标记为 `stale`。

遇到 `stale` 时，请重新打开标签并以新的快照为准，**不要**根据旧快照重复执行命令。

## 移动端终端

移动端收到的是终端快照和经过授权的输入通道，输入会带工作区作用域、generation 检查和审计记录。网络中断时，移动端不会假设命令已经执行，重连后以权威端的快照为准。

<Note>
  终端输出可能包含密钥、路径和用户数据。不要把完整终端输出复制到公开 Issue、日志或诊断资料中。
</Note>
