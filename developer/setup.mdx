## 工具链

| 工具 | 版本或说明 |
| --- | --- |
| Node.js | 22 |
| pnpm | 11.3.0，由 `package.json` 的 `packageManager` 字段声明 |
| Rust | 1.97.0，由 `rust-toolchain.toml` 固定 |
| Git | 用于克隆仓库 |
| Linux 图形 | 可用的 Vulkan 驱动和图形会话 |

```bash
git clone https://github.com/vibex-ai/vibex.git
cd vibex
pnpm install --frozen-lockfile
```

## 启动桌面端

```bash
pnpm dev:desktop
```

脚本会准备开发图标并运行 `vibex-desktop`。单独检查 Rust 时：

```bash
cargo check -p vibex-desktop --locked
cargo test -p vibex-desktop --locked
pnpm smoke:first-frame
```

## 可选：移动端环境

- **Android** —— Android SDK/NDK、`cargo-ndk`，以及目标 ABI 的 Rust targets。
- **iOS** —— macOS、Xcode、XcodeGen，以及 `aarch64-apple-ios` 和 `aarch64-apple-ios-sim` targets。

## 可选：自托管环境

本地开发需要一个可运行的 Rust 二进制或 Docker：

```bash
docker compose -f deploy/relay/docker-compose.yml up --build -d relay-server
docker compose -f deploy/server/docker-compose.yml up --build -d vibex-server
curl -fsS http://127.0.0.1:9700/health
curl -fsS http://127.0.0.1:8765/api/v2/info
```

注意两个服务的信息端点不同。网络、HTTPS、Tailnet 和环境变量见[自托管无头运行时](/self-hosted-server)与[自托管 Relay](/relay)，协议细节见 [Remote v2 与 Relay](/developer/remote-protocol)。

## 桌面端调试开关

```bash
VIBEX_DISABLE_REMOTE_CLIENT=1 pnpm dev:desktop   # 忽略已保存的远程凭据，强制使用本地运行时
VIBEX_HOME=/tmp/vibex-dev pnpm dev:desktop       # 使用独立的运行时 home
VIBEX_PROVIDER_SECRET_STORE=file pnpm dev:desktop # 没有钥匙串时改用主机密钥文件
```

`vibex-desktop` 还提供若干探针入口（`--probe`、`--spike-*`、`--native-content-*`）。这些是开发者工具，不是用户功能，不要在文档里把它们当作产品能力。

## 仓库约定

在仓库根目录执行脚本。

- 不要提交 `target`、签名包、PDFium 运行时或本机凭据。
- 改动产品仓库前，先确认工作树中已有的未提交改动并保留它们。
- 用户可见行为的改动需要同步更新三语文档，见[贡献代码](/developer/contributing)。
