## 亮点

* **用所点名的 chip 调校被委派的 Agent** — 输入框的运行时级联跟随光标：落在 `@Agent` chip 上时，Provider、模型、思考档位、对话模式和功能开关编辑的是这位协作者；移开光标就回到会话。调校值编码进 chip 的 token id，草稿、剪贴板和远程客户端都能还原同一份配置。
* **抓取的 Provider 模型先挑选再导入** — 模型标签页打开选择器，被宣传的每个模型是一行；确认之前不写入，确认时只加入所选行，不覆盖你手写的模型。`autoRefreshModels` 现在只决定厂商的新行是否默认勾选。
* **父 Agent 可以回答自己子任务的审批** — 被委派的子 Agent 继承了父级的沙箱与工具集，因此批准它的常规命令不会扩大权限。`vibex_read_approvals` 让父级先在不信任围栏内读卡片，`vibex_decide_approval` 只能批准或拒绝，不可逆操作仍由人决定。
* **转录有了右键菜单与折叠** — 用户消息、Agent 回答、选区、过程行、回合标题和时间线都能右键；**自动折叠工具调用** 把进行中的工具活动画成一行摘要，展开后才显示调用。折叠偏好默认关闭。
* **被停止的委派不会再冻住输入框** — 取消任务会关闭子任务提出的审批卡片，裁决会读取取消围栏，迟到的审批以 `task_cancelled_before_approval` 作答；发送前队列的派发围栏改为按会话区分。

## 新功能

**会话转录**

* 右键菜单可以复制、引用到输入框、在该行分叉、编辑并重发、停止正在流式输出的回答；过程行可以复制命令、输出、输入、diff 或路径并打开文件；选区可以按文本或 Markdown 复制、引用、查找并打开一个外部链接。
* 菜单携带自己要操作的数据，因此即使在分组面板或只读的子 Agent 侧栏上打开，也作用于它被打开的那份转录；子 Agent 侧栏只保留复制和引用。
* 会话设置新增 **自动折叠工具调用**。开启后，进行中的工具活动只画一行摘要——改动文件、命令、读取和失败的数量——展开后才显示具体调用；含待审批行的运行保留实时规则。
* 该偏好保存在 `SessionUiState`，通过 `AgentTimelineDisplaySettings` 同步到移动端与远程，并参与回合形状键与高度指纹。

**Provider 与 Agent**

* 已保存 Provider 的模型标签页改为选择器：左侧是抓取到的模型、复选框和过滤，右侧是所选模型的设置；确认只加入所选模型，已有行保留能力、显示名称和启用状态。
* 选择器是完整的双栏界面，占用整个窗口并逐帧读取视口，打开期间的缩放会被跟随；关闭某行时通过与设置栏关闭按钮相同的命令收起设置栏。
* 两个编写对话框改为在各自栏内滚动：滚轮落在哪一栏就只移动哪一栏，不再带动表单带或整个对话框页面。
* Agent 页面的 **自定义 Provider** 与 **新建路由组** 固定在图库下方的独立条带里，较长的 Provider 图库不会再把它挤到折叠线以下。
* `vibex_read_approvals` 返回调用者自己的子任务所停驻的卡片——标题、风险类别、截止时间和围栏内详情；不带 `taskRefs` 时报告所有等待项。`mayAnswer` 与裁决执行相同的规则，不可逆操作会直接读作需要人决定。
* 只有继承了父级沙箱与工具集的被委派子任务才能被回答，且只能由该任务自己的父级回答；同级或更上层会被拒绝。拒绝会让卡片保持待处理，每次裁决都会记录作出者。

**委派与协作**

* chip 把思考档位、对话模式和功能值编码进 token id，解析器既接受精确的选项引用，也接受应用请求覆盖项后匹配目录条目的引用。
* 没有独立面板或模式：光标落在 `@Agent` chip 上就编辑该协作者，移开或删除 chip 就是退出手势。每个 Agent 的选择映射及其读取规则已删除。
* 选择 `@Agent` 行后光标落在 chip 右边缘，一次 Enter 既选中协作者又打开其参数；新建会话页面新增 **委派给** 徽章。
* 新会话按草稿所指的配置启动；第一条消息会带上 chip 的提及，立即发送不再丢弃它。
* Provider 菜单从 chip 自身的 Agent 与认证来源打开；chip 写入器跟随所选 Agent 的 id 与名称。
* 调校会随委派进入子任务，并写入与会话切换相同的偏好存储，下一次输入 `@` 时构建的行会带上这份配置。

## 修复

* 取消任务不再死锁会话：审批卡片随取消关闭，迟到的审批不会执行被停止的工作，发送前队列的派发围栏按会话隔离。
* 从 POSIX shell 回显的 Windows 路径（`/C:/...`）与编辑器位置（`:line`）可以正确打开；工作区根目录按同样方式归一化，`file:` URL 与 POSIX 绝对路径不受影响。
* 移除远程实例后列表立即更新，不再等到下一次刷新。
* chip 的选区不再多出一个字符，编辑中的 chip 会画出选中态；新建会话页面的 chip 也会让页面进入编辑。
* 已结算的回合不会被停止操作重写，迟到的结果会标记为迟到。

## 性能

* 关闭的运行时菜单不再逐帧重建：Provider 与模型面板只在弹出层打开或播放退出动画时构建，指针划过转录时不再反复遍历并复制整个模型目录。

## 内部、构建与文档

* 版本号升到 `0.1.6`。
* 未调校的 chip 仍保留原来的精确 id，因此旧草稿和旧的 `@Agent` token 仍可解析。
