## 亮点

* **Agent 会话进入真实终端** — 会话可以创建为终端模式：Agent 自己的 CLI 在 PTY 里拥有整段对话，而不是由 Vibex 绘制时间线。13 款 Agent 已通过验证，侧栏、搜索、通知、移动端和 TUI 仍在同一行上工作。
* **终端网格读起来像终端** — 回滚区搜索与匹配跳转、可拖动滚动条、按笔画绘制的制表符、内置 Symbols Nerd Font、连字、URL 点击打开、OSC 剪贴板与标题，以及三种规范的鼠标上报。
* **MCP 服务器送达原生 CLI** — 你配置的 MCP 服务器、Vibex 委派、嵌入式浏览器和电脑操控，通过每个终端模式 CLI 真正读取的启动输入交给它，凭据不会进入 argv。
* **应用退出后不再留下进程** — 游离的 Agent 守护进程按它运行的内容回收，电脑操控驱动在空闲五分钟后归还内存，被遗弃的帧泵自行退休。
* **gpui-kit 0.9.0** — 工作区升级到新套件与 `gpui-pre` `0.3.11`，并用上两项能力：编辑器查找栏的总览标尺，以及两个客户端都跟随减少动效的光标。
* **会自己组装的发布页** — 发布任务从打标签的说明、运行实际产出的资产和 GitHub 贡献者名单合成一页；macOS 应用包做 ad-hoc 签名，Gatekeeper 不再称它已损坏。

## 新功能

**终端会话**

* `SessionTransport` 命名会话的运行方式：ACP 会话拥有时间线与运行时绑定，终端会话启动 CLI 且两者都不拥有。终端创建是独立入口，不是 ACP 创建上的一个标志。
* 13 款 Agent CLI 通过终端模式验证：Claude、Codex、OpenCode、Gemini、pi、Grok、Cline、Copilot、Cursor、Kimi、CodeBuddy、Devin 和 Hermes。每款的提示接口、模型 / 档位 / 模式参数、重启命令和退出提示都集中在一张 `TerminalCli` 表里。
* 配置的模型随命令行传递，因为终端会话没有别的通道；Agent 默认不传任何 id，未知参数则不传。终端模式只携带 Provider Profile，切换器会直接说明这一点。
* 新会话草稿作为位置参数提示传给 CLI，附件以路径跟随，因此 Agent 从你已经描述的那一轮开始。
* 终端网格之外仍欠读者的信息记录为观察事实：存活、活动、Agent 自己的会话 id，以及未读与通知路径读取的时间戳。`Unknown` 是一等值，因为 CLI 等待审批时声称空闲会误导读者。
* 活动从屏幕底部读取而不是视口，向上滚动不会改变 Agent 正在做什么；`working -> idle` 需要多次一致的扫描，因为它是触发完成通知的依据。
* 进程结束的会话会被关闭而不是看起来仍然健康；重启会重新提供同一份 argv、工作目录和 Provider Profile，Profile 会重新解析，密钥留在钥匙串。
* 桌面端把网格包进圆角的嵌入式窗口，选择模式时输入框会变成终端自己的形状；手机可以选择终端会话并通过常规路径附着；TUI 用与桌面端相同的投影报告活动，对无法显示的时间线则点名桌面端。

**终端渲染**

* 搜索覆盖所有保留行而不只是已绘制的视口，高亮全部匹配，并用上一个 / 下一个把匹配滚进视野。
* 网格上有可拖动滚动条，支持 `Shift+PageUp/PageDown`、`Shift+Home/End`；备用屏幕里的滚轮会变成方向键，全屏 Agent 因此可以滚动。
* Box Drawing 字符按笔画绘制成相连的矢量线，覆盖粗线、双线、虚线、圆角和斜线，表格与面板边框跨单元格对齐。
* 随应用发布 `Symbols Nerd Font Mono`，私有区符号按单元格轮廓适配，消除 Agent 状态图标画出的豆腐块。
* 单元格尺寸取自字体自身的步进而不是固定的 8x18，行按 run 塑形而不是逐个字形，宽单元格保留字体步进，CJK 仍占两列。
* 连字是偏好项，纯 HTTP(S) URL 点击打开，双击或三击选择单词或整行。
* 应答 OSC 52 剪贴板读写、OSC 0/2 标题、OSC 4/10/11/12 颜色查询，以及 1005、1015、1016 三种鼠标上报；新增终端背景不透明度，主题墨色抬到最低对比度，同时保留程序自己的真彩色。

**MCP 送达与桌面端**

* 终端模式 CLI 通过各自读取的附加启动输入收到 MCP 服务器：Claude Code 与 CodeBuddy 用 `--mcp-config`，Copilot 用 `--additional-mcp-config`，Codex 用 `-c` 覆盖，OpenCode 用 `OPENCODE_CONFIG_CONTENT`，Hermes 用受管作用域，Cline 用 `CLINE_MCP_SETTINGS_PATH`，pi 用进程环境。
* Provider 投影迁移 Agent home 时，真实 home 里的服务器会被重新声明，不会丢失。
* 凭据不进 argv：文件在按会话创建、随会话删除的目录里且权限为 `0600`，Codex 收到的是环境变量名而不是值；创建、重启和崩溃恢复时都会重新生成。
* Cursor、Gemini、Grok、Kimi Code 和 Devin 没有按进程的 MCP 输入，因此终端模式下两个工具面板会显示为不可用，而不是宣称可用后静默丢弃。
* 侧栏会话过滤改为多选集而不是单一姿态，第二个过滤会加宽列而不是清空它；项目内会话可以按创建、更新、标题或手动顺序排序，置顶会话留在上方独立分组。
* `@` 文件提及列表里输入路径会直接浏览该目录，大工作区里深层目录也能到达。
* 每个 Agent 的委派行保留自己的运行时配置，由该行的编辑按钮选择，优先于默认来源和 Agent 上次使用的组合；它不会跟随最后一次会话选择，因为委派是另一个决定。
* 电脑操控面板在 Agent 开始驱动时浮出，不抢键盘，有独立的默认开启设置；被拒绝的调用不会弹出面板，已在屏幕上的面板保持不动。
* 不属于任何项目的会话在侧栏、右键菜单、新建会话选择器和搜索里读作 **临时会话**，绿色火花按规则解析而不是存成默认图标。
* 新建会话页面可以提供 Adapter 仍在下载的 Agent，脉冲画在 Agent 自己的标记轮廓里，顶部中央的卡片指向配置中心；下载完成后同一个按钮会立即创建会话。
* 传输切换器移出输入框，放到工作区行的最远端，因为“谁拥有界面”不是另一个“在哪里运行”；没有终端模式的 Agent 会完全隐藏它。
* 输入框占位文字说明快捷短语、引用和历史，`@` 弹出层把会话引用画在独立标签页；编辑器查找栏在总览标尺上标出每个命中，关闭查找栏会清掉标记。
* 运行时失败以顶部轻提示到达，一个 Agent 的失败读作一条提示并带可复制详情，失败的回合不再在输入框的错误条里重复。

**移动端与 TUI**

* 减少动效到达 gpui 自己的标志，询问上下文的套件组件停止动画，光标在主题与输入框绘制的基础层里都保持静止。
* 打开的会话保留自己的工作区与对话：先按会话行重定向导轨再读快照，读取失败不会把上一个会话的文件、改动和终端留在新页面下。
* 不得不切掉实时回合的时间线窗口会在没有回合带的情况下重试，三个壳都安装连续的窗口，而不是在从未空过的会话上画“还没有消息”。
* 手机终端的 Backspace 能到达 shell：IME 接收器保留一个空格，并从它转发的变更里重新播种，按住或快速 Backspace 会按真正要被编辑的文档计算。
* TUI 在运行时探测应答后刷新运行选项，迟到的探测不再让页面停在旧目录上。

## 性能

* 终端网格按文本、样式和尺寸缓存塑形后的行，只通过预绘制缓存重塑受损行，并按 run 绘制每一行而不是逐字定位。
* 调整窗口大小会立刻填满窗格，而不是等往返结束才更新；整趟绘制被裁剪到网格自己的内容遮罩。
* 配置中心写入、Provider 探测、路由组保存、网关读取和终端启动 / 重启都移出帧线程，并有源检查在跨线程语句写错时失败。
* 电脑操控驱动在空闲五分钟后停止：先 `stop` 让它移除自己的 socket，不离开再杀掉；只停止本客户端启动的守护进程。
* 帧泵在每次捕获前检查接收者是否仍在，无人观看时自行退休并关闭通道；失败的捕获以倍增延迟重试，上限十秒。
* 短命的驱动子命令领导自己的进程组，超时会杀掉整组，超时不再留下等待守护进程的孤儿。
* 游离的 Agent 守护进程按运行内容回收：候选由 init 或用户的 `systemd --user` 接管，命令行指向 `<home>/acp-agents/agents/<agent>/` 下的文件；只有同一 Agent 在任何地方都不再挂有进程并持续两分钟后才结束它。

## 内部、构建与文档

* 版本号升到 `0.1.0-rc.10`；数据库模式从 87 到 88，会话行新增 `transport`，并新增 `session_terminals` 关联表。
* 工作区升级到 `gpui-kit` `0.9.0` 与 `gpui-pre` `0.3.11`；默认主题的 diff 状态色跟随套件新的绿 / 琥珀 / 红家族并新增 `deleted` 色。
* 内置 Symbols Nerd Font 登记为已审核字体输入，与其他内嵌字体走同一套来源门。
* Agent 固定版本移到各通道发布的版本，包括 Claude `0.101.0`、Codex `2.5.0`、OpenCode `2.2.6`、Cursor `2026.11.05`、Gemini `0.67.0`、Grok `1.0.78` 和 Kimi `2.5.2` 等，各自保留上一个版本作为兼容下限。
* `_session/steering` 接受 `queued` 与 `startedNewTurn` 作为 Agent 已拥有文本的答案，避免同一消息被提交两次。
* 用户可见文本不再被替换成 `[redacted-sensitive-output]`：厂商拒绝、权限标题、模型 id、网关与浏览器账本、类型化表单值和 Provider 端点都保留，密钥引用仍是存储边界。
