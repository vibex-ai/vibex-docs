## 亮点

* **本地模型网关** — 一个回环端点挡在所有共享 Provider 前面。它说 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Google Generative AI 四种协议，在它们之间翻译，并把每次调用转给服务所请求模型的 Provider。
* **会故障转移的路由** — 一条路由是一个可选择的模型。你可以用整个 Provider 或 `(Provider, model)` 组合它，选七种策略之一，并在某个成员无法作答时让网关移到下一个。
* **重建的 Provider 工作区** — Providers、路由组和网关共享一个工作区，带可折叠侧栏、身份头和原地编辑。手写配置的 Provider 会成为可复用模板，预设模型列表来自 models.dev 目录。
* **SSH 与 WSL 远程运行时** — 桌面端可以把权威运行时放到另一台机器：通过 SSH 安装 `vibex-server`、打开隧道、自动配对，并用保留运行时身份的版本回滚升级。
* **会自己发布的托管产物** — Linux x86_64/aarch64 与 macOS 的无头服务端产物在固定 Debian 12 构建器里生成，发布把稳定镜像镜像到 Docker Hub 与 CNB，AUR 包重新发布 Linux `.deb`，Linux 载荷缩小约三分之一。
* **时间线读起来像文档** — 工具调用按结构渲染而不是 JSON：路径与值字段、待办清单、提问列表，以及作为 diff 的编辑。回合头先讲意图、结果和耗时。
* **每个印出来的键都是按钮** — TUI 里的 `键 标签` 图例就是控件：点击会通过与键盘相同的分发器按下它命名的键。
* **多出十位守护者** — 新建会话的竞技场从六场遭遇扩展到十六场，每位守护者有自己的入场、路线节奏和同伴效果。

## 新功能

**本地模型网关**

* 一个回环端点服务四种编码 Agent 已经在说的协议，并通过单一的中间表示翻译，包括跨流式形状重新编码的工具调用。
* 一段对话停留在持有其提示缓存的 Key 上，固定 Key 不会带来缓存未命中；路由状态（冷却、固定、轮换、在途）不进入 Agent 进程指纹，更换 Key 不会重启进程。
* 并发与请求速率按 Key 设限：通道限制在途请求，满通道在有界 FIFO 队列里等待，之后才回答 429；滚动一分钟限制启动数，突发会退化成等待而不是无界积压。
* 路由组有两种形状：`ProviderGroup` 组合整个 Provider 并提供它们启用目录的**交集**，`ModelGroup` 把 `(Provider, model)` 组合在一个面向 Agent 的 id 后面。只有一个 Provider 提供的模型刻意不进入组，因为组的策略绝不能把模型发给从未听说过它的 Provider。
* 七种策略——有序、轮询、最少使用、智能、最低延迟、加权和手动——都可以从本地观察计算。路由可以设置首 token 期限，同时约束响应头和第一个流式 token。
* 熔断器按路由组而不是按 Provider 划分，未声明的协议会被探测而不是被拒绝。
* 请求账本记录请求实际走的路由：因不可用而跳过的成员与尝试失败分开记录；跟踪只带 id 和失败类型，绝不带提示、回答或 Key 材料。
* Gateway 页面是独立工作区：实时路由图回放每个请求、可展开的请求历史、可选择区间的 p50/p95、告警阈值、默认超时、上游顺序，以及一个说明保留窗口并先询问的清除动作。

**Provider 与远程运行时**

* 共享 Provider 记录是写入权威：在一个地方编辑会到达所有绑定它的 Agent，绑定也可以刻意不指定 Provider，让 Agent 自己认证。
* Provider 工作区重建为：左侧一列把网关、Providers 和路由组折叠在一个 **新建** 菜单下，共享身份头、下划线标签和分区卡片，设置原地编辑，路由组在自己的页面编辑。
* 65 个预设以数据形式发布且不再携带模型 id：应用预设会从内置 models.dev 目录（53 个 Provider）读取厂商条目，包括限制和能力标志。
* 手写配置的 Provider 成为 **用户定义** 下的可复用模板：每次读取时从记录投影，不携带秘密值请求头，用 `user:` 前缀寻址因此不会遮蔽内置预设，可以隐藏和恢复而不触碰 Provider、Key 或模型。
* Provider Key 行用遮蔽指纹而不是生成的标签标识凭据，眼睛按钮通过显式读取揭示值，普通快照只带遮蔽值。
* 请求头覆盖会投影到原生 Agent 与网关；导入一次预览一个来源、分页大模型列表、保存前测试草稿；草稿地址与 Key 可以抓取模型；每个 Key 的模型范围和代理可配置。
* 桌面端通过 SSH 在远程 Linux 主机安装 `vibex-server`，用固定 TLS 证书在回环上启动、打开 `ssh -L` 隧道、自己通过 SSH 领取一次性配对码，并用 Remote Protocol v2 连接——不需要 Docker、公网端口或手动复制配对码。
* 九步配置状态机拥有顺序、取消安全点、失败重试和“运行时 id 只在就绪后暴露”的不变量；重复开始会返回正在运行的尝试。
* 环境探测检查 Linux、架构、glibc、磁盘余量、home 可写、`sha256sum` 和目标端口，并以类型化错误阻止；Git、`SHELL` 和未知端口只作为警告。
* 隧道受监督：看门狗每 500 毫秒检查子进程，必要时重建同一份隧道规格一次，并把重启或失败摆到台面上，而不是留下静默死掉的回环端点。
* 升级是事务性的：新产物安装在当前产物旁边，运行时身份保留，启动失败会回滚到上一版本并启动检查。
* 卸载可以保留 home；SSH 配置可以编辑、移除和重新配置；已配对的 SSH 连接即使在配置前也可以移除。
* macOS 远程主机通过 LaunchAgent 支持，发布 arm64 与 x86_64 服务端产物；WSL2 发行版完全不需要 sshd，上传、安装、启动、等待 localhost 转发、在回环领取配对，并能在 `wsl --shutdown` 后恢复。
* 远程实例现在位于工作区分组的 **设置 → 远程实例**，始终出现在导航、搜索和命令面板里；此前的开发者开关及其环境变量已被移除。标题栏运行时面板变成已配对实例的切换器，底部动作打开设置。

**时间线与会话**

* 工具调用渲染成可读结构：`path: value` 字段、待办清单、提问与回答列表、解包的 harness 输出信封，以及带 `+N/-M` 的编辑 diff，并计入回合的改动文件与移动端。
* 只命名工具的标题会让位给调用自己的命令、路径或查询，`cd <绝对路径> &&` 前缀不再把命令本身挤出截断点。
* 活动头先讲意图与结果：失败调用在折叠时显示它打印的第一行，结束的命令与 Agent 调用显示运行时长，抓取有自己的类型和地球图标，组摘要先讲改动的文件。
* 消息里引用的工作区图片——相对、根相对、绝对或 `file://`——会内联渲染并限制在工作区内，点击打开全窗口预览；时间线图片变成可点击缩略图。
* 内置工具面板按会话而不是按 Agent 选择：新建会话页面记录每个面板的显式开关，缺失项跟随 Agent，分叉或委派会复制这张映射。
* 长正文通过自己的视口读取，运行中的会话打开在历史上而不是实时运行上，读者所在的位置在内容从上方落下后仍然保留。
* 新建会话输入框新增全屏控件，自动继续成为 shell 级默认设置，无需显式选择就会继续。
* 侧栏用会话行已有的漏斗姿态菜单收窄列表——全部、运行中、等待你、未读、失败和已置顶——批量操作跟随可见行。
* 打开的编辑器标签跟随磁盘上变化的文件，浅色主题重调为冷中性阶梯与实心不透明模块填充。

**市场、TUI、移动端与竞技场**

* MCP 市场用读者自己的问题询问注册表，而不是遍历有上限的后台目录，发布顺序很深的名字也能立刻找到；分页走注册表游标，每个问题保留一组结果。
* 市场条目携带发布者自己的图片和远程条目必需的请求头，后者成为安装输入并路由到服务器的请求头而不是环境变量。
* Skill 市场读取约一秒回答的公开目录：排名首页解析一次并共享六小时，浏览页把一个仓库折叠到最多四条，安装从目录点名的仓库取出。
* 市场卡片点击即安装，搜索在输入时运行，按功能的 Agent 胶囊选择哪些 Agent 接收该功能。
* TUI 的每个 `键 标签` 图例都是可按目标：队列与停靠带、模态页脚、设置页脚和新会话页的方括号提示都发布自己的矩形与所指的组合键，按下走与键盘相同的 `handle_key`。
* `Chord::from_hint` 按读者的读法解析图例——`^S`、`Space`、`↑`、`J/K`、`Alt+↑↓`——成对的箭头拆成两个一单元格目标。
* 队列带与停靠面板会滚动以保持光标可见，点击通过带子绘制的窗口映射，而不是从矩形顶部数行。
* Providers 表可以切换网关并显示带价格的套餐预设；导入的 Key 按用途命名；放不下的列会被丢弃而不是挤压。
* 已结算的工具调用保持折叠，落在读者面前的回答保持展开，`Ctrl+C` 只中断会话页面；提示带按输入框真正绘制的宽度设置尺寸。
* 移动端按实际绘制的大小读取文本阶梯，连接页带 Vibex 字标，同步徽章画成文本，CBDT emoji 字体作为 APK 资产发布；文件和提交在输入时搜索，时间线滚动时保留读者的位置，会话结束后把屏幕交还给读者；恢复路径不再因连接已死而中止，新会话提前打开，键盘关闭时终端保持不动。
* 十位守护者加入原来的六位，共十六场遭遇：Cursor、Cline、Grok、ZCode、Kimi、CodeBuddy、Antigravity、Devin、Gemini 和 Hermes。每位拥有自己的入场、退场和路线节奏，每个同伴效果由各自的胜利解锁。

## 性能

* 网关虚拟化请求账本并分页历史，请求在运行时就出现在账本里，而不是结束后才出现。
* 长对话正文通过视口分块读取，带窗口的正文在边缘淡出，而不是布局它持有的全部内容；模型列表虚拟化，草稿的端点与 Key 只探测一次。
* Skill 市场的搜索把 8 到 13 秒的往返缩短到约一秒，MCP 市场不再依赖后台遍历完成。
* Linux x86_64 发布链接用 lld 的 `--icf=all`，折叠重复的单态化函数体。

## 内部、构建与文档

* 版本号升到 `0.1.0-rc.9`；新增 `crates/model-gateway` 与 `crates/model-catalog` 两个工作区成员，数据库模式从 63 到 87。
* 工作区升级到 `gpui-kit` `0.8.0`，`rustls` 到 `0.23.46`，`zip` 到 `9.1.3`。
* 已清除的安全发现包括配置中心里的路径注入读取、一个看起来像凭据日志的测试断言，以及 Linux GTK 栈迁移到 gtk 0.19 与 `tray-icon` 的 StatusNotifierItem 后端，移除锁文件里的 `glib` 0.18 公告。
* Linux `.deb` 改为 xz 重新打包，从 119.8 MB 降到 69.8 MB；打包机现在需要 `xz` 和 `ld.lld`。
* 许可证 SBOM 与第三方声明按当前依赖图重新生成：1080 个 Cargo 包、10 个资源与字体包、5 个原生与安装器输入，全部已批准。
