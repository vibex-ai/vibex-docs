## 亮点

* **Windows 安装包不再替换过长的用户 `Path`** — 安装程序现在通过一个小助手读取注册表值的真实长度、保留它的类型，读取失败时不写入。此前超过 1023 个字符的 `Path` 会被读成空字符串，安装目录写入后其它条目全部丢失。
* **配对以内置 Relay 为首选** — 配对对话框把无需填写地址的内置中继排在首位，局域网与 Tailscale 紧随其后，直连 HTTPS 和自托管 Relay 收进 **其它方式**。
* **本地页面在嵌入式浏览器中打开** — 双击 HTML 文件会用样式表、脚本和图片完整预览页面，由限定在该文件目录内的回环源提供。
* **SSH 运行时干净重连** — 切回已停靠的实例会复用仍存活的隧道，而不是再开一个 `ssh -L`；重建的隧道会一直探测到真正就绪。
* **每个运行时 home 只有一个窗口** — 再次打开 Vibex 会让正在运行的窗口来到前台并退出，不再打开第二个窗口、落到 `desktop_runtime_home_locked`。

## 新功能

**远程访问与 Relay**

* 内置 Relay 是配对的第一个选项，也是唯一不需要输入的选项。官方源位于 `vibex-core` 中且从不渲染，因此不会被打错或误认为可配置端点；只有运行时真正提供该源时，入口才报告中继在线。
* 桌面端的 Relay 行、移动端选择器和 TUI 路由只显示连接名称，不再打印读者无法修改的地址。
* Relay 把 WebSocket 握手和房间注册计入客户端地址：回环反向代理后取最右侧的 `X-Forwarded-For`，否则取对端地址；跟踪表有界并在两个空闲窗口后清理，`/api/info` 报告生效的上限。

**桌面端**

* 设置导航在窗口较矮时只让分组列表在固定搜索框下滚动，每个分区仍然可达；重新打开设置会回到顶部，不再恢复上次的滚动位置。
* 文件树、文件搜索和 **打开方式 → 嵌入式浏览器** 都把本地页面开在面板里，渲染文档或会话中的网页链接也一样。每个目录有一个带独立令牌的回环服务器，拒绝路径穿越、点文件、反斜杠和指向目录外的符号链接，最后一个标签关闭时服务器停止。
* Agent 预览仍保持原有边界：`browser_preview_open` 依然需要一次性批准，只提供一个已批准的文件，批准一个文件不会暴露它的目录。
* 每个运行时 home 的锁和激活端点彼此独立，预览版、RC 版和稳定版安装不会互相争抢。

**技能与市场**

* 从整仓库源安装 Skill 不再在旧的 16 MiB 包上限处失败：下载上限提高到 128 MiB，文件数上限 16384，解压后大小上限 64 MiB，解压上限仍限制解压炸弹。
* 超过下载上限的仓库会报告自己的错误码和仓库名，不再在无关的搜索框下显示目录通用的 `market_response_too_large`。

**Windows 安装包**

* 安装程序和卸载程序把 `Path` 编辑交给 `vibex-installer-env.exe`：它向注册表询问精确字节长度、读取完整值、按整项大小写不敏感匹配、保留 `REG_SZ` 与 `REG_EXPAND_SZ`，读取失败时不写入。
* 卸载程序只移除指向安装目录的条目。**如果更早的版本已经替换过你的用户 `Path`，本次更新无法重建丢失的条目**，需要从备份恢复或手动重新添加。
