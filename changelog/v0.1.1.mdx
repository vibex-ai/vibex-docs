## 亮点

* **一次添加多台远程主机** — 连续添加 SSH 主机会逐台完成配置：每个请求排队等待，不再取消已经在下载的任务；无法连接的主机也不会卡住后面的队列。
* **`vibex-bin` 进入 AUR** — 稳定版发布把标签交给 AUR 任务，Arch 用户可以用 `paru -S vibex-bin` 或 `yay -S vibex-bin` 安装已审核的 Linux 包，不必手动解包 `.deb`。
* **Windows 上带标签的窗口** — 任务栏按钮显示 “Vibex” 而不是一个裸图标，shell 与远程主机通信时也不再闪出控制台窗口。
* **远程主机保持连接，连不上时说明原因** — 配置运行在工作台运行时上，SSH 连接成功后立刻打开的会话不会在第一次读取时因 socket 关闭而失败。`wsl.exe` 失败会报告自己的消息，挂起的 WSL 读取在 15 秒后放弃，认证失败会带上服务器实际返回的内容。
* **标注跟得上光标** — 框、线、箭头、画笔和马赛克笔画在 4K 截图上不再中途闪没或卡住窗口，撤销历史同时按字节数和条目数设限。
* **Providers → Models 标签页保持可读** — 行改为实测布局，打开的行内编辑器会把下面的行推开，而不是让名称和开关画进它的字段里。

## 新功能

**远程运行时**

* 配置是一个队列：第二台主机不会替换第一台已经启动的任务，也不会留下 `.part` 文件并让行停在 **离线 / 未安装**。
* 配置失败——主机不可达、运行时配置不可用、任务被停止——以顶层提示到达。WSL 对话框提交后会关闭，此前错误被写进已经消失的主体。
* 停滞的产物下载在静默一分钟后就失败，而不是把运行挂满五分钟；连接有自己的 30 秒预算，只要还在收到字节，流可以按需持续。
* 每个 SSH、`ssh-keygen` 和 `wsl.exe` 子进程都隐藏启动，Windows 不再为连接、隧道和主机密钥探测各开一个控制台窗口。
* 远程运行时借用工作台的进程级 Tokio 运行时，而不是自建一个并随配置 worker 丢弃；后端不再比它的 reactor 活得更久，连接成功后紧接着的目录读取也不会报 `remote_socket_write_failed`。
* 列出 WSL 发行版时同时排空两个管道并设 15 秒期限，区分启动失败、非零退出（带 stderr 和退出码）与超时，读取移出 UI 线程；对话框把读取中、失败重试和发行版列表画成独立状态。
* WSL 错误按 WSL 诊断：每个 `wsl_*` 错误码不再归类为未知、也不再给一个没有 SSH 跳板的传输显示“安装 SSH 服务器”，而是指向 `wsl --update` 与 `wsl -l -v`。
* 认证失败携带服务器 stderr，锁住的密钥、空的 agent 和错误的 `IdentityFile` 不再都读作同一句 “SSH authentication failed”。

**桌面端**

* 工作台、托盘恢复的窗口和电脑操控面板按发布通道的产品名命名，任务栏按钮和窗口切换器因此有标签。
* 截图标注改为从一张工作图绘制，而不是每次指针采样都编码一次 PNG。一笔现在就地扩展工作图，形状在笔画基线上重画，每帧最多上传一次，退休的纹理在绘制它的那一帧之后释放。
* Providers → Models 标签页用 GPUI 的实测列表放置行；打开或关闭编辑器会重新测量，列表拥有滚动条槽，卡片滚动自己的行而不是让页面滚动卡片。

**嵌入式浏览器**

* Windows 构建从启动器旁按版本命名的目录读取 Chromium 版本，不启动进程，因此发送 `Chrome/<version>` 而不是 `HeadlessChrome`，机器人检查返回正常页面而不是挑战页。

**打包与发布**

* 稳定版 GitHub Release 会派发 AUR 工作流并传入标签；派发结果只报告而不致命，发布不会因此失败。
* AUR 任务在第一次 `makepkg` 前把 PKGBUILD 树和 `SRCDEST` 交给非特权 `builder` 账户。
* 质量门恢复：格式检查按字节比较，macOS clippy 任务不再被 Windows 专用助手卡住，MCP 密钥测试不再访问真实钥匙串。
* 许可证门忽略 Gradle 构建树，本地 Android 构建复制到 `app/build/` 的 emoji 字体不再让 `pnpm check:licenses` 失败。

**性能**

* 嵌入式浏览器不再启动 Chromium 进程来获知版本，读取构建目录是瞬时的，也不会在每次运行时启动时留下多余窗口。
* 标记 4K 截图不再每次指针移动都做约 100 毫秒的 UI 线程编码工作。
* 列出 WSL 发行版不再占用 UI 线程，半安装的 WSL、停掉的 `LxssManager` 或 AppLocker 提示不会再冻住设置窗口。
