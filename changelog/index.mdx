## 如何阅读版本页面

* **亮点** — 该版本最重要的行为变化。
* **新功能** — 该版本新增的能力，按受影响的产品面分组。
* **修复** — 已修正的问题，按受影响的界面分组。
* **性能** — 响应速度与资源占用的改进。
* **内部、构建与文档** — 依赖升级、构建与发布流程、文档和规范改动。

条目末尾的短哈希（例如 `(ec6e378)`）标识 GitHub 上的对应提交。
