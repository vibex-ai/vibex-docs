## 亮点

* **委派跟随输入框所示** — TUI 把选中的运行时选项引用带进草稿、被持有的消息队列和发送路径；桌面端在编辑委派行时改写已插入的 `@Agent` chip；权威端把子会话绑定到最新用户消息中的 Agent 提及。与提及不一致的委派会以 `target_mismatch` 拒绝，而不是悄悄换一个 Provider 或模型运行。
* **WSL 运行时可以选端口** — 添加对话框新增 **运行时端口**（默认 `8765`），在下载开始前校验和探测；端口被占用时对话框保持打开，并把所选端口写进提示里。端口保存在连接配置中，安装、启动、配对和每次重连都会复用。
* **配对链接回归** — **设置 → 远程实例 → 用配对链接连接** 可以直接添加 `vibex://pair#/code/...` 打印的运行时，不需要 SSH、隧道或 Docker 镜像。已完成的配对面板现在提供 **完成**，可以在不撤销设备的情况下关掉。
* **思考档位可以由 models.dev 建议** — 模型编辑器在 **思考档位** 下提供 models.dev 发布的档位值和一个明确的 **应用** 行。不会自动采纳；已经声明相同档位的配置保持不变。
* **Agent 更新不再丢账号目录** — 托管 Agent 更新或应用升级可能在目录重新发现之前改变启动标识。上一次完整的目录会继续支撑显式模型的会话，直到刷新落地；只影响运行时的启动输入不再改变目录标识。
* **失败的回合保留回答** — 已经给出回答、随后遇到边界错误的回合会把回答保留为结论，错误收在折叠后面；向上加载更早历史时，读者所在的那一行也不会被挪走。

## 新功能

**桌面端**

* **添加 WSL 运行时** 提供 **运行时端口**，默认 `8765`；端口先在本地校验，再在发行版内探测，失败时对话框带着端口号保持打开。
* **远程实例** 接受配对链接：链接自带地址时隐藏地址字段，只有代码时接受数字代码加地址，被拒绝或过期的代码连同原因留在字段旁。配对成功会注册运行时、列入 **远程连接** 并连接。
* 完成配对后的面板显示 **完成**，关闭面板不会撤销新授予的设备权限。
* 实时标签的扫掠改为以应用 33 毫秒的动画预算为下限，故意按 30fps 绘制的帧不再被误判为迟到而永久停止扫掠。

**Provider 与 Agent**

* 模型编辑器的 **思考档位** 从 models.dev 缓存的 `reasoning_options` 读取建议值；只有点 **应用** 才写入，已声明相同档位的配置隐藏建议。
* 账号目录在启动标识变化后回退到同一账号修订号下最新的完整目录，而不是让显式模型会话以 `agent_auth_model_catalog_unavailable` 失败。
* 终端能力、继承的环境值等只影响运行时的输入从目录指纹中排除，换 shell 或 headless 启动仍能找到同一份目录。
* 重新发现得到空结果时借用上一次的模型并标记为不完整，等待后台刷新；刷新循环每修复一个 Agent 就发布会话可用的目录，不再等整个清单。
* 一个 Agent 的发现失败或操作锁丢失只记录并跳过，其余目录刷新继续；失败的写入稍后重试，不再中止循环。

**委派与协作**

* `vibex_delegate` 与 `vibex_create_session` 绑定最新用户消息中的 Agent 提及；冲突的 `selectionRef` 以 `target_mismatch` 拒绝，未指定目标时采纳唯一的提及，多个提及时要求调用方点名或用 `agentId` 收窄。人类直接执行的 **委派** 动作携带自己的精确引用，不受影响。
* TUI 接受 `@Agent` 行时记住稳定的运行时选项引用，它随草稿、队列和发送请求一起走；删除可见标签会撤回引用。
* 桌面端修改委派行的 Provider 或模型时，会重写草稿中匹配的 `@Agent` token，可见标签仍是 `@Agent`，编码的提及 id 指向刚选的配置。

**移动端与终端**

* 冷启动时读到空尾不会再清掉已恢复的前缀：只有带缺口且非空的回答才能替换前缀，已配对的会话不会先显示再变成「没有消息」。
* TUI 中先给出回答、后报边界错误的回合把回答保留为结论，错误留在可展开的工作里。
* 在视口上方加载更早历史时同时锚定块与块内行，长回答中间的阅读位置不会被拉回第一行。
