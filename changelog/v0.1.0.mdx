## 亮点

* **首个正式版** — `0.1.0` 是从候选版本进入稳定支持的分界点，提供 `latest` 容器标签与 AUR 发布，正式版与 RC 版使用彼此隔离的数据目录。
* **真实终端会话** — 通过 13 款已验证的 Agent CLI，在 PTY 终端里直接运行 Agent，同时保留侧栏、搜索、移动端和 TUI 集成。
* **真正的工作台** — 会话、源码、Git、终端、嵌入式浏览器、本地模型网关、Agent 团队、目标和多窗格会话组在同一个界面里。
* **运行时在你自己手里** — 权威 `DesktopRuntime` 可以跑在本机、局域网内的 `vibex-server`，或由 SSH / WSL 自动部署的远程运行时上。
* **三个界面，一个运行时** — 桌面端、移动端和终端客户端（`vibex`）驱动同一个权威运行时，并从同一份发布安装。
* **支持 10 种语言** — 英语、简体中文、繁体中文、日语、韩语、德语、法语、西班牙语、巴西葡萄牙语和俄语。

## 核心功能

**会话与工作台**

* 区分 ACP 时间线与纯终端两种传输，支持分屏会话组、命令面板式搜索、会话过滤、内联目标和生命周期任务委派。
* 侧栏、搜索、通知、移动端与 TUI 都能看到终端模式会话，并在同一行上工作。

**终端**

* 回滚区搜索、矢量制表符、内置 Nerd Font、连字、OSC 剪贴板 / 标题 / 颜色查询，以及鼠标上报。

**桌面端**

* 20 套内置主题、跟随系统的窗口边框、基于 Chrome 的可交互嵌入式浏览器、Provider 工作区和智能托盘 / 退出选项。

**网关与模型**

* 统一的本地模型网关（OpenAI、Anthropic、Google）、可自定义的故障转移路由，以及详细的模型能力。

**远程与移动端**

* `vibex-server` 扫码配对、SSH / WSL 远程配置，以及功能与桌面端对齐的移动客户端。

## 性能与底层

* 终端网格渲染从 242 毫秒降到 3 毫秒，会话搜索改为索引式即查，时间线虚拟化，后台资源清理把 Android APK 从 429 MB 降到 73 MB。
* 正式版与 RC 版使用隔离的应用目录，并提供安全的数据库迁移与导入；环境变量做白名单清理，SBOM 与许可证清单更新。

## 从候选版本升级

正式版与 RC 版是两个独立应用，各自拥有独立的数据目录，因此正式版安装后从空数据开始。要继承 RC 版本的工作，打开 **设置 → 数据与诊断 → 本地存储 → 从 RC 版本导入数据** 并确认。Vibex 会先对 RC 数据库做快照、迁移并校验副本，在下次启动时换入；工作区、会话和 Provider 配置会一并带过来，导入失败时保留当前数据。RC 安装本身不会被修改，可以继续把它作为退路。
