## 亮点

* **首个正式版本** — `0.1.0` 结束了候选阶段。稳定通道拥有自己的应用身份与数据目录，容器镜像的 `latest` 标签指向它，AUR 的 `vibex-bin` 也随它发布。
* **真实终端会话** — Agent 可以在自己的 CLI 里运行，由 PTY 承载对话；已验证十三款 Agent，侧栏、搜索、通知、移动端与 TUI 仍然在同一个会话行上工作。
* **一个完整的工作台** — 会话、源码、Git、终端、内嵌浏览器、本地模型网关、Agent 团队、目标与分屏会话组合在一起，不用在工具之间搬运上下文。
* **运行时在你自己手里** — 权威运行时可以跑在本机、你自己的 `vibex-server` 上，或由桌面端通过 SSH / WSL 自动部署到另一台机器。
* **三个界面，一个运行时** — 桌面端、移动端与终端客户端 `vibex` 驱动同一个权威运行时，并从同一份发布里安装。
* **十种语言** — 英语、简体中文、繁体中文、日语、韩语、德语、法语、西班牙语、巴西葡萄牙语和俄语。

## 新功能

**会话与工作台**

* 会话按运行方式分成两种：ACP 会话拥有时间线与运行时绑定，终端会话启动一个 Agent CLI 并只记录观测事实；两者在侧栏、搜索和通知里是同一行（`35916d16`、`55c0c32d`）
* 会话组把同一个 Worktree 下的多个会话放在一起，可以分屏、合并窗格、整组自动继续，也可以拖动到文件夹或解散（`7348c84b`、`e6f49bd7`）
* 侧栏把草稿按文件夹归档，会话可以拖进组里，组用分支导轨画出成员来源（`7348c84b`、`0058ab32`、`cd6f299b`）
* 侧栏筛选是可多选的集合，会话可以按创建、更新、标题或手动顺序排列（`125bea0c`、`7d99b489`）
* 命令面板一次输入同时检索会话、设置项和快捷操作；会话搜索只索引对话文本并高亮命中（`e30fdf14`）
* 目标通过 ACP 的 `_meta.goal` 扩展发布，归一成目标栏里的阶段、统计和控制按钮
* 委派有生命周期：任务可以保持打开、追加跟进、接受或取消，重试落到最初那次接受
* 内置工具面板按会话选择，缺省条目跟随 Agent，分叉或委派复制这份映射（`2acc9b7a`、`3866693d`）

**终端**

* 回滚缓冲区搜索覆盖每一条保留的行，上一处／下一处会把匹配滚动到视野内（`9efd0d49`）
* 制表字符按笔画画成相连的矢量线，表格与面板边框跨单元格对齐（`9efd0d49`）
* 随包的 `Symbols Nerd Font Mono` 让 Agent 的状态图标不再画成方块（`9efd0d49`）
* 单元格度量取自字体自身的步进，CJK 仍占两列；连字是可关掉的偏好项（`9efd0d49`、`bef85503`）
* 回应 OSC 52 剪贴板、OSC 0/2 标题与颜色查询，以及 1005、1015、1016 三种鼠标上报方言（`9efd0d49`）
* 终端背景可以设透明度，主题墨色被提亮到最低对比度（`9efd0d49`）
* 终端模式的 CLI 通过各自真正读取的启动输入收到 MCP 服务器、Vibex 委派、浏览器与电脑操作，凭证不进入 argv（`06e89ac7`、`7b30af79`）

**桌面端**

* 内置二十套浅色与深色主题，主题模式跟随系统，窗口边框可以浮动（`f9e4bc2d`）
* 工作台背景可以放静态图、GIF 或 WebP，支持填充、适应、拉伸和一层可调遮罩
* 内嵌浏览器由 Chrome 驱动，Agent 可以读取和操作页面
* 供应商工作区把网关、供应商与路由组合在一处，支持可折叠侧栏与原地编辑（`9c5f2498`、`e2b94939`）
* 关闭主窗口的行为是一个二选一：继续在系统托盘运行，或直接退出（`6cc327a1`）
* 标题栏的运行时面板是已配对实例的切换器，远程实例始终出现在导航与搜索里（`33571d2e`、`ce9d6afa`）

**网关与模型**

* 一个回环端点提供 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 与 Google Generative AI 四种协议，并在它们之间翻译（`6e7d1513`、`69dcf747`）
* 路由由 `(Provider, model)` 成员组成，支持七种策略、首 token 期限、按 Key 的并发与速率上限（`3bec21f2`、`41956368`、`c166d3b8`）
* 预设作为数据发布并从 `models.dev` 目录读取模型信息，手工配置的 Provider 可以存成可复用模板（`f9dfd52c`、`c7e58564`）
* 请求账本记录每次请求真正走过的路由，只带 id 与失败类型；实时路由图可以重放一次请求的路径（`60974688`、`37193353`）
* 模型能力从维护好的目录建议，上下文窗口与思考档位是声明数据，不会从模型 id 猜测

**远程与移动端**

* 桌面端通过 SSH 在远程 Linux 或 macOS 主机上安装 `vibex-server`，建立隧道、自动配对，并在升级失败时回滚且保住运行时身份（`4aa8b4a6`、`ec66c998`、`349d09bc`）
* WSL2 发行版不需要 sshd 就能作为本机 Linux 运行时，`wsl --shutdown` 后会自动恢复（`6de4ca9e`、`4ccdd60a`）
* 没有 sshd 的 Linux 主机可以用一次性 bootstrap 命令初始化，命令带过期时间并校验 payload 哈希（`c5df1c5c`、`bb67ef78`）
* 移动端扫码配对同一个运行时，可以查看进度、回复提问、处理审批并使用终端
* 移动端跟随「减少动态效果」，打开会话时保持自己的 workspace 与对话（`252329db`、`5d88cbf5`）

**TUI**

* `vibex` 打开当前目录的新会话页，目录与上次使用的运行时已经填好（`97ca1952`）
* 界面是一列全宽横带，任意终端尺寸下都自动重排，没有最小尺寸
* 每个画出来的 `键 标签` 图例都是可点目标，点击走与键盘相同的分发路径（`7d031085`）
* 管理页是桌面风格的配置中心，配对页合并了配对、已配对设备与远程访问
* 语言、主题与键位写入 `~/.vibex/tui-interface.json` 与 `~/.vibex/tui-keys.toml`

**语言与本地化**

* 桌面端、移动端与 TUI 都渲染十种语言；新增的七种语言由一份共享目录承载，未翻译的句子回退到英语（`36d65e63`）
* 语言选择器在两个客户端上都列出全部十种语言加「跟随系统」（`36d65e63`）
* 韩语的间距按随包 CJK 字体的真实步进排布（`c1c421d3`）

## 从候选版本升级

稳定版与候选版是两个独立应用，各自拥有独立的数据目录，因此稳定版安装后从空数据开始。要继承候选版本的工作，请打开 **设置 → 数据与诊断 → 本地存储 → 从 RC 版本导入数据** 并确认。

Vibex 会先对候选版数据库做快照、迁移并校验副本，在下次启动时换入；工作区、会话与供应商配置会一并带过来，导入失败时保留当前数据。候选版安装本身不会被修改，可以继续把它作为退路。

首次启动时如果检测到旁边的候选版数据，也会弹出一次导入提示，选择 **导入数据** 或 **暂不导入**。
