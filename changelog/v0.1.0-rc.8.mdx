## 亮点

* **Vibex TUI：整个工作台进得了终端** — 会话、流式 Markdown、审批、队列、设置与配对都搬进了终端，界面是一列全宽横带并随窗口自动重排，因此没有最小尺寸这回事。它随每个桌面安装包一起发布，在 SSH 和 tmux 里都能用，既能自己启动运行时，也能附着到桌面端正在运行的那一个。
* **Agent 团队化协作** — 委派不再是一问一答：任务在回合结束后可以保持打开，你在同一个子会话里追加跟进，再决定接受还是取消。侧栏的所有权树和会话组的团队状态头会同步显示工作推进到了哪里。
* **消息定时发送** — 给消息挑一个整点，它就留在队列里等你。定时跨重启保留，在弹出面板里编辑，也能看到另一个客户端正在持有的发送。
* **自定义工作台背景** — 在工作台后面放一张自己的图，静态或动图都行，填充、适应或拉伸，再加一层可调遮罩，文字在任何背景下都读得清。图片按项目图标同样的方式导入，存放在运行时 home 下。
* **Agent 电脑操控** — 在你授权之后，Agent 可以接管宿主机的桌面。它在设置里安装和管理，有独立的浮动外壳与本地化面板，驱动的控制台窗口不会跑到你的桌面上，总开关随时能关。
* **移动端重建，对齐桌面端** — 手机端跟随桌面端的模型：会话组与所有权树、带文件树和差异的右侧栏、定时发送、worktree、目标、触感反馈，以及重建的配对与首次运行流程。
* **自动更新默认开启** — 桌面端默认自动更新，既有安装会升级到这个行为；iOS 在模拟器包之外发布未签名的真机 IPA，安装者用自己的 Apple ID 重新签名即可。

## 新功能

**Vibex TUI（终端版）**

* 界面由一列全宽横带组成——状态、对话流、回合状态、输入框、快捷键栏——取代了原来的分栏网格，任意终端尺寸下都自动重排，因此没有最小尺寸，也不再提示「窗口太小」（`1aa9e4d5`、`dedafc55`、`eb95f780`）
* 对话流把 Markdown 边流边就地渲染，强调、代码和表格按真实语法渲染并有一整套颜色层级，而不是白底白字（`e9b05a27`、`2acf4d03`、`10507286`）
* 结束的回合折到 `▸ Worked for 12s` 分隔线后面，这条线本身就是开关；折叠展开时重新量行高，运行中展开也不会顶掉读者所在的位置（`eb4ed877`、`f39d5163`、`13ba42e6`）
* 滚走的用户消息钉在视口上方且只画一遍，`/` 支持智能大小写正则搜索，滚动到顶部会加载更早的历史（`ae610ee3`、`28dda9e3`、`71fee6c1`、`f4d6e9a2`）
* 可以用鼠标选择对话流文本并通过 OSC 52 复制，SSH 和 tmux 里都能用；选区覆盖的单元格会被完整复制（`143b82fb`、`39a59f3b`）
* 输入框支持 readline 式编辑——撤销、kill buffer、按词移动，草稿内可以选择和替换，Shift+Enter 插入换行而不是发送（`5897bd40`、`114b7b30`、`63b44766`）
* 长文本粘贴收成 `[Pasted: 42 lines]` 芯片并可以预览其中的内容，已发送的消息可以用方向键召回（`864cba66`、`499a7ea5`、`9503ed2e`）
* 剪贴板、粘贴和拖入的图片都变成芯片，按终端自身的分辨率绘制，SSH 连接下也能粘贴图片（`260a9b6e`、`94b1a22b`、`beacbd90`）
* `/`、`@`、`$` 打开桌面端自己的补全面板——命令与 Prompt、工作区文件与 Agent 委派列表、Skill；抽屉在行中打开，Enter 取走它给出的那一行（`d5f7b041`、`f2259a44`）
* Agent 的请求就地呈现：提问开在输入框横带上并用真正的表单回答，审批是页面上的卡片；停靠面板集中放 Agent、计划和被持有的消息（`2cd7cb59`、`918e8a21`、`0300847d`）
* 回合轨只按回合打刻度，视口覆盖的每个回合都会点亮；滚动到底部会停住并恢复跟随（`1b5704e3`、`627bf5c3`、`6699797c`）
* 主题、语言和最近命令会被记住；`?` 速查表按分组排列，键位绑定可以直接在界面里编辑，冲突会被拒绝（`c4d28c0e`、`4a49d297`、`4f9ef96c`）

**TUI 的会话、运行时与配置中心**

* 会话列表按桌面端侧栏的排布绘制，行上直接给重命名和删除控件；可以置顶、分组和手动排序，分组段落带摘要（`b4e6b30c`、`2f7d75f2`、`b4dc89a8`）
* 读不到桌面端排布时，你自己的置顶与顺序保存在 `~/.vibex/tui-sidebar.json`（`31c9e9bb`）
* 委派的子会话嵌在会话列表里，用树形导轨画成分支，分支止于子会话的 Agent 标记，也不会从没有会话的上方长出一条竖线（`2faf67a7`、`42297e47`、`77f72704`）
* 另一个客户端读到或删掉的会话会同步过来：已读点消失，删除的行、打开的页面和各自的会话状态一起清掉（`7025a3f4`、`68aa778c`、`f364a0c4`）
* 客户端打开就是当前目录下的新会话输入页，目录和上次使用的运行时都已经填好，`Esc` 在输入页与会话列表之间切换，发出第一条消息后直接落到该会话（`4c29a366`、`34dd24c2`、`d9397935`）
* 新建会话在页面里完成而不是对话框，`Ctrl+W` 能改工作区，选中的目录会保留；工作区选择器打开在页面已经指向的目录，Space 进入光标所在的文件夹（`359be634`、`b7eaeb7c`、`bec4918c`）
* 运行时切换器围绕分组、搜索和暂存选项重建，座位显示为本地模式或远程模式，附着远程座位前先连上传输（`46959e90`、`f6551002`、`78e34b78`、`0527d8dc`）
* 管理页重建为桌面风格的配置中心——Agent、供应商配置、Model、MCP、Skill、Prompt、配对与远程访问都在其中（`5460a842`）
* 列表里的开关按下即响应，先画状态再等权限方确认，被拒绝时会画回原样；没读过的区域画骨架而不是空表，读取失败留在发起它的区域上并给出错误码和重试键（`7e4bc14d`、`729145af`、`898fed38`、`64df2814`）
* 供应商配置可以新建、复制、按读者自己的顺序排列，可以编辑网站、请求头和分协议地址，也可以清掉一个 key、固定端点、限定默认，并与其他 CLI 工具已有的设置互相导入导出（`95dea462`、`6e719bda`、`f0f9b1c2`、`259d7c37`、`7cf9bfab`、`7e1bce36`）
* 可以编辑一个供应商配置提供哪些 Model 和单个 Model 的设置，`y` 一次提供目录里的全部 Model，`z` 全部收回（`a103a9ef`、`b86bb346`、`833c6599`）
* Agent 目录分成三段排好序并带角标，可以发现本机的 Agent CLI、看着它安装，也支持注册自定义 ACP Agent（`48cb6e82`、`3a311efb`、`38596fc5`）
* Agent 账号面板把账号读成一份登录方式列表，可以按方式登录并打开凭证页；终端方式的登录在面板里画出真正的终端，退出前先说明它会结束什么（`845278ab`、`9d0e9630`、`667c6aa5`）

**TUI 的通知、Skill 与配对**

* 通知通过终端转义送达，通道按运行时选择：附着到桌面端时退让给桌面端，同一个事件只从一个通道来（`bdeb8126`、`3adac8f0`、`905bcd4e`）
* Skill 市场可以分页和收窄，卡片会说出自己的状态（已安装的条目提供「重装」，被撤下的条目优先），安装前先读一遍将要写入的说明、文件清单和不会写入的文件，再问哪些 Agent 接收（`eef35bb4`、`e4cd2c08`、`2591dddd`）

**Agent 团队**

* 委派的任务在回合结束后可以保持打开，向同一个子会话追加跟进、接受或取消，旧的单回合路径不受影响（`019d4f14`、`021d6324`）

* 转发的子 Agent 标题不再跑到根会话上，Agent 会先发布一个已结算的回合再压缩它的流式行（`b4fd32ef`、`96d6c7ea`）

**工作台与侧栏**

* 按住 Shift/Ctrl 选中多行后右键，菜单读到的是整个选中区：自动继续设成同一个值，置顶与分叉作用于每一行，删除先确认数量（`3eef716b`）
* 文件夹行在批量模式下带复选框，一次点击就能勾选或清空它管辖的全部会话，包括多层和组内的成员，委派出的子会话仍被排除（`2bac920e`）
* 归档不再只藏在标题栏：会话行菜单、多选菜单和批量栏都能归档，因为可逆所以不弹确认，误归档去归档页撤销（`c43ec865`）
* 会话行右键菜单可以直接分叉这个会话，落在源会话的当前位置，而不是先要求你在对话流里挑一个位置（`b2ce63b7`）
* 委派会话用悬停在行尾才出现的开关展开分支，开关占位固定所以标题不会在悬停时重排，父子行共享同一套高度、圆角与状态列（`65834757`、`41a073d8`）
* 会话组可以整组拖动：放进文件夹、与其他组换位、回到工作区根；拖动组内成员则重排组内顺序，拖到组外就把这个会话移出组（`e9ef0bbe`）
* 工作区行显示正在运行的会话数，运行中的会话用点阵动效表示活动，标题带一道微光（`6d2f9c49`、`83a9b179`、`8aa5f9f1`）
* 回合预览轨按视口点亮它覆盖的每个槽位，跨回合边界时两个回合同时亮（`b55b81f0`、`c545d89c`）
* 冷开会话落在会话末尾：没有游标时读最新窗口，分页在回合边界切开，所以一个回合不会分几次塞进来，回合头也不再显示持续变长的时长（`0f7b88b8`、`27c7c38d`、`2f355bbd`）
