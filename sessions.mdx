---
title: "Agent 会话"
description: "创建、观察、暂停、分叉和恢复 Vibex Agent 会话。"
---

会话把一次开发任务的输入、Agent 输出和工具操作保存为结构化时间线。桌面端保存权威时间线，移动端只显示它的远程投影。

## 创建会话

1. 选择目标工作区。
2. 在 Composer 顶部选择 Agent、供应商配置、模型、推理深度和 conversation mode。
3. 输入任务。用 `/` 选 Prompt，用 `@` 引用工作区文件，用 `$` 插入 Skill，也可以添加附件。
4. 发送前确认工作区和权限范围。Agent 可能需要读取文件、执行终端命令或请求额外授权。

## 阅读时间线

| 项目 | 你会看到什么 |
| --- | --- |
| 用户与 Agent 消息 | Markdown 文本和附件。 |
| reasoning | Agent 的推理摘要（是否显示由 Agent 和配置决定）。 |
| plan | 待办步骤及其进度。 |
| tool/process details | 工具名称、参数摘要、进程和退出结果。 |
| permission approval | 等待你批准或拒绝的操作。 |
| elicitation | Agent 需要你填写的类型化表单。 |
| 状态事件 | 运行、等待、完成、失败、停止和重连。 |

工具参数、终端输出和文件差异可能包含敏感内容。分享截图或诊断前先检查并脱敏。

## 控制运行

- **Stop**：停止当前运行。已写入的文件或已执行的命令不会自动回滚。
- **Continue**：在同一会话中继续发送任务。
- **Fork**：从当前时间线创建分支会话，适合比较两种实现。
- **Rename**：修改会话标题，不会改变 Agent 上下文。
- **Resume**：从持久化历史恢复会话。重启后先等待桌面端完成状态加载。

<Warning>
  停止 Agent 只停止运行过程，不会撤销文件、Git 或外部服务变更。请在 Git diff 和终端中分别检查结果。
</Warning>

## 权限请求与询问表单

当 Agent 请求终端、文件写入或其他受保护能力时，时间线会显示请求原因和范围。选择 **Approve** 或 **Deny** 后，结果会记录在时间线中。

询问表单需要填写结构化选项。提交前确认值和作用范围；取消表单会让 Agent 收到取消结果，而不是隐式批准。

## 导入本地历史

支持的 Agent 本地历史可以通过 **Local history import** 导入。导入前确认来源目录和目标工作区；导入只复制可识别的会话记录，不会替你导入凭据或完整 Agent home 配置。

## 搜索和通知

- 在当前会话中按 `cmd-f`（Windows/Linux 通常为 `ctrl-f`）搜索时间线。
- 会话完成、失败或等待输入时，桌面端可以发送通知。
- 未读完成项会在侧栏保留提示；打开会话后以权威时间线为准。

## 移动端操作

配对后的移动端可以查看同一时间线、发送后续消息、回复询问和处理允许的审批。它不在本地启动 Agent，也不持有工作区文件；网络中断后，重新连接会先执行 catch-up，再继续接收实时事件。
