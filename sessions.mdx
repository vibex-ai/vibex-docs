---
title: "Agent 会话"
description: "创建、观察、控制、分叉和恢复 Vibex Agent 会话。"
---

会话把一次开发任务的输入、Agent 输出和工具操作保存为结构化时间线。**权威运行时**保存权威时间线，其它客户端只显示它的投影。

## 创建会话

1. 选择目标项目和位置（**本地**、**新建 Worktree**，或 **临时会话**，见[项目与工作区](/workspaces)）。
2. 在工作区行末端选择 **传输方式**：**Vibex 界面**（默认，由 Vibex 绘制 GUI 时间线）或 **原生终端**（由 Agent 自己的 CLI 在 PTY 里承载对话）。详见[终端模式](#终端模式)。
3. 在输入框顶部选择 Agent、供应商配置、模型、**思考深度**、**对话模式** 和本会话可用的内置工具。
4. 输入任务。用 `/` 选命令或 Prompt，用 `@` 引用工作区文件或 Agent，用 `$` 插入 Skill，或用 `↑` / `↓` 翻出这个会话早先发过的消息；也可以添加附件。
5. 发送前确认工作区和权限范围。Agent 可能需要读取文件、执行终端命令或请求额外授权。

切换 Agent 或模型只影响后续运行。已写入时间线的消息会保留其原始运行身份。

<Note>
  **临时会话**不属于任何项目，适合一次性问题或试跑。它仍然由同一个运行时保存，也可以归档；需要文件访问时再选择项目。侧栏、右键菜单、新建会话选择器和搜索里都把它显示为「临时会话」，默认图标是解析出来的绿色星光。
</Note>

## 终端模式

终端模式把会话交给 Agent 自己的命令行界面：对话在原生 PTY 里进行，Vibex 不再绘制时间线。它适合已经习惯某个 Agent 的 TUI、或者需要该 CLI 独有能力的时候。

| | **Vibex 界面** | **原生终端** |
| --- | --- | --- |
| 谁绘制对话 | Vibex 时间线 | Agent 自己的 CLI |
| Vibex 扩展（目标、委派、审批卡、队列、定时发送、用量） | 支持 | 不支持 |
| 会话行、搜索、通知、移动端、TUI | 支持 | 支持，仍在同一行上 |
| 凭据来源 | 供应商配置或 Agent 账号 | 只能来自**供应商配置** |

已验证十三个 Agent CLI：Claude、Codex、OpenCode、Gemini、Pi、Grok、Cline、Copilot、Cursor、Kimi、CodeBuddy、Devin 和 Hermes。没有终端模式的 Agent 完全不显示这个开关。

工作方式：

- 新建会话页的草稿作为位置参数交给 CLI，附件以路径跟随，因此 Agent 从你已经描述过的那一轮开始。
- 配置的模型随命令行传入；选的是 Agent 默认值时什么也不传，而不是猜一个 id。
- 终端模式只携带**供应商配置**。页面没有可交出的配置时，开关的提示会说明 CLI 会用它自己的登录态。
- 会话行仍会报告 Agent 的活动、未读状态和通知，这些来自 Vibex 在终端矩形之外记录的观测事实；读不到时状态是「未知」，而不是猜成空闲。
- 进程结束后会话会被关闭并标记为错误；重启会重新提供同一份 argv、工作目录和供应商配置，并从记录的 argv 重建 PTY。
- MCP 服务器、Vibex 委派、内嵌浏览器和电脑操作通过每个 CLI 真正读取的启动输入投递，凭证不进入命令行。没有按进程传入 MCP 入口的 Agent（Cursor、Gemini、Grok、Kimi Code、Devin）会把两个工具面板显示为不可用。

<Warning>
  终端模式没有 Vibex 的审批卡。Agent CLI 自己的权限提示直接在终端里回答，Vibex 不会替你确认。停止会话也不会撤销已经完成的外部操作。
</Warning>


## 阅读时间线

| 项目 | 你会看到什么 |
| --- | --- |
| 用户与 Agent 消息 | Markdown 文本、图片和附件。 |
| 推理 | Agent 的推理摘要，可用 **展开推理过程** / **收起推理过程** 展开或收起。 |
| Plan | 待办步骤及其进度。 |
| 工具与进程详情 | 工具名称、参数摘要、进程和退出结果，以及 **{n} process events** 计数。 |
| 权限请求 | 等待你批准或拒绝的操作。 |
| 询问表单 | Agent 需要你填写的类型化表单。 |
| 委派 | 子 Agent 或委派任务的状态和结果。 |
| 目标 | 目标阶段、统计和控制按钮。 |
| 状态事件 | 运行、排队、等待、完成、失败、停止和重连。 |

回合上方会显示 **工作了** 的耗时。生成过程中会显示 **思考中...** 或 **等待确认中...**。已结束的回合可以折叠；对话流只读取有界窗口，向上翻页会加载更早的历史而不移动你当前的位置。

工具参数、终端输出和文件差异可能包含敏感内容。分享诊断前先检查并脱敏。

## 会话组与分屏

会话组把同一 Worktree 下的多个会话放在一起，适合一个任务下的多个 Agent 或分支：

- 在侧栏多选会话，右键选择 **新建会话组**。
- 组内可以 **分屏** 并排查看，或 **合并窗格** 回到单视图。
- 组头显示团队状态：运行中、等待审批、完成或失败。
- 可以对整组打开 **自动继续**，让满足条件的会话一起推进。
- 组可以拖动到文件夹、与其他组换位，或拖回工作区根；组内成员可以重排，拖到组外就移出组。
- **解散会话组** 不会删除会话。

会话组只能包含同一个 Worktree 下的会话。需要跨 Worktree 并行时，用多个组。

## 目标

支持目标的 Agent 会通过 ACP 发布目标状态：通用的 `_meta.goal` 扩展，以及 Codex 旧的 `_meta.codex.goal` 命名空间。Vibex 把这些归一成同一套模型，并把每次变化存成一条目标时间线条目。

目标显示在输入框上方的固定目标栏里，紧接在排队消息栏下面：

- 目标栏显示阶段、目标和 Agent 自己上报的统计（已用时间、token 用量、回合数）。
- 铅笔按钮（**编辑目标**）打开原地编辑器改写目标；保存时通过目标控制下发，不经过输入框。
- **暂停目标** / **继续目标** 暂停或继续目标。
- **清除目标** 清除目标；进行中、已暂停、已阻塞和额度受限的目标都能清除。

只有适配器明确声明支持时，对应的按钮才会出现。以 `/goal` 发出的消息保留自己的气泡，并在气泡边缘带一个目标图标。

## 委派与 Agent 团队

委派不再是一问一答。被委派的任务有生命周期：

- **保持打开**：回合结束后，子会话仍然存在，可以继续追加跟进。
- **接受**：确认结果，任务结束；重试会落到最初那次接受，不会覆盖早先的工作。
- **取消**：永久取消，阻止该任务名下任何位置的新消息和新子工作。
- **跟进**：只有真正执行过的任务才能继续；意图变了会被拒绝。

界面上可以看到：

- 侧栏的 **所有权树**：父会话下挂委派出的子会话，用树形导轨连接。
- 会话组的 **团队状态头**：显示有多少子 Agent 在运行、等待或完成。
- **委派卡片**：定位到子会话所在的窗格。
- `@` 引用菜单分成 **文件** 和 **Agent 委派** 两个标签页，每行会说明自己指的是文件还是 Agent。

子 Agent 有独立时间线，可以从右侧栏的 **子 Agent 时间线** 进入。子 Agent 生成的标题不会覆盖根会话标题。

## 控制运行

| 操作 | 说明 |
| --- | --- |
| **停止当前回复** | 停止当前运行。已写入的文件或已执行的命令**不会**自动回滚。 |
| **继续** | 在同一会话中继续发送任务。 |
| **重试** | 按 Agent 支持的重试语义重新运行失败回合；不确定是否已执行的外部操作应先检查结果。 |
| **分叉会话** | 从当前时间线或侧栏行创建分支会话，适合比较两种实现。 |
| **重命名** | 修改会话标题，不会改变 Agent 上下文。 |
| **编辑消息** | 改写最后一条用户消息；已完成的时间线事件不会被改写。 |
| **归档** | 把会话移出侧栏，保留完整时间线；可以从 **设置 → 已归档会话** 恢复。 |

<Warning>
  停止 Agent 只停止运行过程，不会撤销文件、Git 或外部服务变更。请在 Git diff 和终端中分别检查结果。
</Warning>

## 消息队列、引导与定时发送

运行期间发送的后续消息会进入队列。输入框上的队列区域提供：

- **自动发送** / **手动发送** —— 切换自动或手动提交队列。
- **引导** —— 只对声明了原生引导（native steering）的 Agent 出现：它把这条消息注入正在运行的回合，而不是先打断。其它 Agent 仍然回退为打断并重发。
- **定时发送** —— 给消息选一个整点，它留在队列里等待；跨重启保留，在弹出面板里编辑，也能看到另一个客户端正在持有的发送。
- **发送排队消息**、**编辑排队消息**、**删除排队消息** —— 逐项操作。
- **恢复队列发送** / **清空排队消息** —— 整体恢复或清空。

投递方式会记在用户消息上，并渲染成气泡下边缘的反应标记：**已引导运行中的回合**（主色）或 **已打断上一轮并重新发送**（警告色）。当后面已经存在更新的回合时，旧回合会标记为被取代：实时状态、运行时长和流式行扩展停止，但已经产生的行仍然可见并保持展开。

取消或删除队列项不会撤销已经完成的操作。定时发送到点后仍受会话状态和权限约束；如果会话在等待审批，发送会等待而不是跳过审批。

## 自动继续

启用 **自动继续** 后，只有满足会话设置和 Agent 能力的回合会自动推进。遇到权限请求、询问表单、失败或需要用户选择时会停下来等待。

- 自动继续默认开启，可以在 **设置 → 会话** 里改默认值。
- 会话组可以单独打开整组自动继续。
- 倒计时期间可以按 TUI 的 `t` 或点击界面上的停止按钮取消本次自动继续。
- 自动继续不会绕过权限审批，也不会替你回答询问表单。

## 权限请求与询问表单

当 Agent 请求终端、文件写入、浏览器导航、电脑操作或其他受保护能力时，时间线会显示请求原因和范围，通常包含工作目录、参数和环境变量。可选操作为 **允许**、**拒绝** 和 **本会话始终允许**。

询问表单需要填写结构化内容。提交前确认值和作用范围；取消表单会让 Agent 收到取消结果，而不是隐式批准。

电脑操作的审批卡还会显示目标应用、操作类别和原因；破坏性或前台操作附带目标窗口截图。密码管理器、安全输入框和 Vibex 自身窗口始终逐次处理或直接拒绝。

## 全局搜索与查找

`cmd-k` 在任何位置都能打开 **全局搜索**（工作台命令面板），入口是标题栏里的搜索图标，紧挨运行时控件之前。一次输入同时检索三组结果：

| 分组 | 范围 | 选中后 |
| --- | --- | --- |
| **最近会话** / **会话** | 会话标题和消息正文 | 打开会话并跳到命中的那条消息 |
| **设置** | 设置项 | 打开设置、定位到对应分区并高亮那一行 |
| **快捷操作** | 注册在工作台上的真实 Action | 直接执行；每行显示自己的快捷键，前置条件不满足时显示为不可用 |

- 面板顶部有自己的查询框，三组之间画有分隔线；空查询时只列出 **最近会话**。
- 会话搜索只索引和高亮对话文本——用户消息、Agent 回答、推理和计划——并只给命中的关键词着色，当前命中颜色更重。
- 输入非空时按 `escape` 先清空输入，再按一次才关闭。
- 索引在后台构建并保留，再次打开是瞬间完成的。已归档的会话不参与搜索。

单会话内的查找仍然用 `cmd-f`（**在当前会话中查找**）。

## 导入本地历史

通过侧栏 **更多** 菜单或项目右键菜单中的 **导入会话** 导入其它 Agent 的历史。

支持 14 个来源：**Claude Code**、**Codex**、**OpenCode**、**Gemini CLI**、**Cline**、**Hermes**、**CodeBuddy Code**、**Kimi Code**、**Pi**、**Grok**、**Cursor**、**DeepSeek Harness**、**ZCode**、**Google Antigravity**。

流程：

1. Vibex 扫描本机历史，显示 **正在扫描本地 Agent 会话...**。
2. 在预览列表中按项目分组勾选要导入的会话，可以按 Agent 筛选或重新扫描。
3. 点击 **导入 {n} 个会话**，等待 **导入完成**。

结果会分成 **已导入**、**已消失**、**失败** 等类别。

<Note>
  扫描器只读取元数据：标题、时间、工作区路径、消息数量和来源路径。导入时才会重新读取内容并一次性写入时间线。凭据、密钥和完整 Agent home 配置**不会**导入。已导入过的会话不会重复导入，也不会被刷新覆盖。
</Note>

## 通知与未读

会话完成、失败或等待输入时，权威运行时可以发送桌面通知。三类通知可以在 **设置 → 会话** 的 **Agent 通知** 中分别开关。

有未读完成项的会话在侧栏显示圆点提示；打开会话后提示消失，以权威时间线为准。系统托盘菜单也提供 **新建会话**、**配置中心** 和 **设置** 的快捷入口。

## 归档与恢复

归档会保留完整时间线，只把会话移出侧栏：

- 从会话行菜单、多选菜单或批量栏都可以归档；归档是可逆的，所以不弹确认。
- **设置 → 已归档会话** 可以恢复或永久删除。
- 自动归档可以按项目/文件夹设置空闲窗口（关闭，或 1–14 天）。
- 误归档可以撤销；删除不能。

## 子 Agent 时间线

当会话使用了委派时，右侧栏会出现 **子 Agent 时间线** 入口，可以查看子 Agent 的独立时间线，并从父会话跳转过去。子 Agent 的更新会标记归属，不会混进父会话的行。

## 在终端里继续

Vibex TUI 可以附着到同一个运行时，读取同一批会话、发送消息、处理审批和队列。`vibex` 会打开当前目录的新会话页；`Ctrl+L` 打开会话列表。详见 [Vibex TUI](/tui)。
