---
title: "用量统计"
description: "按时间、Agent、供应商、模型、项目和会话查看本地用量。"
---

**Usage Statistics** 用来查看 Vibex 已记录的 Agent 用量。它是本地工作区的观测工具，不是账单页面；实际价格、额度和发票仍由供应商决定。

## 选择时间范围

工具栏支持以下范围：

| 范围 | 含义 |
| --- | --- |
| **Today** | 按系统时区查看今天的记录。 |
| **7 days** | 查看最近七天。 |
| **30 days** | 查看最近三十天。 |
| **All** | 查看本地保留的全部记录。 |

统计结果会显示有效起止时间和分桶方式。时间范围为空或没有可用记录时，页面会显示空状态，而不会把未知值当成零。

## 筛选和分组

你可以组合 **Agent**、**Model provider**、**Model**、**Project** 和 **Session** 筛选器。结果还可以按时间、Agent、项目、供应商或模型分组。长会话名称会在筛选菜单中截断显示，但悬停仍可查看完整名称。

## 读取指标

汇总和分组表会尽量显示以下指标：

- **Requests**：已观测的请求或会话运行次数。适配器不提供逐请求数据时，页面会按可确认的运行粒度统计。
- **Total tokens**：输入、输出和缓存等可用 Token 的合计。
- **Input / Output / Cached tokens**：分别显示输入、输出和缓存 Token。
- **Cache hit rate**：缓存读取 Token 相对于可计算分母的比例。
- **Coverage**：标记指标是完整上报、推导、部分上报还是未知。

缺少供应商字段时，Vibex 保留未知状态。不要把 `unknown` 或 `partial` 解读为零，也不要用它推算供应商账单。

## 查看趋势

趋势区域提供三种视图：

- **Bars**：按时间桶比较总量、输入、输出、缓存或请求数。
- **Heatmap**：按日期查看全年活动密度；没有年度数据时会显示不可用状态。
- **Models**：按模型比较请求数或总 Token，超出主要模型数量的项目会归入其他模型。

切换指标不会修改已保存的用量记录。刷新期间页面会保留上一份结果并标记为过期，加载失败时优先使用上一份权威结果。

## 数据边界

用量来自桌面端记录的 Agent 执行和适配器上报。桌面端是统计的权威来源；移动端只接收经过权限过滤的投影。Usage Statistics 不读取完整 Prompt、文件内容、终端输出或供应商密钥。导出诊断时仍应遵守 [隐私与恢复](/privacy-and-recovery) 中的脱敏要求。
