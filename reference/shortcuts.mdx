---
title: "快捷键"
description: "Vibex 的全部默认快捷键，以及如何重新绑定。"
---

Vibex 的快捷键可以在 **设置 → 快捷键** 中查看、修改和重置。冲突的键位会被拒绝，并提示 **快捷键无效或已被占用**。

## 可重绑定的快捷键

以下 15 个动作可以在设置里重新绑定：

| 操作 | 默认键 | 分组 |
| --- | --- | --- |
| 切换侧栏 | `cmd-b` | 工作台 |
| 切换预览 | `cmd-shift-p` | 工作台 |
| 切换右侧栏 | `cmd-shift-r` | 工作台 |
| 打开运行时 | `cmd-shift-o` | 工作台 |
| 切换对话/终端模式 | `cmd-shift-t` | 输入框 |
| 在当前会话中查找 | `cmd-f` | 导航 |
| 打开设置 | `cmd-,` | 导航 |
| 全局搜索 | `cmd-k` | 导航 |
| 后退 | `alt-left` | 导航 |
| 前进 | `alt-right` | 导航 |
| 重试运行时 | `cmd-r` | 运行时 |
| 保存当前文件 | `cmd-s` | 编辑器 |
| 跳转到行 | `ctrl-g` | 编辑器 |
| 撤销图片编辑 | `cmd-z` / `ctrl-z` | 图片编辑器 |
| 重做图片编辑 | `cmd-shift-z` / `ctrl-shift-z` | 图片编辑器 |

<Note>
  表中写的是 `cmd-` 前缀，它在 macOS 上是 Command 键，在 Windows / Linux 上是 Ctrl 键。只有图片编辑器的撤销 / 重做按平台分别定义。
</Note>

**重置** 恢复单项默认值，**全部重置** 清除全部自定义映射。

## 不可重绑定的快捷键

这些快捷键是固定行为：

| 操作 | 按键 | 作用范围 |
| --- | --- | --- |
| 关闭当前预览标签 | `cmd-w` | 非终端标签 |
| 循环切换标签 | `cmd-tab` / `cmd-shift-tab` | 非终端标签 |
| 切换上一个 / 下一个标签 | `cmd-pageup` / `cmd-pagedown` | 非终端标签 |
| 终端复制 / 粘贴 / 搜索 | `ctrl-shift-c` / `ctrl-shift-v` / `ctrl-shift-f` | 终端标签 |
| Tab 补齐 | `tab` / `shift-tab` | 终端标签（发送给 shell 而非移动焦点） |
| 调取历史消息 | `up` / `down` | 会话输入框（上键只在输入框为空时开始；输入即结束翻阅；下键回到最新，越过最新则恢复草稿） |
| 关闭弹层 | `escape` | 运行时管理器、查找栏、全局搜索（第一次清空输入，第二次关闭） |

## 鼠标操作

| 操作 | 效果 |
| --- | --- |
| 拖动词标签 | 重新排列，或拖到边缘分栏 |
| 拖动面板边界 | 调整侧栏 / 右侧栏 / 终端尺寸 |
| 右键文件树条目 | 打开文件操作菜单 |
| 右键标签 | 打开标签操作菜单（关闭、分栏、固定等） |
| 拖动文件 | 在文件树内移动文件，靠近边缘会自动滚动 |
| 缩放图片编辑器 | 滚轮缩放，拖拽平移 |

## 搜索入口一览

Vibex 有多个作用域不同的搜索，不要把它们的范围搞混：

| 搜索 | 范围 | 入口 |
| --- | --- | --- |
| **在当前会话中查找** | 当前会话时间线 | `cmd-f` |
| **全局搜索** | 全部会话标题与消息正文、设置项、快捷操作 | 标题栏的搜索图标或 `cmd-k` |
| **搜索工作区文件** | 当前工作区文件内容 | 文件树 |
| **搜索 MCP** / **搜索技能** / **搜索 Agent** | 对应配置中心列表 | 各自列表顶部 |
| **搜索提交信息或代码** | Git 提交历史 | Git 面板提交标签 |
| **搜索设置** | 设置项 | 设置顶部 |

<Note>
  **全局搜索** 是唯一的跨类型入口：一次输入会同时给出会话、设置项和快捷操作三组结果，按 `cmd-k` 在任何位置都能打开。会话搜索不再挂在侧栏，入口移到了标题栏、紧挨运行时控件之前。
</Note>
