---
title: "终端与预览"
description: "在原生终端中运行命令，并在工作台查看生成的内容。"
---

Vibex 的终端使用原生 PTY 和 ANSI 仿真，适合运行开发服务器、测试和 Git 命令。终端属于桌面运行时；移动端只在获得权限后请求远程终端视图或输入。

## 打开终端

1. 打开工作台的终端面板。
2. 选择工作区目录和 shell。
3. 在终端标签中运行命令。可以创建多个标签并分别调整尺寸。
4. 需要查看旧输出时滚动滚动缓冲区，或使用终端搜索。

```bash
git status --short
pnpm test
```

## 终端操作

- 创建、关闭和切换多个标签。
- 拖动面板边界调整 PTY 尺寸；程序会收到最新的 rows/columns。
- 使用滚动缓冲区查看历史输出。
- 搜索输出，复制选中文本，或粘贴输入。
- 切换可用 shell；shell 的安装和权限由操作系统决定。
- 处理原始字节和 ANSI 控制序列，避免把二进制输出当作普通文本。

## 与 Agent 配合

Agent 请求运行命令时，时间线会显示进程详情和退出结果。命令可能等待权限批准；批准前检查命令、工作目录和参数。终止终端进程不会撤销它已完成的外部操作。

## 预览生成结果

在代码工作台中打开 Markdown、图片、PDF 或受支持的 Office 文档。开发服务器产生的网页预览不等于 Vibex 的远程 Web 后端；Vibex 只在工作区中提供原生内容预览。

<Note>
  终端快照可能包含密钥、路径和用户数据。不要把完整终端输出复制到公开 Issue、日志或诊断证据中。
</Note>

## 移动端终端

移动端收到的是终端快照和经过授权的输入通道。输入会带工作区作用域、generation 检查和审计记录；网络中断时，移动端不会假设命令已经执行，重连后以桌面端快照为准。
