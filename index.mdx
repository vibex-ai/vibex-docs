Vibex 把 Agent 会话、工作区文件、编辑器、Git、终端和预览放在同一个原生工作台里。你可以让 Agent 修改代码，再检查计划、工具调用和差异，最后在同一个工作区中运行和交付改动。

Vibex 的桌面端是唯一的权威运行时。它负责启动 Agent、保存会话和时间线、访问文件与 Git、管理终端和权限。iOS 与 Android 移动端是远程伴侣，不会在手机上运行 Agent，也不会复制一份工作区。

## 你可以用 Vibex 做什么

- 在结构化时间线中查看 Markdown 回复、推理、计划、工具调用、进程详情、附件、审批和询问表单。
- 用 `/` 命令、`@` 文件引用、`$` Skills 和附件组织 Composer 输入。
- 在文件树和编辑器中搜索、编辑、保存、重命名和预览文件。
- 查看 Git 状态、差异、历史和 blame，创建分支并提交或推送改动。
- 使用带 ANSI 仿真的原生 PTY，在多个终端标签中运行项目命令。
- 配置 Agent、模型供应商、MCP、Skills、Prompts、Hooks、定时任务和自动化图。
- 按时间、Agent、供应商、模型、项目和会话筛选用量，并区分完整、推导、部分和未知数据。
- 将桌面会话安全地配对到移动端，在手机上查看进度、回复问题和处理审批。
