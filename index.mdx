Vibex 把 Agent 会话、工作区文件、编辑器、Git、终端、内嵌浏览器、电脑操作和预览放进同一个原生工作台。你可以让 Agent 修改代码，再检查计划、工具调用和差异，最后在同一个工作区里运行和交付改动。

Vibex 采用**权威运行时 + 类型化投影**的结构：

- **权威运行时**持有 Agent 进程、会话时间线、工作区文件、Git、终端、浏览器、电脑操作、供应商凭据和持久化状态。它有三种形态，能力一致：
  - **桌面端内嵌的本地运行时**（默认）。
  - **无头运行时 `vibex-server`**，运行在你自己的服务器或家用机器上。
  - **SSH / WSL 远程运行时**，由桌面端在另一台机器或本机 WSL2 里配置和管理（测试版）。
- **客户端**是桌面工作台、iOS / Android 移动端和 **Vibex TUI**。它们渲染权威运行时发来的投影，并发送类型化操作。移动端和 TUI 不在本地运行 Agent，也不复制一份工作区。

也就是说，桌面端既可以**自己作为权威运行时**，也可以**连接到一个远程权威运行时**。详见[远程访问与移动端](/remote-mobile)、[SSH 与 WSL 远程运行时](/ssh-runtime)和[自托管无头运行时](/self-hosted-server)。

## 你可以用 Vibex 做什么

- 在结构化时间线中查看 Markdown 回复、推理、计划、工具调用、进程详情、附件、审批和询问表单。
- 用 `/` 命令与 Prompt、`@` 文件与 Agent、`$` 技能和附件组织输入框的内容。
- 把任务委派给子 Agent，保持任务打开、追加跟进、接受或取消，并用目标跟踪长回合。
- 让 Vibex 自己下载、升级和卸载受支持的 Agent 运行时，并按 Agent 配置模型供应商。
- 在共享 Provider、路由组和本地网关之间做故障转移和协议转换。
- 在文件树和编辑器中搜索、编辑、保存、重命名和预览文件。
- 查看 Git 状态、差异、历史和 blame，创建分支并提交或推送改动；用隔离的 Git worktree 并行推进多个任务。
- 使用带 ANSI 仿真的原生 PTY，在多个终端标签和分屏中运行项目命令。
- 在内嵌浏览器里查看页面，让 Agent 读取和操作它；在批准后让 Agent 操作本机桌面。
- 从应用内市场安装 MCP 服务器和 Skill，编写可复用 Prompt，并按 Agent 限定作用域。
- 把消息排进队列、引导运行中的回合、安排稍后发送，或让自动继续推进回合。
- 按时间、Agent、供应商、模型、项目和会话筛选用量，并区分完整、推导、部分和未知数据。
- 跨全部会话和消息正文搜索，导入本地 Agent 历史，归档并恢复会话。
- 把桌面会话安全地配对到移动端，在手机上查看进度、回复问题、处理审批和使用终端。
- 在终端里用 TUI 继续同一批会话，或通过 SSH / WSL / 自托管运行时从任意设备继续工作。
