Vibex 把 Agent 会话、工作区文件、编辑器、Git、终端和预览放进同一个原生工作台。你可以让 Agent 修改代码，再检查计划、工具调用和差异，最后在同一个工作区里运行和交付改动。

Vibex 采用**权威运行时 + 类型化投影**的结构：

- **权威运行时**持有 Agent 进程、会话时间线、工作区文件、Git、终端和供应商凭据。它有两种形态，能力完全一致：
  - **桌面端内嵌的本地运行时**（默认）。
  - **无头运行时 `vibex-server`**，运行在你自己的服务器或家用机器上。
- **客户端**是桌面工作台和 iOS / Android 移动端。它们渲染权威运行时发来的投影，并发送类型化操作。移动端不在本地运行 Agent，也不复制一份工作区。

也就是说，桌面端既可以**自己作为权威运行时**，也可以**连接到一个远程权威运行时**。详见[远程访问与移动端](/remote-mobile)和[自托管无头运行时](/self-hosted-server)。

## 你可以用 Vibex 做什么

- 在结构化时间线中查看 Markdown 回复、推理、计划、工具调用、进程详情、附件、审批和询问表单。
- 用 `/` 命令、`@` 文件引用、`$` Skills 和附件组织 Composer 输入。
- 让 Vibex 自己下载、升级和卸载受支持的 Agent 运行时。
- 在文件树和编辑器中搜索、编辑、保存、重命名和预览文件。
- 查看 Git 状态、差异、历史和 blame，创建分支并提交或推送改动；用隔离的 Git worktree 并行推进多个任务。
- 使用带 ANSI 仿真的原生 PTY，在多个终端标签中运行项目命令。
- 配置 Agent、模型供应商、MCP 和 Skills。
- 按时间、Agent、供应商、模型、项目和会话筛选用量，并区分完整、推导、部分和未知数据。
- 跨全部会话和消息正文搜索。
- 把桌面会话安全地配对到移动端，在手机上查看进度、回复问题和处理审批。
- 把桌面端或移动端配对到自托管的无头运行时，从任意设备继续同一批会话。
