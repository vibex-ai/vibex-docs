## Highlights

* **Vibex TUI: the whole workbench fits in a terminal** — Sessions, streamed Markdown, approvals, the queue, settings and pairing all move into the terminal, laid out as one column of full-width bands that reflows with the window, so there is no minimum size. It ships with every desktop installer, works over SSH and in tmux, and can either start its own runtime or attach to the one your desktop is already running.
* **Agents work as a team** — Delegation is no longer one question and one answer: a task can stay open after its turn ends, you follow up in the same child session, and then decide whether to accept or cancel. The sidebar's ownership tree and the session group's team status header show how far the work has moved.
* **Scheduled messages** — Pick an hour for a message and it stays in the queue for you. The schedule survives a restart, is edited in a popup, and shows a send another client is holding.
* **A custom workbench background** — Put your own image behind the workbench, still or animated, filled, fitted or stretched, with an adjustable scrim on top so text stays readable over anything. Images import the same way project icons do and live under the runtime home.
* **Agent computer control** — After you authorize it, an Agent can take over the host machine's desktop. It installs and is managed in Settings, has its own floating shell and localized panels, the driver's console window never lands on your desktop, and the master switch turns it off at any time.
* **Mobile rebuilt to match the desktop** — Mobile follows the desktop's model: session groups and the ownership tree, a right sidebar with a file tree and diffs, scheduled sends, worktrees, goals, haptics, and a rebuilt pairing and first-run flow.
* **Automatic updates on by default** — The desktop updates itself by default and existing installs are moved to that behaviour; iOS ships an unsigned device IPA alongside the simulator build, which you re-sign with your own Apple ID.

## New Features

**Vibex TUI (terminal client)**

* The interface is one column of full-width bands — status, conversation, turn status, composer, shortcut bar — replacing the old split grid and reflowing at any terminal size, so there is no minimum size and no more "window too small" (`1aa9e4d5`, `dedafc55`, `eb95f780`)
* The conversation renders Markdown in place as it streams, with emphasis, code and tables drawn from real syntax and a full colour hierarchy instead of white on white (`e9b05a27`, `2acf4d03`, `10507286`)
* A finished turn folds behind a `▸ Worked for 12s` divider that is itself the toggle; expanding re-measures row heights, and expanding mid-run does not push the reader out of place (`eb4ed877`, `f39d5163`, `13ba42e6`)
* User messages that scroll away pin above the viewport and are drawn once, `/` search runs a smart-case regex, and scrolling to the top loads older history (`ae610ee3`, `28dda9e3`, `71fee6c1`, `f4d6e9a2`)
* You can select conversation text with the mouse and copy it over OSC 52, over SSH and in tmux; the cells the selection covers are copied in full (`143b82fb`, `39a59f3b`)
* The composer edits like readline — undo, kill buffer, word movement, selection and replacement inside the draft, and Shift+Enter inserts a newline instead of sending (`5897bd40`, `114b7b30`, `63b44766`)
* A long paste collapses into a `[Pasted: 42 lines]` chip whose contents you can preview, and a sent message is recalled with the arrow keys (`864cba66`, `499a7ea5`, `9503ed2e`)
* Clipboard images, pastes and drops all become chips, drawn at the terminal's own resolution, and you can paste an image over SSH (`260a9b6e`, `94b1a22b`, `beacbd90`)
* `/`, `@` and `$` open the desktop's own completion panels — commands and Prompts, workspace files and the Agent delegation list, Skills; the drawer opens in the row and Enter takes the row it offers (`d5f7b041`, `f2259a44`)
* Agent requests appear in place: a question opens on the composer band and is answered with a real form, an approval is a card on the page, and a dock panel collects Agents, plans and held messages (`2cd7cb59`, `918e8a21`, `0300847d`)
* The turn rail ticks by turn only and lights every turn the viewport covers; scrolling to the bottom stops and resumes following (`1b5704e3`, `627bf5c3`, `6699797c`)
* Theme, language and recent commands are remembered; the `?` cheat sheet is grouped, key bindings are edited right in the interface, and a conflict is refused (`c4d28c0e`, `4a49d297`, `4f9ef96c`)

## Performance

* The TUI repaints only the face the reader is looking at: an expanded process group is windowed by row, the window carries its own overscan, and a whole group is no longer laid out every frame (`eac6def7`, `768c97e7`)
* Each process cell keeps its own element tree, a finished cell reuses it, and it is no longer rebuilt every frame (`e45b5288`, `fb567d07`)
* A tool activity group's summary reads a bounded projection table keyed by row version and language instead of re-projecting every member row and re-parsing tool input each frame (`7299a056`)
* The live label measures the gap between two conversation frames, falls back to static text when frames drop, and resumes its sweep once the display is back in cadence (`7299a056`)
* Opening a session no longer pages the whole archive: it reads a bounded window by turn and by byte, a page carries only the fields collapsed activity needs, tool details are read separately when expanded, and a finished turn merges adjacent stream chunks into one row (`ca7a1d62`, `e6295130`)
* The view keeps growing its window while the conversation does not fill the viewport, instead of stopping at less than a screenful and waiting for a scroll (`e6295130`)
* The sidebar skips the session query when a heading collapses or expands and reads the arrangement it already has (`f164c9fe`)
* Multi-select resolves once per frame: one scope map and one drag payload per item, with a row's batch menu reading from the same slice (`48055044`)
* The sidebar's running indicator now draws a six-dot ring point by point on a fixed 20px canvas with a sweeping highlight, sampled to the conversation's 30fps budget — no longer replaying the TUI's braille frames at 10fps, and no longer falling back to replacement boxes when a font lacks the block (`828749ed`, `aa705410`, `5642cf83`)
* A child Agent's conversation no longer folds every frame, and the child Agent side rail gets its own render boundary and a per-session Markdown retention table (`2e89866e`, `92a7e905`)
* A retained cell is rebuilt only when its render key changes, expanding or collapsing triggers one re-render, and a notification alone no longer causes a rebuild (`1ee6f666`)
* Every row has its own id, so two rows no longer share one element and one retained text view, and a streamed answer is not left as a bare background block (`5d11e308`)
* The desktop narrows repaints to the sidebar and the conversation, virtualizes the Markdown file preview, and spreads its work across frames when it opens (`e3e0f5f2`, `1bac0ed1`, `df7dd245`)
