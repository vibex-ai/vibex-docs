Vibex terminals use a native PTY with ANSI emulation, which makes them a good fit for dev servers, tests, and Git commands. Terminals are hosted by the **authoritative runtime**, so mobile can use the same terminals once it has permission.

## Open a terminal

Open one from the **New terminal** icon in the right sidebar, or choose **Open In → Terminal** on a path in the file tree to start the terminal in that directory.

```bash
git status --short
pnpm test
```

The terminal button above the composer opens a **bottom terminal panel**. Press `cmd-shift-t` to switch between the conversation and the terminal. The panel spans the workbench width instead of being squeezed into the composer.

## Terminal actions

| Capability | Description |
| --- | --- |
| Tabs | Create, close, rename (**Rename terminal** / `Terminal name`), and switch. |
| Splits | The tab menu offers **Split right** and **Split down**; drag the split boundary to resize. |
| Resize | Drag the panel boundary and the PTY receives the latest rows/columns; the pane fills the new size at once instead of leaving the painted grid at its old size. |
| Scrollback | Fixed at **10000 lines**, not configurable. |
| Search | **Search terminal** opens the search bar and shows `0 matches` or `{n} / {total}`. Search covers every retained line rather than only the painted viewport, and **Previous match** / **Next match** scrolls the hit into view. |
| Scrolling | A draggable scrollbar sits over the grid; `shift-pageup` / `shift-pagedown` and `shift-home` / `shift-end` also scroll. In the alternate screen (a full-screen Agent) the wheel becomes arrow keys. |
| Copy and paste | **Copy** / **Paste** in the toolbar, or `ctrl-shift-c` / `ctrl-shift-v`. Double-click selects a word and triple-click a line. |
| Search shortcut | `ctrl-shift-f`. |
| Open link | Hover the cursor over a hyperlink to see **Open link**; a plain `http(s)` address opens on click. |
| Status | The tab shows `running`, `exited`, `killed`, or `stale`. |

The terminal handles output and ANSI control sequences as raw bytes and never treats binary output as text.

### Rendering

- **Box Drawing** characters are painted from their arms as joined vector lines — heavy, double, dashed, rounded and diagonal forms included — so tables and panel borders line up across cells.
- **`Symbols Nerd Font Mono`** ships with the app and private-use symbol glyphs are fitted to the cell outline, so an Agent's status icons no longer paint as tofu.
- Cell metrics come from the font's own advance rather than a fixed 8x18 constant; wide cells keep the font's advance, so CJK still spans two columns.
- **Ligatures** are a preference, toggled in **Settings → Appearance → Ligatures**. Off keeps every glyph on its own cell, which is what column-aligned output assumes.
- The terminal background can be translucent (**Settings → Appearance → Terminal opacity**, 60%–100%); theme ink is lifted to a minimum contrast while a program's own true colour is left alone.

### Terminal protocol support

Beyond ordinary ANSI sequences, the terminal also answers:

- **OSC 52** clipboard stores and reads, which is what makes copying work over SSH and in tmux.
- **OSC 0 / 2** window and tab titles.
- **OSC 4 / 10 / 11 / 12** colour queries.
- **Mouse reports** in the 1005, 1015 and 1016 dialects.

## Shell selection

The toolbar lists the available shells, and selecting one switches the shell for the current tab:

- Windows: **PowerShell**, **Command**.
- Other platforms: **bash**, **zsh**, **fish** (only those actually present on the system).

Each tab can pick its own shell. To change the default shell, see [Settings](/en/settings).

## Working with Agents

When an Agent asks to run a command, the timeline shows the process details and the exit result. The command may wait for permission; check the command, working directory, and arguments before you approve it.

<Warning>
  Killing a terminal process does not undo the external operations it already completed. Stopping an Agent also does not reclaim the terminals it already opened.
</Warning>

## Stale terminals

After the authoritative runtime restarts, terminal session content is not preserved (only tab metadata is). Lost terminals are marked `stale`.

When you see `stale`, reopen the tab and trust the new snapshot — do **not** repeat commands based on the old snapshot.

## Mobile terminals

Mobile receives terminal snapshots and a permission-gated input channel. Input carries the workspace scope, generation checks, and an audit record. When the network drops, mobile does not assume a command ran; after reconnecting, trust the authoritative snapshot.

## TUI and SSH

The Vibex TUI is a client in the terminal, not a replacement for terminal tabs: it draws sessions, approvals, the queue, and settings on a character grid, which makes it useful over SSH or in tmux. It ships with the desktop package; run `vibex`. See [Vibex TUI](/en/tui).

The TUI copies over OSC 52, so copying works over SSH and in tmux. It does not take over terminal tabs already open on the desktop; both are clients of the same runtime.

<Note>
  Terminal output can contain secrets, paths, and user data. Do not paste complete terminal output into public issues, logs, or diagnostic material.
</Note>
