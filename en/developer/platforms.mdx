## Support matrix

| Platform | Product form | Key dependency | Note |
| --- | --- | --- | --- |
| Linux | Native desktop | Vulkan graphical session | Supports development and preview smoke tests. |
| macOS | Native desktop | Xcode toolchain as needed | Also supports iOS builds. |
| Windows | Native desktop | Native Rust/Node environment | Use the platform shell. |
| Android | Native mobile | Android SDK/NDK, `cargo-ndk` | Debug defaults to arm64-v8a/x86_64. |
| iOS | Native mobile | macOS, Xcode, XcodeGen | Produces `VibexFFI.xcframework`. |
| Self-hosted Linux/container | Relay | Rust/Axum or Docker | Forwards encrypted frames only. |

## Desktop platform boundaries

The desktop owns Agents, files, Git, PTY, providers, permissions, and persistence. Keep platform differences in `apps/desktop/src/platform` or a shared facade. Do not duplicate business branches in UI code.

## Android builds

```bash
pnpm build:mobile:android
```

Package a Release APK with:

```bash
pnpm package:mobile:android
```

Set `VIBEX_MOBILE_ANDROID_TARGETS` to override Debug ABIs. Release APKs are unsigned and need alignment and signing before distribution.

## iOS builds

```bash
pnpm build:mobile:ios
```

Xcode controls signing, bundle identifiers, and device or simulator selection. Do not commit certificates or provisioning profiles.

## Mobile lifecycle

Mobile must handle backgrounding, network changes, disconnects, and reconnects. On resume, fetch authoritative sessions and timelines through Remote v2 before subscribing to live events. Do not let an old local projection overwrite desktop state.

## Relay deployment

Bind Relay to loopback and publish it through controlled HTTPS or Tailnet Serve. Validate Host and Origin independently; never use `*` for CORS. Relay must not serve a mobile Web UI or business API.
