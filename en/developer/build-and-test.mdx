## Routine checks

```bash
pnpm check
```

This covers Rust quality, frontend type/lint, and license checks. Use `pnpm check:all` for a broader cross-layer run.

## Release build smoke

```bash
pnpm release:build-smoke
```

This checks the desktop, mobile, and Relay crate build graph. It does not produce a signed release package. Targeted desktop checks are:

```bash
cargo check -p vibex-desktop --locked
cargo test -p vibex-desktop --locked
pnpm smoke:first-frame
```

## Feature smoke

The repository provides checks for ACP, the code workbench, terminals, PDF and native content, remote pairing, and Relay. For example:

```bash
pnpm check:acp
pnpm check:code-workbench
pnpm check:terminal
pnpm check:mobile-native
pnpm smoke:relay:local
```

Scripts can create local evidence or capture files. Check `.gitignore` and the script notes. Do not commit artifacts containing credentials, Prompts, paths, diffs, or terminal content.

## Contracts to test

- Insufficient permission returns a structured error.
- Cursor/generation gaps trigger `resync_required`.
- File writes use revision/CAS to avoid overwriting external edits.
- Terminal and attachment streams open only after authorization and close on revocation.
- Restart, disconnect, and stale states are reproducible.

## Release checklist

Read `docs/operations/release.md` and the target platform notes before a release. Packages, runtime binaries, Release APKs, and signing material are build artifacts, not source.
