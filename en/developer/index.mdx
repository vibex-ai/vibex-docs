## Constraints to preserve

- The desktop owns Agents, sessions, timelines, files, Git, PTY, providers, permissions, and persistence.
- Mobile consumes shared remote projections and sends typed operations. It does not duplicate business state.
- Remote v2 DTOs, errors, capabilities, and sequence contracts live in the shared core layer.
- Relay forwards encrypted frames. It does not own authorization, files, or the session database.
- Cross-layer changes need deterministic checks or evidence and a test set proportional to their risk.
