Vibex brings Agent sessions, workspace files, editing, Git, terminals, and previews into one native workbench. Ask an Agent to change code, inspect its plan and tools, review the diff, and deliver the result from the same workspace.

The desktop is Vibex's only authoritative runtime. It starts Agents, stores sessions and timelines, accesses files and Git, and controls terminals and permissions. The iOS and Android clients are remote companions. They do not run a local Agent or keep a second workspace.

## What you can do with Vibex

- Read Markdown replies, reasoning, plans, tool and process details, attachments, approvals, and elicitation forms in a structured timeline.
- Use `/` commands, `@` workspace references, `$` Skills, and attachments in Composer.
- Search, edit, save, rename, delete, and preview files from the file tree and editor.
- Review Git status, diffs, history, and blame; create branches and commit or push changes.
- Run project commands in native PTY tabs with ANSI emulation.
- Configure Agents, model providers, MCP, Skills, Prompts, Hooks, scheduled tasks, and automation graphs.
- Filter usage by time, Agent, provider, model, project, and session, with explicit coverage states.
- Pair a desktop session with mobile to monitor progress, answer questions, and handle approvals.
